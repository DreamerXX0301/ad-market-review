# 冒险的梦想家 · 前端

React、TypeScript、Vite 与 ECharts 实现盘面研究、个股/板块策略及跟踪。行情、指标、筛选与回测结果来自后端；页面按实际返回的数据和覆盖状态展示。

产品入口和首次配置见[项目 README](../README.md)，部署与更新见[版本升级与回滚](../docs/版本升级与回滚.md)。

0.1.15源码与发行附件以对应 [v0.1.15 标签](https://github.com/DreamerXX0301/ad-market-review/tree/v0.1.15)及[本版 Release](https://github.com/DreamerXX0301/ad-market-review/releases/tag/v0.1.15)的实际状态为准，变更及schema32不变的升级边界见[版本记录](../CHANGELOG.md#v0115)。完整提交、镜像摘要和双架构检查以本版`release-image.json`为准；构建成功不等于镜像已经发行或现用实例已经更新。

本版将竞价、午评及盘后自动开关统一到数据中心，竞价只保留每天计划状态；股票明细新增昨日板型、板高与板别组合筛选和排序。个股已保存结果按实际补充输入核验后复用，新盘后增量完成数据发布后再执行已开启的选股、跟踪与划线提醒；既有午评同份成员报价、收盘回看和行业概念能力保持。前端、API和唯一worker来自同一冻结提交；旧运行与午间事实不改写，缺少快照或收盘证据保持明确空态。已发布行情日与午评自然日期分别说明，用户查看不会自动创建取数或策略任务。

自动竞价、午评和盘后计划初始关闭，仅在用户保存开启后由唯一worker在当日有效窗口执行；页面本身不定时创建任务。标准恢复关闭自动配置并保留原台账与自定义时间，副本验收不接管原实例计划。使用规则见[自动午评与盘后复盘](../docs/自动午评与盘后复盘.md)、[盘前竞价](../docs/盘前竞价.md)及[今日划线提醒](../docs/今日划线提醒.md)。

## 本地开发

需要 Node.js 22.12+。在 `frontend/` 运行：

```bash
npm ci
npm run dev
```

开发页面为 [http://127.0.0.1:5173](http://127.0.0.1:5173)，`/api` 代理到 `127.0.0.1:8788`。请另行启动后端；也可在仓库根目录使用 `./scripts/dev.sh` 启动构建后的整套应用。

```bash
npm run format:check
npm run build
```

`build` 先执行 TypeScript 检查，再生成 `dist/`。生产构建由后端同源托管，无外部字体、CDN 或运行时第三方脚本依赖。依赖解析以 `package-lock.json` 为准。

## 交互与数据约束

- 盘面页面共享选择日期；策略、跟踪、题材、研究、回测、数据和来源配置使用独立业务状态。历史研究报告的图表与统计遵守报告行情截止日。
- 个股和板块策略的定义、结果、跟踪轮次分别保存。板块成员打开个股时传明确行情日，不能附带板块入池点位或自动建立个股跟踪。
- 普通条件可继承策略默认日/完整周/完整月，也可逐叶指定周期。定义缺少 `period` 时继承默认周期；固定日线条件不随全局周/月切换。周期标签、右值及依据必须与实际计算一致。
- “历史事件＋当前条件”中每个节点独立绑定事件。新增事件条件按日线配置；复杂规则打开后取消不提交修改，不展平嵌套布尔组。
- 当前成员的采集日与行情日分别显示；历史缺档不借当前名单。报价或指标未知保留 `null`，不补0。精确涨停次数与已确认下界有不同展示。
- 日 K 的报价序列指标与严格交易日诊断可切换；图表偏好不改变策略、跟踪或回测口径。周/月不完整柱不能确认技术交叉。
- 本地排序必须基于原始数值/日期，未知排末；服务端排序列表由后端对完整查询范围排序后分页，不能二次只排当前页。
- 市场情绪的顶层温度/阶段与三轴统计分开；制度组价格主卡使用昨日冻结队列的独立价格对象，严格同制度晋级另行核验。页内目录支持折叠区、页底及窄屏定位，当前项蓝色与执行状态红/绿/黄/灰分开；无值收起，真实0保留。
- 盘面板型使用共享 `BoardTags` 与后端已核验对象，高度、形态、量能和反馈独立展示；连板反馈按已确认昨日高度降序，未知不回退原始高度。完整边界见[市场温度与计划](../docs/市场温度与下一交易日计划.md)和[板型与反馈](../docs/连板高度板型与反馈.md)。
- 业务修改通过实际 API 留存。浏览器存储只用于主题和图表偏好，不保存 Key、持仓或业务数据库；Key 仅提交后端，配置输入及时清空。

## 可复现检查

以下命令均在 `frontend/` 执行：

```bash
npm ci
npm run format:check
npm run build
find src -name '*.test.mjs' -print0 | xargs -0 -n 1 node
```

辅助用例覆盖显示口径、周期继承、规则/政策往返、历史事件绑定、排序、搜索、日期、图表偏好、摘要与任务进度。它们不替代浏览器视觉与真实数据验收。

对已启动且已初始化的隔离副本执行GET契约审计：

```bash
SHIXU_API_BASE=http://127.0.0.1:8789/api/v1 npm run check:api
```

不设默认地址；执行时必须用 `SHIXU_API_BASE` 显式指定隔离候选的完整前缀，缺少参数时在发送请求前退出。8789是示例候选端口。完整套件读取研究报告会更新报告缓存TTL和保留引用，不是业务库完全不变的只读检查，不能对唯一正式库直接运行。报告写入当前目录 `api-contract-checks.json`，不应把包含本机业务明细的报告直接作为公开制品。脚本不会配置来源、验证凭据、创建同步或运行策略；未初始化实例不满足这项真实数据审计的前提。正式只读验收须排除有副作用的GET并做前后对账，步骤见[交付与验收](../docs/交付与验收.md#已初始化实例检查与get副作用)。

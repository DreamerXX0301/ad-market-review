# 自动午评与盘后复盘

在「数据中心 → 自动午评与盘后复盘」分别设置自动午评和自动盘后复盘。新安装两个开关都关闭；默认时间分别为北京时间12:05和18:30。勾选、调整时间后点击「保存自动设置」才生效，保存计划不代表任务已经创建或执行。读取或保存设置不取行情、不初始化数据库。

## 时间和运行条件

- 时间始终按`Asia/Shanghai`解释，与浏览器或电脑的显示时区无关。
- 午评可设为11:31至12:59；只在当天有效窗口执行，13:00起不再补采当天午评。
- 盘后可设为18:00至23:59；当天到点后重新启动服务，可以在当日继续检查，跨零点不追补历史。
- 唯一worker约每60秒检查一次，不承诺精确到秒。电脑和API/worker必须运行，关闭页面不会停止服务端检查，关机时不能采集。
- 只在已经核验的市场交易日及来源、初始化条件满足时创建任务。没有准确日历或其他前提时保留原因，不猜测下一次精确执行时间。

本功能是保存开启后对两类自动创建任务的明确授权；首次初始化仍由用户手动发起。不建立新的行情worker，不由浏览器轮询计时或自动调用取数接口。启用午评、盘后设置互相独立；关闭计划阻止后续自动创建，不等同于取消已经创建的任务。

## 重复、失败与已有任务

同一天已有运行中或已完成任务时复用已有任务，不再重复创建。失败、暂停或取消任务保留在原任务中，由用户手动处理，调度不会自动重试或续跑；手动午评的每天一次约束与时间窗继续适用。页面的最近检查显示服务器返回的任务日、原因、检查时间和任务状态；有任务身份时可点击「查看已有任务」，不会因此创建新任务。

盘后复盘沿用已有主行情增量及后续链、全局进度锁、策略同步开关与来源核验规则，不因为开启自动计划而自动初始化、扩大旧任务范围或无条件加入跟踪。没有当日有效午评时，盘后不反造午间数据。

自动盘后任务由现有全局会话发现机制显示进度并锁定业务操作，不要求在当前浏览器中手动点击运行。任务完成后仍需用户确认结果才解锁，不自动确认。上一轮结果未确认时，后续自动盘后复盘等待确认。自动午评由活动任务摘要发现并锁定，采集结束后沿用午评原有恢复规则。

## 保存与冲突

两个计划一并保存，使用读取时的修订号防止覆盖其它页面的更改。返回设置冲突时保留当前未保存内容；点击「放弃修改并重新读取」后再确认新设置。网络响应不确定或返回不完整时，不显示保存成功，可重新读取核对。盘后整链运行期间，设置读写沿用现有全局操作限制。

卡片不提供声音、浏览器通知或后台页面计时。视觉划线提醒仍按最新已发布业务日显示，与自动计划独立。调度接口及服务端边界见[自动任务契约](../contracts/automatic-review-tasks.md)；午评每天一次与正文保留见[午评快照](午评快照.md)，原生启动见[部署与运维](部署与运维.md)。

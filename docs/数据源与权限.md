# 数据源与权限

每个安装使用自己的来源账户。数据源页面的免费、注册或 Key 标签只描述接入方式，不能证明账户具有某项权限；以配置后的实际能力验证结果为准。注册成功、请求成功和完整历史覆盖是三个不同结论。

## 接入与凭据

| 来源入口 | 主要职责 | 限制 |
| --- | --- | --- |
| 扶摇 | 已适配的批量行情、指数、题材及特色数据 | 需要自己的 Key，按接口验证权限和历史范围 |
| TickFlow 公开/Key 模式 | 已适配的行情能力 | 公开模式不代表所有接口免费可用；Key 模式按实际权限 |
| AKShare 同源公开补充 | 封板明细、行业资金与部分公开盘面资料 | 直接适配相关公开接口，限流与历史窗口可能变化，不依赖本机 AKShare 安装 |
| 板块指数历史 | 明确来源代码的行业/概念指数日 K | 与成员档案独立核验，同名跨来源板块不代表成员完全相同 |
| 研究公开资料 | 个股公告、财务、股东等材料 | 查询时间与行情观察日分开，不能充当任意历史时点资料 |

具体已验证能力显示在应用中，尚未适配或验证失败的能力不能通过手动修改标签启用。权限探测与同步均由用户明确发起，默认不开实时取数或自动日更。

Key 仅发给后端加密保存。主密钥与密文分开，不进入 Git、前端存储、普通日志或源码包。主密钥丢失后不能从源码或密文还原；迁移需要原主密钥，或在新实例重新配置来源。

## 日期与初始化

首次默认目标近五年，主行情、题材、板块 K、盘面补充分阶段执行。完整成功后不重复整库初始化，失败阶段可按任务状态补缺；新盘后增量追加尾部，保留来源 SHA 与已有发布版本。

交易日北京时间 18:00 后可以更新当日数据；之前以最近已完成日为基准。非交易日与来源尚未更新的情况以任务计划、实际返回日期和页面提示为准。公开接口不保证任意历史日期都可回补，不能用当天数据替换所选历史日期。

“五年目标”“任务处理成功”“全部板块可用”不代表每条证券、每个字段或每个历史日完整。十年个股容量测试不证明十年指数、日历或初始化来源齐全。

## 需要分开的数据

- **板块行情与成员**：有指定日指数价格时可以展示板块 K；没有该日成员档案时不填成分股历史。当前名单按真实采集日标注，不能回填到之前日期。
- **成交额与资金流**：成交额不等于净流入。主力资金是供应商按成交单大小的分类，不是真实机构账户流向；概念净流入未接入时不以概念成交额代替。
- **年内涨停次数与最近日期**：以已核验事件池、报价和覆盖范围为依据。覆盖不足显示已确认下界或未知；无标记不证明没涨停。
- **收益与价格**：年内、30 交易日收益需要足够基准和同一价格口径；图表显示前复权不等于完整股数/现金分红账户回测。
- **换手率**：需要来源真实字段或可靠股本分母，不能由成交额直接推算；缺失保留未知。
- **日、周、月**：周/月由已验日线本地聚合，策略使用完整周期；未完成周期与预热不足不生成确定信号。

## 使用与再分发

源码公开不授予供应商数据的抓取、缓存、商业使用或再分发权限；使用者仍需核对各来源的服务条款与账户授权。仓库保留适配代码和合成测试，不附真实行情数据库、原始供应商响应、个人策略或验收截图。

应用只作研究工作台，不自动下单。完整功能与限制见[实现范围与数据边界](实现范围与数据边界.md)，数据结构见[数据库与数据流](数据库与数据流.md)，备份和密钥迁移见[部署与运维](部署与运维.md)。

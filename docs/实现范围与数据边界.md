# 实现范围与数据边界

本页描述当前代码能力，不代表某一台安装的数据已经齐全。应用使用真实导入或真实请求的数据；来源未授权、缺报价、预热不足、日期不符或校验冲突时保持未知，并提供原因。离线测试中的合成样本不进入产品页面。

安装见[项目入口](../README.md)，检查方法见[交付与验收](交付与验收.md)，更新见[版本升级与回滚](版本升级与回滚.md)。

自选与策略跟踪分别保存。收藏跟踪中的个股时，保留原轮次入池日期和事件日收盘价；重复收藏不覆盖首次来源。人工从成员列表或个股页收藏、且没有原个股跟踪轮次时，事件基准保持为空。移出自选不会结束原跟踪，也不会修改题材归属。

加入后涨幅以首次加入业务日的真实原始收盘为独立基准。重复收藏不重置；缺少当日唯一有效报价，或后续公司行动无法统一价格基准时保持未知。它不代表从策略事件日起的收益，也不是包含分红到账、交易费用和实际成交的账户收益。

返回策略页恢复已保存的运行结果，并保留该次运行的版本和日期；点击“刷新选股”才按当前规则与行情重新运行。运行期间可在任务栏查看任务名称、真实阶段及已有进度；排队或尚无可核验百分比时不生成估算进度。

个股 / 板块批量执行的全选范围仅当前类型，按冻结顺序筛选并把命中自动加入各自跟踪池。命中数、成功入池、跳过和其中手工忽略分别显示；已有或已忽略轮次不重设。单项失败继续其他项，旧批次不追溯扩成自动跟踪；刷新、暂停后恢复和崩溃续跑不重复已提交步骤。单策略仍可在运行结果中手动选择入池。

## 初始化与日常更新

当前新初始化默认目标为近五年。依据是现有扶摇指数来源的实际历史窗口；十年个股存储与性能测试不能证明十年指数、交易日历和完整业务数据可得。具体支持窗口由 `/data/status` 元数据返回，旧任务按原冻结范围恢复，不自动扩大。

新初始化链依次处理主行情、题材目录与成员、全目录行业/概念历史 K、盘面补充。周/月由真实日线聚合；首次全库板块 K 采集成功后，初始入口在界面和服务端禁止重复执行。`collection_complete` 表示冻结目录中的板块均有可用缓存；`complete` 还要求没有历史报价缺口，两者不可混同。

当日盘后增量需北京时间18:00后手动创建。板块 K 增量只请求已验收尾部之后的缺少交易日，保留旧原始响应和合并依据，不每天重下近五年。来源滚动边界、板块新设或缺日仍作为覆盖限制。显式暂停/取消不自动继续；有限重试与崩溃恢复只处理原已授权任务。

行业/概念日行情、历史 K、成员、研究材料分别验证 Key 实际权限。免费接口可能变化或限流，付费档位也不构成数据完整证明；可用字段与日期以验证及同步结果为准。页面读取已验缓存不应发起来源下载，加载或补缺须明确手动创建任务。

## 历史日期与分类归属

- 盘面选择日期只影响盘面各页及其打开的历史详情。策略、跟踪、题材、研究和回测有独立业务日或区间，切换盘面日期不改业务时钟。
- 行业/概念的指数日行情与成员名单是独立能力。有该日真实指数价格时，不能因为历史成员缺失清空行情；成员家数、涨跌家数和涨停家数缺档则未知。
- `latest` 成员显示真实采集日，股票报价使用明确行情日，两天可以不同。`historical` 只读指定日已有档案，未留存时返回不可用，不借当前成员回填。
- 跨来源唯一同名行业可作明确标注的本地指数观察，不等于原来源精确成分；歧义不能按模糊名称猜测。
- 全局搜索查当前目录中的股票、指数、行业与概念；找到板块不代表已有对应日期的成员档案。

## 周期、信号与价格

个股和板块的普通条件可继承默认日/完整周/完整月，也可逐叶指定。周/月只使用最近已完成且可比的周期，并在依据中保留信号日期。日线新高、日线涨停事件、入池基准等固定日条件不因全局周期变化而变成 N 周、N 月。量能倍数按所选周期与前一可比周期计算；状态“高于均线”与事件“收盘上穿均线”分开。

技术组合可快捷添加MACD水上金叉、KDJ低位金叉和K>D状态。水上金叉同时要求前一期DIF≤DEA、当前DIF>DEA及当前DIF、DEA均>0，等于零轴不算；KDJ低位金叉要求前一期K≤D、当前K>D且当前K、D均小于所设上限（默认20，可调），等于上限不算。K>D只检查当前强弱状态，不要求当天金叉。模板展开成可编辑的标准条件，新增时逐叶固定到所选周期；历史事件内部固定日线，完整周/月条件可在事件节点外添加。预热和覆盖不足按现有三值规则保留未知，已知不满足仍可使全部满足组判为否。这些是规则定义，不代表收益效果已经验证。

BOLL收口与方向是独立参数条件，支持当期收口、首次收盘上/下突破及上/下方回轨，可与量能、MACD、KDJ组成全部/任一组。周期、总体标准差倍数、历史分位窗口、前置收口范围、中轨方向及带宽扩张可调；阈值只使用此前带宽，前置收口不包含突破当期。日/完整周/完整月与公司行动覆盖采用严格信号口径；历史事件then支持日线，where拒绝。图表显示、既有策略与已完成回测不被改写。参数与公式见[BOLL选股条件](BOLL选股条件.md)。

卖出区域的技术组合优先提供MACD死叉、KDJ死叉，以及可选水上/高位限制。死叉要求前一期快线≥慢线、当前快线<慢线，不能用“今天没有金叉”代替；MACD水上死叉还要求当期DIF、DEA均>0，KDJ高位死叉还要求当期K、D均严格大于可调下限（默认80）。K<D是持续状态。普通死叉不附带零轴或高位门槛；预热不足保持未知。新增组合保留原有卖出条件，仍按外层全部/任一关系判断。

K值可手输闭区间上下限（0–100且下限≤上限），选择单独K范围或“KDJ金叉＋K范围”。只限制当前K，不暗含D也不修改KDJ算法。低/中/高快捷填入0–20、20–80、80–100，可继续修改；20和80位于相邻闭区间，分类并非互斥。设置上限能排除高于该上限的K值，不能据此声称已经证明超买风险或收益改善。

历史事件窗口按市场交易日计算，提供近 N 日内任一天、自定义前 N—M 日、指定前 N 日三种设置；新建默认前1—30日，不含今天，两端均包含。历史事件与今日条件分别编辑：可查历史倍量、同日已核验收盘涨停或自定义事件，再组合今日涨幅、MACD/KD金叉等；事件价比较是可选条件。最近/最早匹配先绑定一个事件，今日条件失败不会另选有利事件，也不用已知事件绕过优先待核验日期。选股、跟踪、回测历史涨停共用同日来源池、身份、原始收盘与有效成交报价核验，缺源未知，不按涨幅猜测。多个节点独立绑定。新增历史事件按日线配置，事件价格比较使用观察日日 K 收盘与绑定事件的收/高/低；旧定义无周期字段时保留其既有含义。

历史事件可以组成“三倍量、收盘涨停、当日涨幅>5%任一满足”，再取前30或60个交易日中的最近一次；今日条件另设MACD或KD金叉。比较事件价支持有符号百分比偏移：今收<事件价×1.03是相对涨幅小于3%，今收≥事件价×0.97是回撤不超过3%，两者不能混为一谈。事件价与偏移阈值、实际偏离比例均留证，价格可比要求不变。

历史匹配也可显式选“范围内任意一次满足”：where内部的任一条件决定某天是否属于历史事件，match=any再判断是否存在同一天的事件、今日条件和完整价格过程全部通过。按近到远搜索，选择最近的完整满足事件留证及画线；没有完整true且存在未知时保持待核验，不能把未知计为false或把多个日期的子条件拼接。失败或未知不绑定回退事件。旧latest/earliest模式及默认值保持原样，上次金叉专用过程不接受any。

“上次金叉价比较”限定从昨日回看的最近同类日K金叉，回看长度可调；默认60日。先绑定真正最近一次，再检查期间死叉与今日再次金叉；默认另加今日收盘>上次金叉日收盘，例如60到61。上次事件不以K值、水上或价格过滤，不能跳过较近的失败金叉去寻找更老的合意金叉。今日K范围、涨幅与价格偏移都在独立今日条件中设置；周期过程本身不隐含价高。没有窗口内事件、缺数、预热或行动不可比均按事实给出未满足/待核验，不把形态筛选称为效果结论。

历史事件还可启用“事件后的价格过程”。保护价固定为事件收盘下方可调百分比，例如10元回撤5%是9.50元；检查事件后至今日全部收盘，等于算守住，破位后再涨回仍失败。可另要求事件后至昨日确实回落过，以及昨日或最近N个交易日的事后区间至少一次收盘靠近保护价。百分比价格采用未舍入十进制值判断，显示位数不改变边界。今日涨幅、MACD/KDJ仍在今日条件中设置，两者共同满足才命中；不是只因历史出现倍量就加入候选。

只要求当前收盘高于事件收盘时，在历史事件的“今日条件”添加观察日收盘价 > 事件日收盘价。该比较只看两期收盘；“今日重新收复”还要求昨日为事件后独立交易日、昨收低于参照价而今收不低于，最早在事件后第2个交易日触发。

价格过程另支持今日收盘不低于事件价（仅看今日）、昨低今收回、首次价格收复、最高价达到与实际触及。仅看今日可连续多日满足，不代表事件后每天站上；要始终守位需单独配置守位过程。最高价达到允许跳空越过，实际触及须当日高低区间包含基准；最高达到不代表收盘已站上。首次按事件后全部价格上穿计数，不因当时技术条件未满足而改称后来一次为首次。路径、事件绑定和今日条件均给出独立依据。

以上过程固定日线，适用于共享的选股、跟踪和受限样本回测；不扩展成无偏全市场收益结论。事件后的缺报、零量、重复、行动未知或未转换原价保持待核验；只有不可比点之前的明确破位等事实可以证明失败，缺口后的价格不冒充可比依据。用户未启用的旧策略不会自动增加这些约束，未重放旧结果或自动创建跟踪。

日 K 图表默认可按实际报价序列连续显示 MA/MACD/KDJ，仍披露停牌或未证明原因的缺报价区间，不插入缺日 K 线；可切换严格交易日诊断。此显示设置不改变策略、跟踪和回测的严格信号。周/月保留完整周期和缺日边界，历史长度不足时指标为空。

策略 MACD/KDJ 数值待核验时展示已有公司行动或缺报重置原因、当前连续可比根数及至少35根的要求；金叉与死叉至少36根。右侧比较字段缺失也显示其具体原因，未知根数明确未留存。说明来自现有指标元数据，不重算指标、不改变真假或预热/复权口径，不重写旧运行结果。

图表默认原价，可显式选择以观察日为锚的本地事件前复权。只有核验过的现金、送转、配股等事件才用于变换；无法确认时回退原价并说明，不叠加原价基准线到无法对齐的复权图。成交量/成交额不随价格变换伪造。图表偏好保存在浏览器，不改策略价格口径。

水平线工具仅用于个股，并按股票独立保存，可命名多条参考、支撑或压力线。未复权水平线可跨日 / 周 / 月 K 显示；前复权水平线只在图表价格口径与复权锚点相同时显示。旧参考线不自动启用提醒，手动画线不修改策略条件或触发交易。

显式启用后，可核验收盘突破压力、日内触及压力、回踩支撑收回及支撑失守。穿越或收回使用严格前一市场交易日，缺报不回退最近有价日；触及按当日高低价判断。前复权规则按已核验公司行动将固定锚价统一到判定日价格，缺少转换证据保持未知；未复权线在除权日也不直接混比前收。规则只检查启用业务日及之后已发布的日线，可补查离线交易日，不提供实时监控。

成功命中且启用自动收藏时，可以把不在自选的股票加入；失守仅作风险提醒，不自动新增自选。补跑的事件保留历史触发日，实际加入日期和独立收盘基准使用当前业务日，不冒称当时已收藏。同事件重复检查不重复收藏，容量或当前价格缺失时保存失败原因；移出自选不会停止独立划线规则，需在该线设置取消触发条件。修改规则后旧任务不能提交，历史事件仍保留当时名称、价格和核验依据。

转折与波浪显示为同一连续片段内的候选价格结构，记录确认日期；不使用形成中柱确认，不跨缺口或公司行动拼接。它不是已确定的完整艾略特浪，也不是预测或买卖指令。

个股策略新增可保存的价格口径。新建页面默认本地前复权；已有版本沿用未复权，切换后保存新版本生效。价格指标及事件价比较复用图表已有的本地事件前复权数学变换，并保持信号观察日、严格交易日和完整周/月规则；不会直接复制图上的报价连续指标。缺少可核验行动覆盖或存在冲突时保留待核验。原价量比、涨跌幅及涨停事实独立核验，不随价格复权改写。

跟踪沿用该轮入池版本的口径，同一观察日投影入池原始基准；缺同日复核证据时不把旧比较冒充当日结果。回测信号按每个历史观察日锚定，撮合仍用原价；现有权益账本未覆盖回测区间内分红送转，仍排除这些证券，复权指标不扩大收益承诺。

## 回测与尚未接入能力

个股回测有独立区间、预热、上市身份、连续报价、公司行动及字段可用性检查。部分选股字段、历史题材和涨停历史证据未达到回测要求；当前身份不能冒充逐日历史身份。已知上市日期缺失等情况可使候选集合不可用，系统不会为此生成虚构权益。

引擎按受支持范围执行次日开盘、T+1、费用、涨跌停拒单与期末持仓估值；尚非包含分红现金到账、送转股数及配股处理的完整公司行动账户。图表复权连续不代表完整复权回测。受限当前样本存在幸存者和事后样本选择偏差，回测表现不能当成无偏历史全市场结论。

回测曲线可切换累计收益率与账户权益，下方保留回撤。收益率相对报告冻结的实际初始权益，费用已反映在权益中；不以当前编辑表单或第一条普通曲线记录为本金。旧报告仅缺实际起始权益字段时才兼容自身配置按分舍入，非法或缺少本金时收益率不可用；权益为零则为−100%，缺失权益不画成零。切换图表不重新模拟，不代表策略效果已经验证。

个股策略可删除到回收站，关联的当前可见回测一并移入；恢复只恢复本次一起移入的报告。也可单独整理回测历史。已有跟踪轮次、入池基准、自选和行情保留，不因删除策略自动结束跟踪。活动任务及未释放租约阻止删除，需先明确处理任务；恢复不重跑、不改写旧报告、不重设策略版本。回收站是可恢复的可见性整理，不释放报告和输入证据的磁盘占用。

回收站可逐项明确确认永久删除，清理策略的全部版本、政策、运行、候选、跟踪和事件及关联回测。任何历史或当前跟踪证券仍在自选时，整条策略禁止永久删除；独立于收藏来源和轮次当前状态。单份回测也可永久清理，不影响策略与跟踪。唯一worker只按冻结范围解除对象自有pin、移除无共享引用的专属报告文件，保留全市场行情、自选、划线事件、任务审计、发布目录与已有备份。清理失败保留状态与文件台账，重试不扩范围；不自动压缩SQLite，不承诺清空全部磁盘占用。升级和普通浏览不触发永久清理。

真实筹码价格档、连续封单稳定度、完整盘中资金轮动、全量正式监管原文与长期历史成员档案尚未完整接入。供应商监控标签不等于交易所正式监管文件；近期公告或材料摘要不代表所有公告完整覆盖。没有来源时显示不可用，不用日 K 或演示值推造这些能力。

K线的来源范围、计算口径与已知缺口集中在可展开的“数据说明”中；个股详情合并同源重复说明。请求失败、明确阻断及各项指标的未知状态仍直接显示，折叠说明不代表数据已完整。

数据中心可手动“核验本地数据”，由唯一worker检查当前留存文件与逐股日期，并保存当前代际的小报告。已知上市范围的报价出现率只描述证券交易日机会中是否留有有效报价；无报价不直接认定为停牌或漏抓。公司行动可核验本地字段，但来源未给全市场应有总量时不展示完整百分比。联网修补前显示明确范围，重复使用既有盘面补充任务；核验本身不联网、不改变已发布快照质量。

日K与分析行情的无报价区间共用诊断报告，按连续市场交易日归并并说明影响及下一步；前后实际报价和本地原始包对照可帮助区分本地转换差异与来源尚无报价。孤立或长连续区间都不能自行认定为停牌。显式来源核验回执另行保留且不改旧行情；来源同样没有报价，也不能替代正式停复牌证据。名录总量、已上市、待上市与身份未知分别统计，人工确认保留可溯源证据，未知日期不以首根报价猜补。

待上市分类需要未来的有效来源上市日，或明确人工确认，并核验本代没有原始或分析报价记录。重复、无效或仅原始文件存在的记录也不能当作无报价，证据不足保留未知。人工说明标为用户确认，支持追加更正；它不修改来源上市日期。新行情head或人工修订后重新核验，来源日期已到达时优先按来源确认上市；日期仍缺失但已出现报价时只标“已有报价、上市日待核验”。待上市证券仍在后续增量取数范围内。

任务完成、当前范围覆盖和来源快照质量是不同维度。文件SHA通过只证明对应文件一致，报价出现率只描述已知上市范围与本地日历中的报价记录，不表示停牌已证实、缺报原因已全部解释或历史来源全集完整。比例不足100时不能因显示精度变成100；缺少应有总量时不展示完整百分比，局部100也不扩大解释为所有能力已齐。

## 个股调研增强的来源与时点

研究v2在既有财报/估值/公告/股东材料之外增加指定证券的当前主营构成、证据引用、事件线索去重与确定性技术评估。主营构成按行业、产品和地区分开，不相加为一个重复总量；未取得原披露日时只作当前取得快照。上下游客户/供应商缺证据则保留未知。尚无已授权的机构目标价、预测或媒体新闻接口；雪球与韭研公社提供外链，未抓取、缓存或交给模型。

技术评估固定原价、严格市场交易日与完整周/月；形成中周期不当确认值，缺最近应有周期不退回旧值。20/60日相对强弱按相同精确端点和可比窗口计算；转折参考位在观察时确认并按同段收盘失效规则筛选。报告冻结图与数值同源，用户后来改变偏好不能重算旧结论。所有阈值是可解释观察规则，不是已经验证的收益优势。

来源披露日不等于首次实际可见或完整修订链；v2证据均不承诺历史PIT可用，机构目标价、EPS×PE情景与技术距离不合成为上涨概率。首版没有模型调用、长期收藏或收益预测。具体字段、来源和请求预算见[研究v2契约](../contracts/research-v2.md)。

# 实现范围与数据边界

本页描述当前代码能力，不代表某一台安装的数据已经齐全。应用使用真实导入或真实请求的数据；来源未授权、缺报价、预热不足、日期不符或校验冲突时保持未知，并提供原因。离线测试中的合成样本不进入产品页面。

安装见[项目入口](../README.md)，检查方法见[交付与验收](交付与验收.md)，更新见[版本升级与回滚](版本升级与回滚.md)。

## 已实现的业务闭环

| 模块 | 能做什么 | 必须满足的边界 |
| --- | --- | --- |
| 盘面八页 | 指数与广度、情绪、行业题材、涨停梯队、涨幅榜、异动和资金观察，按日期查看 | 各模块单独显示实际数据范围；不能把主行情五年当成所有模块五年 |
| 行情图表 | 个股、四个主要指数及行业/概念日 K；本地聚合周 K、月 K；MA5/10/20/30/60/250、成交量、MACD、KDJ | 指标需要足够可比周期；缺口不画假 K 线，未完成周期不确认信号 |
| 题材库 | 多题材/行业交并集、成员行情、排序、批量增加归属、人工保留/排除及审计 | 当前研究分类不等于历史归属，人工修改不重写旧运行快照 |
| 个股策略 | 股票范围、题材、量能、均线、涨幅、涨停证据、技术交叉，嵌套全部/任一组，历史事件与当前条件 | 白名单规则求值，不执行任意代码；数据不足走三态，不把未知当否 |
| 板块策略 | 独立筛选行业/概念指数，默认及逐条件日/完整周/完整月 | 独立策略、版本、运行、候选、跟踪和事件；不接受 ST、个股涨停等专属字段 |
| 跟踪 | 默认30个市场交易日、当日/跟踪涨幅、提醒与提前结束、手动移除和历史轮次 | 提醒不自动结束；板块仅跟踪自身，展开成分不建立个股轮次或套用板块基准价 |
| 个股四项摘要 | 年内涨幅、近30交易日涨幅、年内涨停次数、最近涨停及交易日距离 | 严格截至观察日；次数不完整显示已确认下界，最近日期有缺口标“最近已确认” |
| 个股研究 | 指定标的后手动查询行情与近期材料、分项说明日期和覆盖、留存报告 | 不会全市场自动生成研究；报告行情与材料查询日期分开，缓存有独立期限 |
| 个股回测 | 独立区间与条件、七项统计、权益/回撤、交易、订单、成交和持仓 | 只运行当前引擎和来源能够支持的样本；没有板块回测或自动实盘下单 |
| 数据与运维 | 手动初始化、盘后增量、任务历史、暂停/继续/取消、数据校验、备份与独立恢复 | 一个行情写入 worker；迁移、升级和恢复需要显式操作，不承诺无停机 |

## 初始化与日常更新

当前新初始化默认目标为近五年。依据是现有扶摇指数来源的实际历史窗口；十年个股存储与性能测试不能证明十年指数、交易日历和完整业务数据可得。具体支持窗口由 `/data/status` 元数据返回，旧任务按原冻结范围恢复，不自动扩大。

新初始化链依次处理主行情、题材目录与成员、全目录行业/概念历史 K、盘面补充。周/月由真实日线聚合；首次全库板块 K 采集成功后，初始入口在界面和服务端禁止重复执行。`collection_complete` 表示冻结目录中的板块均有可用缓存；`complete` 还要求没有历史报价缺口，两者不可混同。

当日盘后增量需北京时间18:00后手动创建。板块 K 增量只请求已验收尾部之后的缺少交易日，保留旧原始响应和合并依据，不每天重下近五年。来源滚动边界、板块新设或缺日仍作为覆盖限制。显式暂停/取消不自动继续；有限重试与崩溃恢复只处理原已授权任务。

行业/概念日行情、历史 K、成员、研究材料分别验证 Key 实际权限。免费接口可能变化或限流，付费档位也不构成数据完整证明；可用字段与日期以验证及同步结果为准。页面读取已验缓存不应发起来源下载，加载或补缺须明确手动创建任务。

## 历史日期与分类归属

- 盘面选择日期只影响盘面八页及其打开的历史详情。策略、跟踪、题材、研究和回测有独立业务日或区间，切换盘面日期不改业务时钟。
- 行业/概念的指数日行情与成员名单是独立能力。有该日真实指数价格时，不能因为历史成员缺失清空行情；成员家数、涨跌家数和涨停家数缺档则未知。
- `latest` 成员显示真实采集日，股票报价使用明确行情日，两天可以不同。`historical` 只读指定日已有档案，未留存时返回不可用，不借当前成员回填。
- 跨来源唯一同名行业可作明确标注的本地指数观察，不等于原来源精确成分；歧义不能按模糊名称猜测。
- 全局搜索查当前目录中的股票、指数、行业与概念；找到板块不代表已有对应日期的成员档案。

## 周期、信号与价格

个股和板块的普通条件可继承默认日/完整周/完整月，也可逐叶指定。周/月只使用最近已完成且可比的周期，并在依据中保留信号日期。日线新高、日线涨停事件、入池基准等固定日条件不因全局周期变化而变成 N 周、N 月。量能倍数按所选周期与前一可比周期计算；状态“高于均线”与事件“收盘上穿均线”分开。

历史事件窗口按市场交易日计算，支持恰好 N 日前或过去区间、最近/最早匹配，以及独立的事件条件组。多个节点独立绑定，不用更早已知事件绕过优先待核验日期。新增历史事件按日线配置，事件价格比较使用观察日日 K 收盘与绑定事件的收/高/低；旧定义无周期字段时保留其既有含义。

日 K 图表默认可按实际报价序列连续显示 MA/MACD/KDJ，仍披露停牌或未证明原因的缺报价区间，不插入缺日 K 线；可切换严格交易日诊断。此显示设置不改变策略、跟踪和回测的严格信号。周/月保留完整周期和缺日边界，历史长度不足时指标为空。

图表默认原价，可显式选择以观察日为锚的本地事件前复权。只有核验过的现金、送转、配股等事件才用于变换；无法确认时回退原价并说明，不叠加原价基准线到无法对齐的复权图。成交量/成交额不随价格变换伪造。图表偏好保存在浏览器，不改策略价格口径。

转折与波浪显示为同一连续片段内的候选价格结构，记录确认日期；不使用形成中柱确认，不跨缺口或公司行动拼接。它不是已确定的完整艾略特浪，也不是预测或买卖指令。

## 涨跌停、收益与资金

| 信息 | 正确解释 |
| --- | --- |
| 收盘涨跌停标记 | 仅显示经来源与原价核验的正事件；无标记不证明当日未涨跌停。周/月显示周期内具体日事件，不称整根周/月柱涨停 |
| 年内涨停次数 | 当年截至观察日的已留存收盘事件；精确完整数与已确认下界分开。观测0且覆盖不足不能显示0次 |
| 最近涨停 | 后缀状态覆盖完整才称最近；有缺口只显示最近已确认，距离按市场交易日计算 |
| 年内 / 30交易日涨幅 | 核验的历史端点和公司行动连续价格口径；不是未来收益、当前题材历史表现或含现金分红到账的账户回报 |
| 连板 / 反包 / 晋级失败 / 20cm | 按已确认日事件、前序交易日和制度证据分类；未知不算否，价格表现标签不等于主观强弱评级 |
| 封单金额 | 收盘快照可比规模；单点金额不能证明全天“最稳”。连续稳定度需多时点盘口 |
| 行业主力净流入 | 供应商按成交单分类的日级指标，不等于机构账户真实净买入；近期跨日趋势不等于全天盘中轮动 |
| 概念行情观察 | 可展示真实指数涨幅与成交额；尚未接入概念净流入时明确说明，不能用成交额替代 |

## 回测与尚未接入能力

个股回测有独立区间、预热、上市身份、连续报价、公司行动及字段可用性检查。部分选股字段、历史题材和涨停历史证据未达到回测要求；当前身份不能冒充逐日历史身份。已知上市日期缺失等情况可使候选集合不可用，系统不会为此生成虚构权益。

引擎按受支持范围执行次日开盘、T+1、费用、涨跌停拒单与期末持仓估值；尚非包含分红现金到账、送转股数及配股处理的完整公司行动账户。图表复权连续不代表完整复权回测。受限当前样本存在幸存者和事后样本选择偏差，回测表现不能当成无偏历史全市场结论。

真实筹码价格档、连续封单稳定度、完整盘中资金轮动、全量正式监管原文与长期历史成员档案尚未完整接入。供应商监控标签不等于交易所正式监管文件；近期公告或材料摘要不代表所有公告完整覆盖。没有来源时显示不可用，不用日 K 或演示值推造这些能力。

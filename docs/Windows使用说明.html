从解压到第一次看到行情

这份手册可以离线打开。授权在本机核验，验证或更新外部行情、调用 AI 模型时需要网络。

  1. 完整解压并启动。 在 Windows 11 x64 的本机磁盘新建目录，把 ZIP 整包解压，双击 AMR-Desktop-Preview.exe。应用会用默认浏览器打开本机工作台。蓝紫色图标可能在任务栏右下角的隐藏图标「∧」里，悬停时显示「冒险的梦想家」。
  2. 激活工作台。 授权页可以复制机器码。拿到为该机器码签发的 .amr-license 后选择文件并导入。激活后可点「打开工作台」。以后可从右上角「授权管理」查看到期时间、导入新卡。同一 Windows 用户且本地授权身份保留时，已激活的有效卡可沿用。
  3. 先确认是否导入旧数据。 新装会打开空工作台。如果这台电脑有首版或旧托盘版数据，先从旧版退出并等任务收尾，再在新版首次启动提示中选择导入。系统先做备份并核验独立恢复副本，再启用新版数据目录。两份旧数据都在时优先取上一版托盘数据。导入后的排队任务保持暂停，自动计划需按需重新开启。
  4. 配置扶摇并验证。 左侧「数据源」→「行情数据源」→ 扶摇「配置」。填自己的 API Key，开启「启用此数据源」和「设为当前来源」，点击「保存配置」，再点「验证能力」。看日 K、指数、日历、批量等本次实际核验结果。也可从数据中心点「配置数据源」。
  5. 手动首次初始化。 进入「数据中心」的「首次初始化」卡片，确认同步来源和目标范围，提交后查看「当前任务」。等待主行情发布及题材、板块 K 和盘面补充的后续阶段。初始化可能较久，时间取决于网络、权限和覆盖范围。详见首次初始化。
  6. 看一份已发布交易日。 先确认数据中心的「当前业务日」与「数据覆盖」，再打开「盘面总览」看当日结构，点一只股票检查 K 线。随后可按需设置自动采集计划和AI 模型。模型未配置时，可以先使用行情、图表和本地研究功能。
网页与后台是两件事

关闭网页后，本机任务继续运行。双击托盘图标、右键「打开工作台」或再次双击 EXE 可以重开。正式退出用托盘「退出工作台」，等待正在执行的任务收尾。找不到图标时，可在解压目录的 PowerShell 运行 .\AMR-Desktop-Preview.exe --quit。电脑关机、休眠或工作台退出时，后台无法在时窗内采集。

授权、数据目录和升级

  • 授权离线核验。 签发时已经确定截止时间，导入有效的新卡后以新卡的签名截止时间为准。同一文件重导沿用其截止时间。到期后可进入授权管理并导入新卡，已开始的任务按规则收尾。机器码随本地 Windows 用户身份保存，系统重装或清理该用户的应用数据可能需要补发。
  • 程序与业务数据分开。 解压目录装的是程序。业务库、已发布文件、研究记录等在当前 Windows 用户的 %LOCALAPPDATA%\ad-market-review\workbench-tray-native-v1 下，以验签指纹再分目录。授权使用独立的 license-preview-v1。凭据密文与主密钥分开保存，迁移时需要保留原主密钥，或在新实例重新配置 Key。
  • 升级先保留旧数据。 先正常退出旧版，保留旧程序和原数据，再解压新版本到新目录。以迁移提示、核验结果和恢复回执为准。首次启动已经选择新库时，旧数据导入需另建独立恢复目录。
  • 启动诊断。 在解压目录运行 .\AMR-Desktop-Preview.exe --diagnose，在临时空库检查 API、前端、独立 worker、备份恢复、DPAPI 及原生扩展加载。结果窗口中 api、frontend、worker_once、backup_restore 应为 ok。

数据源 · AI 模型

模型负责把用户明确选择的材料和问题组织成分析文字。它与行情库的初始化、指标计算和策略判定是不同环节。入口是「数据源」→「AI 模型」，或在「AI 助手」点「模型设置」。

  1. 在 OpenAI 或 DeepSeek 卡片点「配置」，填自己账户的官方 API Key，选择模型。模型 ID 以页面可选项与账户实际验证为准。
  2. 展开「费用与限制」，按需设置每日预算（美元）、每日付费请求上限和单次等待上限。两家服务共用本实例预算，验证请求也计入用量，实际账单以供应商为准。
  3. 点「保存并验证」，或先「仅保存」再点「验证所选模型」。查看账号与模型目录、所选模型调用等结果，通过后点「启用 AI」。更换 Key、模型或等待上限后重新验证，再启用。
  4. 回到 AI 助手或相应研究入口，查看要发送的内容、数据范围和费用提示，再确认请求。AI 解读应结合来源证据复核。关闭 AI 或清除 Key 后，可查看已保留的本地历史。

数据中心 · 怎样理解数据模型

「数据中心」管的是本机有什么数据、更新到了哪天、任务做到哪步。OpenAI、DeepSeek 等推理模型在数据源 → AI 模型配置。数据中心的覆盖数字描述实际留存。

数据中心 · 首次初始化

  1. 先启用扶摇并设为当前来源，核对「同步来源」显示已配置。打开「首次初始化」，核对窗口和页面显示的目标范围，再提交。
  2. 新安装默认目标近五年。流程依次衔接主行情 → 题材目录 → 行业与概念历史 K 线 → 目标日盘面补充。行情、指数、日历和各字段的真实范围逐项核验。
  3. 在「当前任务」查看状态、目标日、阶段、批次和结果与缺口。主行情发布后，后续步骤仍可能在排队或核验。用「同步历史」点开任务查看日志和失败原因。
  4. 主行情发布后转入日常增量。失败阶段可按原任务状态或对应补充卡片处理。已有主行情、缺行业和概念历史 K 的安装，可以独立补齐板块全库。待全部冻结目录已验收后，后续走板块尾部增量。来源历史边界的部分覆盖单独显示。

数据中心 · 手动盘后增量和盘面补充

主行情初始化完成后，交易日北京时间 17:00 起以页面显示的实际窗口为准，点「开始盘后增量」。增量更新主行情、板块 K 线尾部和目标日盘面补充。已授权的后续选股、跟踪核对、划线提醒等按实际任务设置执行。主行情达到 100% 以后，继续看整条任务链。

工作台进度窗锁定业务操作，整链结束后看各阶段的状态和警告，再点「确认结果，继续使用」。同日主行情已更新时，页面会提示。需要补封板、板块日行情或年内事件覆盖时，用「盘面补充」的「修补盘面缺口」或原失败步骤，先核对目标日和数据范围。

盘后复盘与盘后增量沿用同一数据链。已有同日有效午评和所需收盘证据时，可生成午评页的「收盘回看」。两处用途不同，盘后行情用于确认收盘事实，收盘回看用于对照午间观察。

数据中心 · 覆盖、缺口、任务与常见排查

  1. 先定位日期。 对照行情页观察日、数据中心当前业务日和具体模块的覆盖日。午评、竞价、盘中、板块成员等各自有留存记录，可能和主行情日期不同。
  2. 看「数据覆盖」。 对比每个数据集的真实起止日期、覆盖、记录数和缺口。应有总量未知时，比例也可能未知。「部分覆盖」表示有可用内容并列明缺口。明确有证据的零与缺报是两种结果。
  3. 先做本地核验。 点「核验本地数据」检查本地文件与报价结构。查看「缺口处理计划」、上市身份与核验依据。需要外部证据时再选择「向来源核验报价缺口」，核对范围后提交。权限、停牌、未上市、来源边界、坏文件与网络失败应分别处理。
  4. 再决定是否修补。 目标日盘面缺口用「盘面补充」，板块历史缺档看行业与概念历史 K 线的核验记录，已发布主行情的日常补齐走盘后增量。未留存的盘中快照或历史名单保持未知，后续行情和当前名单各自按实际日期使用。
  5. 看「同步历史」。 点任务编号可回看状态、进度、目标日、接受记录、日志和缺口。勾「包括策略、回测与研究后台任务」可一并检查这些任务。遇到临时断网或状态待确认，先刷新任务和核对已受理记录，再按页面给出的操作处理。

盘面研究

先看页面标注的观察日、实际行情日和来源，再比较涨跌、成交额、板块及个股。盘面各页共用手动选择的观察日，切换到策略、跟踪等页面后再回来，原选择仍会保留。点击「回到今天」或「回到最新」退出历史回看。默认浏览时，竞价和午评优先显示当天，盘后类页面优先使用最新已发布的交易日。盘中可能同时看到今天的时点快照和上一交易日的正式日线。

「—」「待核验」「未留存」表示证据不足或资料缺档，只有来源核实为零才显示 0。看一项排行或统计时，一并看样本范围、有效家数、比较日期和单位。成交额衡量成交活跃程度，净买额或净流入须另有对应的买卖口径。

盘面总览

用于从全局检查当日盘面，再找值得展开核对的指数、方向和股票。

  1. 先确认日期和覆盖。「最近发布」说明本机已发布到哪一日。「沪深京总成交额」汇总对应范围股票的实际成交额，对比上一市场交易日的同口径增减。涨停、跌停与炸板读取当日事件池。炸板池家数按股票计，个股开板次数则描述同一只股票的开板记录。
  2. 看指数与市场广度。点指数卡切换下方 K 线，核对指数价格、涨跌幅及自身成交额。广度查看上涨、下跌和平盘在有效样本中的分布。若指数上涨但上涨家数偏少，可以继续核对上涨是否集中在部分权重或题材。
  3. 看昨日接力和今日活跃。「连板反馈概览」对照上一交易日已核验的首板或连板样本今天表现，按昨日高度分组。成交额前 10 看当日交易活跃度，「近7日活跃」看这些股票在最近 7 个市场交易日进入同口径成交额前 10 的次数。展开可核对具体日期、名次和金额。
  4. 看异常活跃和封板线索。「炸板池前五」默认按开板次数、成交额排序。「封单资金前五 · 收盘快照」按单次留存封单金额排序，只反映快照时点。点击表头只重排已入选样本。对单只股票有疑问时，点名称看图，再到市场情绪看完整的连板反馈与炸板结构。

盘前竞价

把严格前一交易日已保存的判断与今天的竞价终态并排，核对昨日关注、高位股、涨停或炸板样本开盘前是延续、修复还是走弱。

  1. 提前开启采集。在「数据中心 → 自动采集计划」开启并保存「自动盘前竞价」。在核验为交易日且本机服务运行时，约 09:25:30 起自动采集，09:30 前截止。页面读取已保存结果，历史竞价以当时留存为准。需要扩大观察时可开启「今日竞价发现」，将发现结果和原观察单分开阅读。
  2. 看「强弱对照」和「竞价观察单」。首批冻结最多 100 只去重候选。看竞价价、涨幅、竞价额、来源量比及报价覆盖，再按昨日板高、上市板别或行业概念定位股票。昨日板高是上一交易日事实。昨日炸板后高开属于修复观察，昨日涨停后低开属于转弱观察。一字涨停开使用已核验报价与参考价核对，结论限于本次开盘参考。
  3. 用「题材共振」确认集中程度。查看竞价前列命中数、样本均幅、中位数及高开占比。集中倍数大于 1，表示该组进入竞价前列的比例高于整份候选的前列比例。点行业或概念查看实际入组股票，原成员档案日期与竞价日分别展示。
  4. 盘后复核。同日正式收盘发布后展开「盘后核对」，必要时点「读取盘后结果」。按早上的原分组看竞价均幅、收盘均幅和竞价至收盘价差。收盘涨幅以相应前收为基准，竞价后价格变化以竞价价为基准。覆盖不足或开盘价无法对账时，按待核验处理。

「AI 解读当前时点」会把所选日期和阶段带到 AI 助手。先看实际报价和来源范围，再发出需要整理的问题。错过采集窗口时，当天历史终态需以已有快照为准。

盘中观察

比较同一交易日已留存的时点，回答哪些方向在变强或回落、量能是否变化、哪些股票新增封板或出现开板。

  1. 选时点。从 09:35、09:45、10:00、10:30、11:00、13:30、14:00、14:30 的盘中时点，以及午评和收盘档中选择已留存项。自动采集在「数据中心」设置。需要手动取数时，在当前允许窗口点「采集当前时段」，手动和自动共用该交易日该时段的名额。竞价终态在独立页面查看，也可进入累计简报。历史旧档可能没有某些时段。
  2. 先看指数、广度和量能。「同档累计」比较两天同一档的累计成交额，「同段新增」需要两天都具备对应的起止端点。比较股票样本时，以两档都有可核验报价的同一组股票为准。「部分留存」提示仍有报价或来源缺项，点开时点说明查看具体范围。
  3. 从「盘中方向」穿透到个股。切换行业或概念、板块强度、封板家数、宽口径概念等视角，也可在「盘中发现」看由弱转强、涨幅扩大、走弱回落和当前领涨。板块强度综合指数方向、可比成员的上涨比例、中位涨幅和覆盖。选左侧方向查看右侧成员，再按上市板别、走强、封板或炸板筛选。超过 200 只成员的宽口径概念单列观察。
  4. 看变化的具体证据。「题材轮动」查看各时点的板块涨幅与封板家数。「较上一档变化」用可比涨幅计算百分点差。「本段板况变化」对照所选档与相邻上一档，查看可核验的新增封板、新增跌停、新增炸板、封板打开或炸板回封。点卡片看股票，回封与新增封板可能重叠，分别阅读各类家数。
  5. 看累计简报和收盘对照。简报汇总从竞价到所选时点的留存线索，简报内部切时段只定位文字。正式收盘发布后可在收盘档核对，盘中表格仍保留原时点数字。点股票通常优先展示所选日已发布的正式 K 线。收盘尚未发布且时点价格可对账时，日图会加临时柱。

行情和板况先由采集结果核验，AI 简报和「AI 解读当前时点」用于整理已有事实。缺上一档、成员覆盖不足或前收口径变了，先以页面给出的比较范围为准。

午评快照

记录本交易日午休窗口取得的行情，分开看午间事实、昨日计划和同日收盘结果。配置行情来源并完成初始化后，可在交易日 11:31 至 13:00 前点「手动采集午评」，或提前保存自动午评计划。首次提交后到任务记录看进度和结果。历史日期以已留存快照为准。

  • 「午间总览」依次看四个基准指数、午间广度与成交额、午间情绪温度、昨日接力、今日梯队和主线方向。温度是午间规则读数，展开可看广度、封板样本、涨跌停对比、昨日强势样本反馈和四指数支持等分项。必要分项缺失时显示「暂不评分」。指数金额优先与严格前一交易日的可比午评对照。
  • 「昨日复盘对照」查看前一交易日采集前已经保存的原判断、逐股关注及本次报价。若只留存了昨日收盘事实，可以看样本反馈并保留原判断缺失。用「我的午后观察」保存自己的文字，后续按同一批对象核对。
  • 「收盘回看」在同日正式收盘数据发布并完成核验后查看。对照午间封板收盘仍封、午间炸板收盘回封、午间未封收盘涨停、午间封板收盘未封，先看核验范围再点开股票。「午后涨跌幅」是收盘价相对午间价的变化，两个日涨幅相减得到的是百分点差。

在「来源说明」核对采集区间和分页覆盖。午间报价代表本份快照，盘后回看比较两个有据时点。午评和收盘回看按 28 个自然日的保留规则清理，缺档、失败、过窗和已清理各有状态。

指数行情

查看上证指数、深证成指、创业板指、科创 50 的点位、涨跌幅与成交额，核对同一天不同市场指数是否同向。点上方指数卡切换下方 K 线。先看实际报价日期和指数代码，再用日、周或月视角核对趋势、波动与均线位置。历史区间受本机留存限制，指标也受连续周期和预热数据影响。

指数卡的放量或缩量来自该指数与严格上一市场交易日可比成交额的差值。不同指数所含证券可以重叠，市场总成交额请以盘面总览的股票汇总为准。若主要指数表现分化，可进一步到「市场情绪」对照广度与接力反馈。

市场情绪

把市场环境拆成广度、指数和短线接力三条证据线，便于解释「指数不错但个股分化」或「涨停样本强但覆盖不足」这样的盘面。

  • 广度与阶段。沪深广度温度按上涨股票占有效上涨、下跌、平盘样本的比例计算。上方读数看观察日和前一交易日变化，走势可悬停核对历史日期。冰点、修复、退潮、高潮、普涨、混沌和分化是项目依据当日事实给出的阶段标签。出现「待核验」时，展开范围与缺口。
  • 指数环境。逐一看指数相对 MA20 位置、近 20 日涨幅和波动，再判断指数与广度是否相互支持。四个指数分别解释。
  • 短线接力和炸板反馈。看昨日已确认涨停队列今天的涨跌、均幅和有效样本数。可切换普通 10% 等前日已核验制度分组。价格反馈看可比报价，晋级另核验今日事件和制度。炸板结构可看当日分布、近 7 个交易日及昨日炸板样本今天的表现，先核对同源覆盖。
  • 下一交易日计划。开仓、加仓及抄底分别列准备状态、需要确认的条件及失效条件。「候选跟踪」核对指数参照和后续变化。题材与个股观察名单可以作为复查对象，计划只在页面展示，需要自己核对实际条件。
  • 保存这次复盘。到「来源与留存」点「留存本次复盘」，保存当时所用输入、规则结果和实际保存时间。相同输入重复保存会沿用已有记录。用「查看留存」读原记录。现在回看旧日行情时，以证据已有的范围和实际保存时间理解原结论。

行业与概念

从板块指数表现切入，再看成分股的真实分布，区分「指数涨」与「很多成员一起涨」。

  1. 切换行业或概念，必要时选来源或行业层级，再选「全部行情」「上涨榜」「下跌榜」「成交额榜」「涨停活跃」「炸板分布」或「持续活跃」。按名称或代码找方向，点表头重排当前范围。
  2. 点板块名称打开板块 K 线。点同一行其他位置展开右侧成分股。成分股可按主板、创业板、科创板或北交所筛选，打开右侧「完整指标」查看更多个股字段，点股票名称看个股图表。左侧榜单的「完整列」用于查看较多板块指标。
  3. 分别核对板块行情日期、成员档案日期与成员报价覆盖。板块自身指数日行情和历史成员分别留存，有板块报价时即使成员缺档，指数行情仍可查看。需要看当前研究名单时，可在提供该入口的成员视图显式切换「当前最新成员」，以界面列出的当前日期为准。

成交额榜看交易活跃程度。「样本上涨比」以已观察到有效报价的成员为分母。「涨停活跃」和「炸板分布」看已确认事件家数与覆盖。「持续活跃」分别统计近 7 个市场交易日上涨前 10 和成交额前 10 的本地出现次数。历史未留存时，以已观察日期及次数为准。相同名称的异源板块按来源代码与层级分别比较。

涨停梯队

查看同日已确认涨停股的高度、板型、分类关联和来源线索。先展开「覆盖与来源」，再使用名称、代码或题材筛选。

  • 「连板梯队」按连续高度查看首板、二板及更高分组。个股卡可看首次封板时间、开板记录、涨幅、换手、成交额和来源原因，缺项以「—」显示。板高描述连续涨停高度，封板时点及开板记录单独解释。反包候选使用 T 日涨停、T-1 确认非涨停及 T-2 涨停的事件条件。晋级失败表示昨涨停样本今天已确认未收盘涨停，实际收盘方向另看涨跌幅。20cm 分组要求有当日制度核验证据。
  • 「概念关联」点上方概念数量可筛出关联股票，再点同一项可取消。关联家数与下方浏览分组的独占家数口径不同。同一股票可关联多个概念，比较时分别读各组。
  • 「当日主线」先看独立的高标观察，再看重点方向、其他方向和事件线索，最后读个股来源原文。系统按同日确认涨停及留存的来源原因归类，资料不足时保留缺口。重点方向是供复盘查证的候选归类，真正驱动因素需结合其他证据。

龙虎榜

核对所选交易日上榜股票的买卖结构、披露原因和席位。切换「全部榜」「机构榜」「游资榜」，再选「单日榜」或「三日榜」。机构净额来自机构榜口径，游资标签来自来源分类。同股多标签或两个披露区间分别查看。

  1. 搜索名称或代码、点表头排序，也可在游资榜点标签筛选。再点同一标签取消筛选。表头先对当前完整筛选结果排序，再分页。
  2. 点股票名称看 K 线，点行内其他位置展开「买方席位前五」与「卖方席位前五」。同日多次披露时先选对应原因。看席位全名及其买入、卖出、净额和单位。匿名同名席位按披露行保留，双向上榜时以对应披露记录为准。
  3. 历史缺档时先看「来源与30日留存」。在最新行情日可手动「补齐最近30个交易日」，随后到数据中心看进度。完成后按近 30 个市场交易日滚动留存，单日窗口的缺口与来源核验为空分开显示。

龙虎榜金额描述已披露范围内的交易，分析席位时保留区间、原因和来源，账户身份以能取得的正式证据为准。

30日涨幅榜

用于发现所选日前一段时间走势较强的证券，也能检查某只股票为何未进入排名。近 30 日按市场交易日计，比较观察日与向前第 30 个市场交易日的可比价格。存在已核验的全天停牌时，页面可能按规则使用停牌前的实际成交收盘价，并标出实际取价日。

  1. 默认看前 100，可切前 200、300、500、1000 或「全市场」。输入股票名称、题材或代码时可查全市场，包含未排名证券。选「未排名」查看价格端点缺报、复权依据不足等原因。
  2. 先看近 30 日涨幅，再核对实际起止报价日、观察日当日涨跌和区间缺报价提示。点股票名称开图，用相同观察日复查走势。
  3. 分类分布以原始排名前 1000 的实际样本为基础，按分类显示方向和样本占比。同股可有多个标签。若页面标明「最新行业概念参考」，分类标签可来自日期较晚的成员档案，价格涨幅仍使用原行情日期。回看历史时按该历史日期的可核验归属阅读。

异动与监管

用于核对来源提供的严重异动或重点监控标签。默认「最新名单」显示本机最近留存的名单，查看过去某一天时切换「指定盘面日历史名单」。注意工具栏的「名单日期」与「行情日期」可能不同。

按名称、代码或监控标签筛选。点股票查看标注行情日的图表，展开「来源与日期说明」核对名单获取时间、来源和覆盖。刷新只重读存档。「名单未知」表示所选日证据不足。区间起止来自供应商标签，正式监管及解除日期须以可核验的官方原文为准。

自定义研究

先明确研究对象与日期。想整理行业概念用「题材库」，想让条件筛出候选用「策略管理」，想记录候选之后的变化用「策略跟踪」。单纯收藏股票和核验手画价位用「我的自选」。这些页面各自使用当前已发布业务行情日或其报告日期，盘面顶部的历史日期不会改写这些记录。

题材库

用来查看和维护本机的行业、概念、人工研究题材，以及它们和股票之间的关系。若本机已经有成员档案，点「登记本地题材」即可登记。「同步新增题材」对照来源目录补采本机尚未留存的新增分类成员，到数据中心查看任务和覆盖。「新增题材」可填写名称、别名和定义说明。

  1. 在左侧目录搜索题材、行业或别名，选择一个或多个分类。右侧「题材与行业联合查股」可以看并集或交集。并集要求属于其中至少一个分类，交集要求同时属于所选分类。
  2. 用上市板块或股票名称、代码缩小范围。点股票名称看该股 K 线，结合成员关系日期、行情日、涨幅和最近已确认涨停判断这个成员是否值得继续研究。成员身份未知与当日报价缺失分别查看。
  3. 单选一个分类后可维护成员、编辑或查看变更记录。来源分类可以人工加入或排除指定股票，之后可「撤销人工修改」恢复按来源判断。其他分类仍有独立的归属。也可在个股详情的「行业 / 题材」处点「补充题材」。

题材维护从当前业务日生效。当前成员关系适合建研究名单，判断历史那天属于哪个题材要看当时已保存的关系。当前的标签只能说明归属，也需要独立证据才能解释涨停原因或实际经营关联。

策略管理

把研究假设写成可重复的筛选条件。个股策略产出股票候选，行业 / 概念策略产出板块指数候选。两者各有运行记录、判定依据和跟踪池。首次筛选前，先完成所需的行情初始化，确认最新业务日已发布。

从个股规则到候选

  1. 切到「个股策略」，点「新建策略」。填写名称，选择「判断周期」和「技术指标价格口径」。周线和月线条件使用已完成周期。新建个股策略默认本地前复权，结果会同时显示本次规则口径和单只股票实际可用口径。
  2. 在「股票范围」设置所需市场或题材，按需启用「近期热点题材 / 行业」。热点使用近窗已核验的收盘涨停股票日数及当前分类成员，适合缩小当前研究范围。打开「本次热点范围」可看本轮排名、来源和缺口。使用该范围的策略在本版无法做历史回测。
  3. 在「选股条件」选择「全部满足」或「任一满足」，添加字段、比较方式和阈值。可给每项单独选日线、完整周线或完整月线。通过「快捷添加条件」选择模板后，还要点「加入条件」。例如把「日线收盘价高于 MA30」和「成交量大于前一周期」放进同一全部满足组。要找刚发生的事件时，选「收盘上穿 MA30」等信号字段。历史涨停、交易日窗口等日线专属字段按日线核验。
  4. 需要比较某个历史事件与当下条件时，添加「历史出现过＋今日满足」，设历史窗口、匹配方式、事件条件和今日条件。事件收盘、最高和最低是不同参照价。若启用守位或收复，展开命中依据复核实际绑定的事件日和价格。查看图表时可以定位该事件。
  5. 设置默认跟踪期限后点「保存策略」，回到策略详情点「运行选股」。同一业务日、相同规则和有效输入已有结果时，按钮会变为「查看今日结果」。规则修改后保存为新版本，旧结果继续按原记录读取。
  6. 在「运行结果」分别查看「满足」「待核验」「未满足」。展开「命中依据」，确认实际信号日、量能、价格口径和缺失原因。比如三倍量比较的是所选周期与前一可比周期的成交量，缺报价或前期为零时看待核验。由信号结果判断是否满足条件，由真实交易记录判断是否成交。
  7. 在「满足」中勾选候选或点「全选命中」，再点「加入跟踪」。批量操作中「执行所选并跟踪」和「一键执行并跟踪」会授权新运行的命中加入各自策略跟踪池，只读取已保存结果时按界面提示处理，已有轮次和手动忽略的股票会跳过。仅想核对选股时，走单策略「运行选股」并查看结果。

板块策略与盘后衔接

切到「行业 / 概念策略」，点「新建板块策略」，选择目标分类、日周月周期及板块指数适用的价格、量能或技术条件，点「保存板块策略」。用「运行板块筛选」读取已留存的板块 K 线，在满足项中勾选后点「加入板块跟踪」。新高窗口按市场交易日，缺报价或预热不足的结果为待核验。这个入口的对象是指数自身，个股涨停、ST 和上市板块条件用个股策略。

个股策略卡片还有「同步后执行」。如果希望盘后增量完成后重新筛选，打开对应开关，按需另选「命中新股自动加入此策略跟踪池」并「保存设置」。这是策略的盘后计算设置，数据采集计划在数据中心设置。若要模拟买卖，使用策略编辑器的买卖条件和策略回测。

策略跟踪

用来观察已入池对象后来发生了什么。先选「个股跟踪池」或「行业 / 概念跟踪池」，再按策略过滤。在「跟踪中」查看观察进度和基准，在「触发提醒」查日期与命中条件，在「结束历史」看提前结束、期限结束或手动移出的轮次。

  1. 从策略管理加入命中后，核对入池业务日与该轮价格基准。跟踪日从入池第 0 日起算，停牌日计入市场交易日，报价缺口单独披露。重复命中保留原入池基准。若规则命中了历史事件，详情可分别看入池基准、事件日收盘与高低价，三者在不同规则里起不同作用。
  2. 在个股行点「提醒与结束条件」，分别设置跟踪期限、提醒规则和提前结束规则。例如把 MACD 金叉设作提醒，触发后仍可观察。如需在收盘跌破该轮事件日最低价后结束，单独添加相应的提前结束条件。两类条件各有判断逻辑，可展开记录检查判定使用的日期、价格口径和数值。改默认政策时，可选择同步到仍沿用默认政策的当前轮次。
  3. 点「核对至当前行情日」用已发布行情核验个股轮次，板块页用「复核板块跟踪」。成功的盘后增量也可衔接相应核对。没有新行情时先检查数据日期，到了期限仍标待核对时再看核对任务。数据不可比的价格条件保留待核验。
  4. 手动移出后可在「结束历史」查看冻结记录，后续确需再次入池时可解除忽略。打开行业或概念的成分股属于浏览，板块的跟踪规则和事件价格只用于板块本身。

策略提醒用于已入池对象的条件判断。只想对一只股票的自画价位设提醒，用下面的「我的自选 → 划线提醒」。两类记录分开保存。

我的自选

通过个股详情、股票列表或跟踪页的星标收藏股票。在「自选股票」搜索代码、名称、策略来源或行业题材，核对当日、近 30 个交易日、年内表现和加入后涨幅。加入后涨幅按独立的首次加入业务日收盘基准统计，来自策略的股票可另查原轮次的事件价。两类基准的起点可能不同。

设置和检查划线提醒

  1. 打开个股 K 线详情，在划线工具中选择支撑线或压力线，输入线价并勾选提醒条件，点「保存划线」。压力线可观察从前一交易日未站上到当日收盘严格站上，或当日日线高低价覆盖线价。支撑线可观察回踩后收盘不低于支撑，或收盘跌破支撑的风险记录。参考线适合只标记观察价。
  2. 按需勾选成功触发后自动加入自选。收盘失守作为风险事件记录。已经收藏的对象保留原加入基准。想停用时在该线取消提醒条件并保存，移出自选只处理收藏记录。
  3. 回到「我的自选」点「检查划线提醒」，用最新已发布日线核对。查看「划线提醒」里的「今日」和「历史」，点击详情看触发日、前收、高低价、收盘、线价及核验依据。顶部铃铛预览当前业务日已保存提醒，历史筛选只查已有记录。

这里的「日内触及」由发布后的日线最高价和最低价核验。提醒走工作台铃铛和记录列表。未触发的线持续核验，首次触发后继续 60 个市场交易日，超期随相应盘后增量清理划线及其关联记录。

生肖跟踪

维护你自己的年度生肖观察池。先选「观察年度」，核对页面同时显示的观察池年份和对应生肖年，再点「添加股票」搜索本地 A 股，或「批量添加」核对名称、代码和重复项后提交。可记录关联类型、加入理由、依据链接和重点关注。这里的关联来自你的研究记录，行业和概念仍由各自的有效目录显示。

「观察中」看池内整体涨跌、涨幅中位数和覆盖，再按年内涨幅、近 30 个交易日涨幅、年内涨停次数、最近确认涨停等字段筛选。点击股票可查看 K 线，详情可查加入日基准、加入后涨幅、技术周期、来源和变更记录。年内统计取行情截止日所在公历年，观察池年份和对应生肖年用于组织名单。

点「编辑」更新理由或重点，点「移出」可在「已移出历史」保留本轮。用「重新加入」建立新轮次。若详情提示缺失基准，可点「重新核验缺失基准」，按原基准日读取可用的本地证据。每年默认观察年度会切换，旧池可手动切回。

个股研究

  1. 在「个股研究」用名称、代码、拼音或首字母搜索，选定准确标的。只想看图，可打开行情详情。要生成含材料和来源的报告时，点「运行研究」，通过任务进度查看各环节。
  2. 报告中按区块看业务及主营构成、财务、估值、公告与事件线索、技术走势和风险或证据缺口。主营构成的行业、产品、地区是不同维度。比较业绩时先对齐报告期和单位，解释走势时看报告冻结的实际行情截止日。
  3. 展开「材料与来源索引」核对披露时间、采集时间与报告期，按需查看原材料。在「研究历史」打开已留存报告，主动打开后按界面说明留存 7 天。若要重新获取可用材料，点「重新调研」。要让模型解释报告或继续追问，从该股的「问AI」进入。

公告、财务及其他材料按可用来源取得，查询时间和当时可获得的历史资料需要分别核验。缺资料时看报告中的来源和缺口说明。

AI 助手

用于围绕工作台已有的盘面、行情和个股研究做解释与追问。从导航直接打开，或在盘面、个股研究点「问AI」，带入当前日期、时点或股票。未配置时点「前往模型设置」，在「数据源 → AI 模型」为所选服务填写凭据和模型，保存、验证后手动启用。验证和生成都可能消耗供应商额度。

  1. 在输入框写清楚对象、日期和问题，检查预填的股票、报告或时点。比如「按所选交易日对比午评和收盘，哪些方向延续，缺哪份快照？」或「这只股票近 30 根日 K 的量价特征是什么？」点击发送才提交任务。
  2. 先看回答中的数据来源、日期、样本范围和已核验依据，再回到对应页面对照。只在所选模型具备联网能力且有可用来源时才可能进行补充搜索。精确历史统计以已存事实为准。「未到时点」「未采集」「未知」「本轮未读取」分别代表不同状态。
  3. 可在输入框用回形针添加支持的文件，或拖入文件、粘贴图片。发送前核对附件，图片需要支持看图的模型，文档文字提取受页数、大小及格式限制。离开页面后可从历史继续看任务，需中止时用停止按钮。切换模型配置时按界面提示开启新会话，旧会话继续可读。

回答可能省略部分明细，费用状态和回答完成状态独立。重要数字、因果和下一交易日条件建议回查原材料，模型回答不能替代原始数据核验。

策略回测

在指定历史区间，用支持的个股策略跑一次独立模拟账户。回测先核验策略字段、预热长度、日期、报价、证券身份和公司行动覆盖。在「回测配置」选择策略，等可用区间核验后再选起止交易日。当前范围无法核验时先看页面原因，例如当前热点成员缺少历史依据。

  1. 在策略管理保存买入与卖出条件，回到回测页面打开「交易与费用参数」，设置初始资金、持仓数、仓位、持有期限、收盘止盈止损、佣金、卖出税费、滑点等本次模拟参数。核对当前策略版本和价格口径后点「运行回测」。
  2. 任务完成后从「回测历史」打开冻结报告。先看模拟范围、样本边界和费用，再结合累计收益率、账户权益、最大回撤、闭合交易数与期末持仓。胜率与盈亏比按已闭合交易统计，期末未平仓按收盘估值。
  3. 在「交易与账户明细」查成交、拒单或未执行原因，点逐笔记录核对买卖触发依据和实际模拟成交日。收盘产生信号后，下一个交易日开盘才尝试撮合，并受可成交限制。前复权技术条件与未复权成交价格分开处理。

模拟受样本、资金、费用和实际留存数据限制，本版排除区间内分红送转等无法完整模拟的样本。回测报告保存本次参数与证据，不代表实盘委托、未来表现或全市场无偏结论。

全局搜索、观察日期与 K 线详情

从盘面榜单、策略结果、跟踪、自选或全局搜索打开同一只股票，使用的是同一套行情详情。入口决定观察日期、可连续浏览的名单以及随图带入的事件依据。打开图表只是查看，收藏、划线和加入跟踪各有独立入口。

全局搜索与盘面日期

  1. 在顶部「名称 / 代码 / 拼音 / 首字母」搜索股票、指数、行业或概念。输入名称片段、代码、全拼或首字母都可以，例如输入 zwcm 查中文传媒，输入 rgzn 查人工智能。先核对候选的名称、代码及类型，再点选结果。「可能想找」里的同音或近似候选需要手动确认。全局搜索打开股票或指数时使用最新已发布行情。从历史榜单点股票才保留该入口的观察日期。
  2. 进入盘面研究后，点击顶部日期选择留存日期，也可用左右箭头查看前后留存交易日。手动选定的日期在盘面各页之间共享，切到自定义研究再回来仍会保留。策略、跟踪、回测、个股研究和数据设置按各自的业务日期或区间工作。
  3. 使用「回到最新」或对应页面的「回到今天」恢复默认浏览。盘前竞价、盘中观察和午评默认看当天留存的快照，基础行情默认看最新已发布收盘日。当天只有快照时，收盘行情页会提示尚未发布，可用「回到已发布盘后日」查看最近的收盘数据。

例如周末看到「最新已发布行情（非今日）」，先看提示中的交易日。它表示当前显示的是已入库的收盘数据。数据中心可核对更晚交易日是否已发布，以及盘后更新是否还有结果待确认。

个股详情先看头部，再核对原始报价与事件

  • 点击个股名称打开详情。首屏定位到图表，点「↑ 顶部资料」查看原始收盘报价、行业 / 题材及风险标签，再用「定位图表」回去。点名称旁的代码可以复制。通过榜单、策略、跟踪、自选或成员列表进入时，可用「上一只」「下一只」按该入口已经加载的顺序查看。
  • 头部的「今日收盘」「今日涨幅」对应本图观察日，历史回看时就是所选历史日。头部另可见近30交易日涨幅、最近已确认涨停及距离、年内涨停次数。板况标签区会区分首板、连板高度、来源的「几天几板」和已核验形态。原始板况文字与实际连续收盘涨停天数需要分别阅读。
  • 个股原始报价以实际报价日和未复权价格展示，图表上另标「图表价格」。核对题材时看关系有效日、采集日和来源。历史图上的「当前归属」可用于现在了解该股票，历史事件的归因仍以当时的留存依据为准。
  • 从选股结果或跟踪轮次打开，图下可能出现「历史事件 · 实际规则绑定」，记录原规则绑定的事件日期、收盘或高低价。点「定位事件」可在主图查看该日。前复权图在依据可核验时显示换算后的图价，同时保留原值。跟踪入池参考价、自选加入基准、历史事件价是三套独立记录，各自对应不同的日期和用途。
  • 从盘中观察或午评的个股名单打开，若所选日已有正式收盘，优先读该日正式 K 线。盘后数据尚未发布时，日 K 会在价格可核验时加一根标明时点的快照临时柱。周 K、月 K 仍读观察日前的已发布行情。竞价页的个股图以该日已发布收盘或之前的留存收盘为依据，竞价读数在竞价页单独看。

如何读单根 K 线与比较两个日期

看哪里读法
「日 K」「周 K」「月 K」日 K 看单个交易日。周 K、月 K 由已留存日线聚合，适合看较长的价格结构。周/月柱若仍在形成，或该周期有报价缺口，先看状态说明，再用完整周期判断周/月策略信号。
十字线与浮窗悬停蜡烛看开盘、最高、最低、收盘和涨跌幅，主图与技术副图会对齐所选日期。最高和最低涨幅对照同口径前收，旁边可看参照日期。日 K 用严格前一市场交易日报价，周/月用前一完整周期收盘。
「距行情截止日」与「至观察日涨跌幅」距离从所指 K 线到本图截止日按市场交易日计算，截止日本身距离为 0。周/月按该柱最后实际报价日计算。至观察日涨跌幅比较同口径的所指收盘和观察日收盘，反映价格变化，账户收益还涉及实际成交、成本和其他现金流。
「未复权」与「本地前复权」未复权显示来源的原价。个股前复权以本图观察日为锚，按已核验分红、送转等公司行动换算历史价格，便于对照除权前后的走势。切换后先读「图表价格」确认实际口径，依据不足时可能回退到原价并提示。指数用原始点位。
缩放和定位在图内滚轮或触控板缩放，拖动图面或底部范围条向前回看，图外继续滚动页面。可用「聚焦近期」、放大、缩小、「恢复默认可读范围」和「显示全部」切换视野。「适配一屏」压缩主图及副图，「恢复大图」恢复原高度。显示全部只展开本次已加载行情。

事件标记、自动趋势线和波浪结构

  • 个股日 K 的「涨跌停标记」显示已有证据的收盘涨跌停与地天、一字日形态，炸板和回封另据相应来源标记。先悬停看日期、类型和来源，再去盘面板况、龙虎榜或历史事件依据对照。相近涨幅、盘中触板与收盘封住分别读。
  • 有结果时可勾选「自动趋势线」，在「图层」选择「主线」「近端线」「水平区」「穿线记录」。主线看较长一段的支撑或压力，近端线更重视近期高低点，水平区显示有多次拐点反应的价格带。「当前价位」可逐条显示或隐藏对应线或区域。
  • 「穿线记录」把旧线与事件日对应起来，区分盘中越线、收盘穿越及下一根完整 K 线确认。图上编号与记录对应，点单条记录可高亮旧线，点「显示全部旧线」可对照本周期历史。自动趋势线是对已留存价格结构的整理，核对时先看是否有连续、可比的报价。
  • 图上提供「波浪结构」时，可在关闭、最新结构、仅转折之间切换。日期可在当前图独立选择。识别不到五浪候选时，可切「仅转折」查看已确认高低点，同时核对实际拐点日与后续确认日。

保存参考线、支撑线或压力线

  1. 在个股或大盘指数图表点「划线」，选择「参考线」「支撑线」或「压力线」。直接填「线价」，或点「点图选价」后在蜡烛主图取价。可选颜色、填备注，再点「保存划线」。参考线适合记观察价，支撑和压力用来区分观察价格的不同方向。
  2. 需要从历史中找候选时，在「自动支撑压力」选择回看 60、120 或 240 根当前周期 K 线，点击「计算候选并预览」。看参考收盘日、分型数量和确认日期，勾选有用的价位，再点「保存所选支撑压力线」。预览可重算，已经保存的线可单独编辑或删除。
  3. 不同周期可共享同口径的保存线。前复权线保存时记录原价与原锚，后续在证据完整时换算到本图锚点。若图上看不到，先看保存列表的显示开关、价格口径和隐藏原因。指数水平线以原始点位保存，仅用于标记和展示。

让个股划线在盘后核验

在个股图上新建或编辑支撑、压力线时，勾选需要的提醒条件再保存。保存的参考线或自动候选可以只做展示。以下规则用已发布日线核验，「盘中触碰」指日线高低价所反映的盘中范围。

线与条件核验什么
压力线 · 收盘突破前收未站上压力，当日收盘严格站上。
压力线 · 盘中触碰该日最低价至最高价包含线价。可与当日收盘分开检查。
支撑线 · 回踩收回前收不低于支撑，日内回踩，收盘回到支撑线或其上方。
支撑线 · 支撑失守提醒（风险）前收不低于支撑，当日收盘跌破。按风险事件保留。

需要自动收藏时可勾选「触发后自动加入自选」，符合成功条件才入池，失守记录用于风险观察。进入「我的自选」的「划线提醒」查看「今日」「历史」及核验依据，或点「检查划线提醒」发起手动检查。顶栏铃铛的数量对应最新已发布业务日的已确认事件。移出自选与停用划线条件是不同操作，停用请编辑对应线并取消提醒条件。首次实际提醒后继续跟踪 60 个市场交易日，超期的线和相关提醒由符合政策的后续盘后增量清理。

指数、行业和概念的 K 线与成员

  • 在「指数行情」看上证指数、深证成指、创业板指、科创50，或用全局搜索选中具体指数。读原始点位、涨跌及均线，和个股的元价、涨停次数分开。
  • 在「行业与概念」点板块名称看板块 K 线，点表格行的其他位置看成员。全局搜索也可打开板块，有入口时用「查看成分股」进入成员列表。先核对板块来源代码和观察日。同花顺板块指数是来源点位，东财同名行业的指数观察若标为代理，应与原成员口径分开理解。
  • 板块 K 线首先读取本地已核验历史。该观察日缺历史时，图中有入口则点击「加载板块历史K线」，等待当前板块任务完成，再切日 K、周 K、月 K。有效范围以来源返回和核验结果为准。暂停任务在数据中心手动继续。刷新缓存状态只是重读当前状态。
  • 板块点位与成分股档案分开。旧盘面日的历史成员缺档时仍可查看已留存的板块点位。要查看当前名单，在有入口的成员视图切「当前最新成员」，同时读清「成员采集日」和「行情日」两个字段。历史成员覆盖不足显示未知，缺档不能据此判断板块没有成员。

看见待核验、缺线或筹码空白时

  1. 先核对所选标的、观察日、实际报价日、图表口径及周期。个股详情的「资料与风险」可看数据截止、最新换手率和「数据说明」。指标断点可展开「指标断层说明」，核对历史长度、停牌、缺报价、公司行动或完整周期原因。
  2. 历史日缺资料时按所示缺口解释。可在数据中心查看相关数据覆盖与任务结果，必要时按有入口的缺口手动做「向来源核验」。数据为空、尚未核验与已核验为零的含义不同。普通浏览和日期切换读取的是留存数据。
  3. 个股图表的「筹码分布 · 本地 CSV」接受用户已有权限的 Tushare cyq_chips 文件。选择同股票、同交易日的 UTF-8 CSV，列名为 ts_code、trade_date、price、percent。文件在当前浏览器读取，价档用来源自身的坐标，展示来源估算的成本分布。未导入或股票、日期不匹配时，按界面提示检查文件。

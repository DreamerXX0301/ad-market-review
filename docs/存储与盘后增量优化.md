# 存储与盘后增量优化

这项改造分阶段推进，每个阶段独立验收。源码功能、运行实例和自动清理的启用状态分别确认；提交代码不表示已有安装已升级。

## 第一阶段：容量口径与轻量核验

已实现：数据中心使用十进制GB，展开可查GiB、原始字节和五类构成。数字只统计本实例published的普通文件，不包括业务库、raw、work、其他版本和备份。文件块量单列；逻辑重复文件和旧行情代际都不等于可直接释放空间。扫描不完整时明确显示小计，不能把失败目录当作零。

主行情完成后，先给划线提醒和上市身份核验排队，再创建板块尾部任务；重启补漏使用相同顺序。全局队列仍为FIFO，不抢占先前用户工作，不恢复显式暂停或取消的任务。无变化同步先冻结父任务自己的业务日，不能用后来发布的日期替换。已配置的本地策略与跟踪核对仍在唯一worker中执行，实际用时写入父任务事件；这些本地计算和已有排队工作仍会影响轻量核验的开始时间，不能承诺固定30秒完成。

第一阶段不改变行情文件格式，不取新数据，也不执行清理。已有实例应依照[升级与回滚](版本升级与回滚.md)使用独立恢复副本验收后更新。

## 第二阶段：公开资金来源的故障预算

已实现的新手动在线任务冻结 `public-fund-budget-v1`，沿父任务后续链传递；已有任务及其重试继续使用原冻结参数。新模式最多3个在途请求，两轮共用200逻辑请求、600次应用HTTP调用和60秒异步网络截止目标。健康目录维持原覆盖；同类连接、结构、5xx、限流或拒绝连续5次后停止新发请求，不把128个行业一次全部塞进后台执行器。目录与行业请求都支持暂停时取消并等待收尾；第二轮只补暂时失败，永久日期缺口不重复拉，已成功或有效部分历史缓存继续核SHA复用。

两轮使用首个已确认目录的代码、名称和分类指纹。目录缩小或改名时，保留首轮记录、分母、缺口及两轮原始证据并标为部分覆盖，不能因少了失败行业而变成完整。

实际逻辑请求、传输调用、在途峰值、故障类型、未请求代码、缓存及本地校验时间分别记录。未请求、被取消和数据缺口保持未知，不记作零或完整。60秒是共享异步网络截止目标；同步本地缓存、校验、发布和平台DNS收尾可能延长实际时间，因此不能称为整个补充阶段的硬60秒上限。没有运行真实来源增量来宣称全链提速，验证使用隔离合成传输，包括健康128行业全覆盖、持续故障停发、混合永久/暂时失败、目录恢复、共享截止及暂停取消。

扶摇来源的1.2秒间隔和710板块范围没有改变。来源是否存在符合本项目身份、日期与证据要求的批量接口仍未验证，不提高并发绕过来源限制。

## 第三阶段的离线验证工具

`scripts/compare_market_partitions.py` 接受一个明确路径和SHA固定的不可变日线Parquet，比较按月、按日的临时候选。它只打开独立内存DuckDB，不导入应用或打开现用分析库；保留全部列，以固定证券范围验证全行、类型和键域，再核单股及最近20个留存交易日的读取。临时文件有511MiB总逻辑预算和2GiB磁盘预留，异常也只清除本次新建的临时子目录，输出小型私有JSON，不修改源文件。

调用入口及全部参数见 `backend/.venv/bin/python scripts/compare_market_partitions.py --help`。只应使用已冻结副本；输出目录与源、临时目录分离，来源SHA不匹配、期间变化、键重复或预算不足会失败，不输出假成功。全量对账按128证券范围分批排序，其耗时属于有界验证器，不能当作生产全扫基准。OS缓存未清，原文件与候选的写入器、排序和行组也不同；读取和大小差异不能只归因为分片粒度。

离线验证表明，分片可以有利于近期窗口读取，却会增加单代际文件体积与单股读取成本；更细的日分片不必然更好。减少长期增长还需要跨代际复用未变化对象，而不是简单把同一套历史文件拆开。工具没有启用生产读写、manifest依赖、增量发布、备份恢复或滚动清理，不能作为这些功能已完成的证明。

下一步仍需完成旧格式兼容、发布、完整来源链和自足备份恢复的对账。只有新增或修订的分片生成新对象，未变化内容才能复用；旧报告仍引用原来的价格和SHA。

## 第四阶段与保留门槛

第四阶段默认只预览近五日历年的活动窗口。锚点是最近成功发布的主行情业务日，不是机器今天或页面所选日期。窗口外的MA、完整周/月、递推MACD/KDJ边界状态、历史事件、复权和原始来源需要单独保留；不能统一截成250日。自选基准、划线触发、策略运行、跟踪事件、报告、可恢复任务、备份及读取租约的全部依赖必须保留。引用闭包未证明完整时，不能给出可执行删除清单。

活动窗口、对象GC、业务回收站、升级旧实例和备份保留各自独立。默认不开自动清理，不清空回收站，不删除升级副本。用户保存的历史证据和备份增加时，总磁盘仍可能增长；“保留五年”不能作为总容量固定的承诺。

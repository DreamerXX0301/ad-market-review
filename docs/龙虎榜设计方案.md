# 龙虎榜使用与30个交易日留存

当前源码在盘面研究提供独立“龙虎榜”页。榜单、个股席位与30个市场交易日滚动留存均由唯一worker处理；页面只读取已发布本地资料，不因为切日期、搜索或打开个股发起外部取数。发行版本与部署结果以对应Release及验收回执为准。

## 定位与页面

用于核对上榜股票的买卖结构、机构净额和来源游资标签，辅助短线盘后复盘。沿用现有系统的深蓝底、卡片、表格、按钮、红涨绿跌和股票代码复制方式。

在盘面研究中提供龙虎榜入口，与盘面日期共用观察日。全部榜、机构榜、游资榜为同页分类；单日榜与三日累计榜独立切换，默认单日。顶部显示当前范围已留存上榜股票数及买入、卖出、净买额，分页表格支持搜索和表头排序。点击表格整行展开该日买卖席位并定位明细标题；点击股票名称单独打开现有个股K线详情，复制按钮只复制代码。关闭K线保留原筛选、分页和席位状态；个股K线沿用原报价、指标与图表偏好，上一只/下一只按当前筛选的完整股票顺序去重。

搜索框支持股票名称、代码、拼音、首字母（如 `rcdf` 对应日出东方）、近似名称、来源概念、游资标签和披露的买卖席位名称。结果随所选观察日、榜单、单日或三日及标签范围筛选。命中席位时标明买方或卖方及留存名称，点行打开对应披露记录。搜索只查所选日的留存档案，一键清除会回到第一页并保留当前范围。游资标签点一次选中，再点同一项取消；取消后展示全部标签，不自动选中其他标签。全部标签下的股票汇总按股票和区间去重，独立标签净额不跨标签混加。

搜索完成后，单日榜和三日榜分别显示匹配条数。当前榜为空且另一榜有匹配时，首次显示该搜索范围会自动切换一次；之后可手动选回空榜，通过提示跳转到有匹配的榜。明细、金额和股票导航随当前所选榜查看。

名称、涨幅、净买额、买入额、卖出额和机构净额均支持点击表头切换升降序，先对当前筛选的全部结果排序再分页，未知始终放在末尾。数字表头与数值右对齐，排序箭头说明当前方向。选择股票使用稳定标识，排序后不能跳到另一只股票；从席位返回时恢复所选股票所在页。

机构榜展示实际返回的机构净额。游资榜展示供应商标签与关联股票，行内净额使用该标签在该股的字段；未选标签时，顶部明确显示“股票龙虎榜净额（去重）”。不把股票全榜净额当成某游资净额，也不把标签当作已核实的账户身份。未取得营业部原始明细时保留未知，不补造买卖前五列表。

## 个股买卖席位

买方前五与卖方前五是本功能的重点内容。宽屏并排、窄屏上下排列，沿用系统深蓝卡片，每行展示披露排名、席位全名、买入金额、卖出金额和净额。买入显示红色，卖出显示绿色，净额按正负着色；长名称换行，金额明确标注万元，股票代码可复制。顶部提供该披露范围的买入、卖出、净额汇总及比例条。

扶摇的[个股龙虎榜机构金额详情](https://fuyao.aicubes.cn/docs/api-reference/dragon-tiger-institution/)提供机构汇总以及 `buy_departments` / `sell_departments` 名称索引，名称索引不含每个席位的买卖金额。完整金额明细需独立来源，不能把机构汇总分配给这些名称。

个股席位来自[东方财富龙虎榜公开数据](https://data.eastmoney.com/stock/lhb/000678.html)，按日期分别读取买入、卖出报表，保留披露记录ID、原因、股票代码和原始行；查询失败与真实无记录分开。金额按元留存，界面明确显示万/亿元。

- 同股同日可能有多条披露原因，先选择具体记录，再展示其前五；不把多个原因或单日、三日累计榜混合排序为一份前五。
- 同一席位可同时进入买方、卖方，不把两表简单相加。汇总优先采用已核验的同范围来源汇总；跨源对账不符时显示差异，不凑平。
- “机构专用”等同名或通用代码可以对应多个匿名披露行，不能按名称或通用代码合并。保留方向、排名、原始行和披露记录标识。
- 来源只提供本方向金额时，对手方向和无法核验的净额保留未知；不能把原始字段中等于单向金额的值当作实际净额，也不能跨方向按同名机构猜值。
- 席位名称是披露的营业部或交易单元，不能据此推断实际个人账户；游资标签单独标明来源。
- 点击股票仅查询本地留存席位；不在页面打开时逐股联网。源未发布、日期错位、单向金额或证据不完整时显示相应缺口。

页面参考[单日观察示例](https://fuyao.aicubes.cn/best-practices/08-dragon-tiger-watch/example.html)的榜单分类与详情联动，保持本系统的主题、颜色与组件。当前提供单日/三日榜、标签、个股穿透和30日覆盖，不提供跨概念等分资金图；来源概念关联不代表真实题材资金归属。

## 数据源与核验

主来源为[扶摇龙虎榜接口](https://fuyao.aicubes.cn/docs/api-reference/dragon-tiger-data/)，`GET /api/a-share/special-data/dragon-tiger-list`；按明确交易日请求 `all/org/hot_money` 三类，不省略日期。文档支持一年内逐交易日查询，无分页；新功能只取约定30日范围。

- 三类返回的实际交易日必须一致且等于请求日，核验时间戳、数组长度与源记录数。
- 单日与三日分别保存；同股票同日出现两个区间不是重复记录。窗口累计默认仅用单日榜，不能把重叠三日榜求和。
- 标准代码缺失时，仅使用已核验名录中的唯一对应关系补充规范标识，保留原始代码。基金、REIT、转债或名录未匹配记录单列说明，不直接计为A股，也不以空标准代码将多个标的合并。
- 金额按元存储，显示明确的万/亿元；来源涨幅、占比的小数形式转为百分比。检查净额与买入减卖出的差异，保留正负号、真实0与未知。
- `limit_reason` 是来源涨跌停原因，不是龙虎榜披露原因，不互相替代。历史概念若不能证明当日成员关系，标明当前资料关联，不回填为历史主线或用于历史题材累计。
- 机构和游资的分类范围未经互斥核验时不相加，不用差额凑出“其他资金”，不制造总额守恒的假象。

交易所披露本身有范围限制，并非每只股票的全部买卖或全市场资金。可核对[上交所公开信息](https://www.sse.com.cn/disclosure/diclosure/public/inquirydatatib/)和[深交所2026年交易规则](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)的交易公开信息章节。

## 30个交易日滚动留存

常规保留最近30个市场交易日，页面可以切换已留存日期；不提供长期龙虎榜统计回测。不按自然日，也不按“成功取得30份数据”向更早无限扩展。

新创建的首次初始化冻结 `dragon_tiger_policy=dragon-tiger-v1`，按最近30个市场交易日补齐；新盘后增量及新单独盘面补充只冻结当日范围。这一标识通过题材/板块K线子链传到盘面补充，由唯一worker采集。旧冻结任务没有此标识时不增加龙虎榜取数。扶摇三类榜各日一请求时最多90次；席位明细另外按日期获取买入、卖出及披露汇总报表，并按来源分页，其请求量不能算在这90次内。

已有安装可在最新行情日手动点击“补齐最近30个交易日”；完整留存后按钮禁用，有缺口时可修补。历史回看日不能创建不同锚点的补齐任务，需切回最新行情日。创建任务后可到数据中心查看实际阶段与进度，显式暂停/取消后不自动恢复。此入口独立于旧盘面补充成功回执，已有补充成功不会阻止用户主动补齐新增龙虎榜能力。不采用每次打开股票重新请求或按全部股票逐只重复抓取的方式。

补齐遇到当天席位与披露汇总范围不一致时，会重新核对三份东方财富公开报表。三份报表仍对不上时，页面保留该日缺口。

唯一worker按日期保存榜单、席位规范记录与各自的源证据，采用不可变对象和小型索引。GET只读对应日期或最多30日索引，不逐次扫描全历史目录，不打开worker正在写入的DuckDB。席位明细同样按30个交易日清理，不能只清榜单摘要而留下无限增长的明细文件。

以最新成功验收并发布的龙虎榜观察日为锚，从本地市场日历取含锚日的最近30个交易日。新日成功发布后再在本次手动更新中清理窗口外资料；失败不能先删旧资料。窗口内失败日明确缺口，不拿更早日期凑满30份。数据为空只有在来源明确、日期一致且空集核验通过时才记为真实无记录。

默认不因股票在自选或跟踪中就永久保留龙虎榜。若以后允许研究报告显式引用，只保护已引用的必要证据快照并说明例外；常规列表仍限30日。不自动延长为个股/指数K线的五年窗口，旧备份内资料随既有回滚集规则管理。

## 验收与性能要求

验收覆盖单日/三日分离、源代码缺失、非股票混入、同股多标签、未知和真实0、金额与百分比、日期错位与非交易日、来源失败、重复提交与断点重试。席位另验同股多原因、匿名机构重名、双向上榜、方向排名、来源分页及跨源汇总差异。

滚动清理验证第31日边界、节假日、窗口内缺日、更新中断、先发布后清理及引用保护。必须确认清理不触及五年K线、自选、策略、跟踪和其他补充数据。

页面只读本地资料，默认分页25条；日期切换只加载该日三类榜，搜索、标签和排序在当前完整日数据内处理，打开席位只读取对应个股和区间。首次补齐、每日新增、打开榜单与个股联动的真实耗时以本轮验收回执为准，不能用单日设计页代替正式性能验收。


来源游资响应的 `count`、`stock_count` 不等同于标签展开行数或唯一股票数，作为原始未核验统计保留。页面的标签数量、标签行数和去重股票数量按实际返回记录分别统计；不能据汇总差额补造记录或推断具体缺股。窗口响应已留存与字段统计已核验是两个维度，金额、日期、区间和身份仍按强约束校验。

# BOLL、个股详情、研究阅读与底部抬高验收清单

这份清单对应本轮功能，供本地升级后逐项复核。验收不需要重新初始化、创建研究任务或运行全市场策略；使用已有股票与已留存报告即可。图表和技术条件的显示偏好不改变策略算法。

## 1. BOLL与副图顺序

- 进入任一个股详情，打开图表偏好，启用成交量、BOLL、KDJ、MACD。
- 偏好按钮、图下开关与实际副图顺序都为：成交量 → BOLL → KDJ → MACD。指数上涨家数位于最后。
- BOLL保持独立副图，里面是同周期、同复权的蜡烛K线，上轨红、中轨青、下轨绿；仍按20周期简单均值±2倍总体标准差计算。
- 切换日/周/月、缩放或移动十字线，各副图日期联动；缺失或不足20根可比数据时，轨道保留空值。
- 关闭全部副图、刷新、切换同类型股票，偏好应保留；指数和个股仍分别记忆。

## 2. 统一的个股详情与显眼股价

- 分别从30日涨幅、资金与轮动、行业题材成员、搜索、自选或策略打开同一股票。
- 使用同一套详情布局：股票名称与代码、观察日真实收盘价及涨跌幅、题材关联、行情摘要、K线、偏好、划线和研究入口。
- 报价标明日期、未复权和非实时；观察日无报价时明确最近实际报价日期或待核验。移动十字线和切换周/月不改变头部日收盘报价。
- 入口保留各自观察日期与上一只/下一只浏览范围。仅已有自选或策略的股票展示对应业务上下文，普通浏览不创建跟踪或事件。
- 题材是有日期和范围说明的关联资料，不把当前归属称为历史当日涨停原因。

## 3. 旧锚水平线与提醒

- 使用已有前复权划线，切换到更新的观察日；“显示标记”开启时，已有线不应仅因锚点日期变更而消失。
- 同代际、覆盖旧锚到当前观察日的公司行动证据完整时，按真实事件转换展示价；期间无行动时线价不变。
- 列表保留原保存价格与锚，换算时说明当前图价。编辑、提醒和事件证据不得被展示换算覆盖。
- 价格口径不同、原锚早于可核验范围、未来锚或转换证据不足时，列表写明具体隐藏原因，不盲画原价。
- 日/周/月共享同一实际价格口径，显示标记仍可正常开关。

## 4. 个股研究阅读

- 打开已有个股报告，默认看总览；桌面有报告内左侧小菜单，窄屏变为横向章节。
- 业务、财务、事件、趋势与证据逐章查看，避免整份长报告一次铺开。仅打开趋势章时挂载冻结行情图。
- 来源缺口、执行记录和字段元数据默认折叠，未知信息保留；旧版报告仍可读。
- 证据可按关键词、材料类型和来源是否提供发布时间筛选，每页8条。
- 点击章节中的证据引用，应清除冲突筛选、切到正确页并定位证据，不跳离研究页。
- 相同核查问题合并展示，原始来源引用仍保留。“条留存证据”不表示独立文档数，有发布时间也不表示已验证内容。
- 财务快览和完整三表共用增减颜色：同比红增绿减；利润、每股收益及净现金流红正绿负。与报告内上年同口径同期比较，悬停查看基期和差额；缺同期不填零，负基数不算普通同比，亏损收窄/扩大及扭亏/转亏单独标示。原有收入、资产负债、市值及估值绝对值保持中性。

## 5. 独立底部抬高条件

- 策略条件中选择“底部抬高”，默认60，允许手输8—750个所选周期；支持日、完整周和完整月。
- 低点必须严格低于左右各2根low，右侧2根完整后才确认；等低平台不算。
- 取回看窗口内最近两底L1、L2，不跳过后续较低低点。要求L2>L1，且从L2确认期（含）到观察期的所有收盘都≥L2。
- 破位后收回仍不满足同一对结构。左侧额外2根预热、窗口、公司行动或有效报价不足时显示待核验；完整窗口不足两底为不满足。
- 可与倍量、金叉、历史事件等条件用AND/OR组合；不会自动要求两底在某个历史事件之后。历史事件的今日条件可用，事件日条件中不可用。
- 结果展开“低点依据”，可查看L1/L2日期、价格、确认日及L2确认起最低收盘。选股、跟踪与受限回测共用严格算法，不用图表波浪结果代替。

## 本轮边界

没有新增数据库迁移，没有自动运行新策略、研究、回测或来源取数。真实行情、划线、提醒、已有策略与研究记录随最终备份完整保留；升级使用独立源码和恢复副本，按升级文档切换API与唯一worker。

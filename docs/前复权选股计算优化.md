# 前复权选股计算优化

本轮针对个股单次筛选及批次中的选股计算，减少同一证券重复准备指标的工作。唯一行情worker、顺序任务、暂停取消及真实来源核验规则保持不变，没有新增生产线程池或进程池。

## 完整种子与有界输出

历史事件的EMA、KDJ、均线和前高仍从原始留存起点按原顺序递推。准备上下文时，只物化事件保留窗口及前一条有效报价，窗口外的完整证明对象不再重复构造；第一条保留报价仍有原先的交叉与量能前值。停牌、报价缺口、公司行动和预热不足照常保留，不截短指标种子。

前复权计算同时保留原价事实与复权技术指标两条通道。原价周线只需提供完整周期的涨幅、量能及成交事实，不再计算最终会被复权通道替换的原价EMA/KDJ和日线前高。仍先对全部日历和日报价完成周完整性分类，再计算末两期事实。月线沿用完整月聚合及原有指标适配，不能用不完整月替代最近应有完整月。

## 批次内复用与内存边界

需要历史上下文的同一批次内，原价、复权报价只规范化一次。日、完整周、完整月及历史事件使用同一份规范化种子，但各自取得私有字典，缺量适配或调用者修改不会污染其他周期。不需要历史上下文的结构策略沿用原包装路径，避免为一次结构扫描额外复制两条完整种子。非规范日期的兼容输入沿用原来的拒绝或未知路径，不会因提前规范化而变成有效事件日。

含历史事件的前复权选股内部批次为16只证券，其他路径仍按原32只上限；完整候选范围、顺序、进度统计和任务粒度不变。该边界限制同时保留的原价、复权及历史上下文对象数量，避免给不需要历史上下文的结构策略增加批次读取，不是增加并行worker。

跨次有界摘要仍按数据根、真实来源SHA、行情代际、观察日、复权锚、周期及指标参数隔离。使用摘要前仍核验实际来源，题材、政策及决策不进入共享技术缓存。入池价格仍是业务日的真实原始收盘，已有策略版本和跟踪基准不改写。

## 验证

测试逐字段比较完整日、周、月指标及历史上下文，覆盖报价缺口、重复日、零量、缺量、无效OHLC、未知公司行动、已知行动、形成中周期和缺观察日报价，并验证缓存修改隔离、内部批次上限及全部候选保留。

真实性能比较使用相同已留存来源、观察日和冻结规则，在独立业务副本中执行实际选股函数；网络连接及非内存DuckDB被拒绝。计时包含来源核验、冷行情加载、完整候选计算、私有任务进度、候选保存和结果读取，排除创建副本及结果归档。旧新完整返回只去掉运行ID、任务ID和真实计算时间，比较全部候选、指标、依据和未知状态。

单策略、连续策略计算和缓存回访分别报告。连续选股的累计时间不代表包含自动入池与队列等待的整个批次耗时；硬件、操作系统页缓存、规则复杂度及来源覆盖都会影响结果。进程RSS峰值只反映被测进程，不代表API与worker并发时的整机内存。具体实测与验收状态以本轮交付记录为准，不给任意规则的固定耗时保证。

复杂全市场前复权筛选首次执行仍可能是分钟级。新参数的底部结构与BOLL条件仍需扫描各自严格窗口，本轮没有改变这些结构算法，也不能把连续策略累计提速解释为每一条策略都变快。

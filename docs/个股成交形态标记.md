# 个股成交形态标记

个股详情标题旁显示观察日已确认的“地天板”“一字涨停”“一字跌停”“炸板”或“回封”。日K在当天蜡烛旁显示相同标记，回封与普通涨停合并显示“回封”，炸板使用黄色菱形“炸”；悬停可看原始成交价格、来源与判定说明。关闭图上的“涨跌停标记”会隐藏这些图上标记，标题旁的观察日信息仍保留。

头部使用观察日的日线信息，悬停历史蜡烛或切换周K、月K不会改成别的日期。周月仅列出周期内哪些具体交易日出现形态及数量，不将整根周/月K称为一字板。指数不显示个股涨跌停形态。原来的收盘涨停和跌停统计、策略、跟踪、回测均不因新增展示改变。

## 判定方式

| 标记 | 必要依据 | 不据此推断 |
| --- | --- | --- |
| 一字涨停 | 未复权开高低收按分精度全等、正成交量、同日同证券涨停收盘池价格精确相符 | 盘口全天封死、无法成交、没有撤单 |
| 一字跌停 | 同上，收盘来源改为跌停池 | 全天卖单封死、没有打开过委托队列 |
| 地天板 | 有效最低成交触及可核验的跌停参考价，最终收盘价被来源确认涨停 | 首次触板先后、封单大小、开板回封次数 |
| 炸板 | 同日炸板来源池中的证券、日期与原始有效收盘价核验一致 | 仅凭最高价曾触及参考涨停价猜测炸板 |
| 回封 | 已核实同日收盘封板，来源明确记录 `open_times > 0` | 把每只普通涨停股都称为回封 |

炸板与回封沿用原图表窗口和已保存来源覆盖，不另设100天或一年采集任务。缺少历史池的日期保持待核验；前复权只调整标签位置。盘中或午评的临时日K可显示“盘中炸板／盘中回封”，依据仅来自所选快照：回封需要明确开板次数，或已核验的严格相邻时点先炸后封证据。临时状态不等同最终收盘，不写入正式日线、选股、跟踪或回测。

目前没有直接留存交易所上下限价字段。地天板因此使用严格受限的派生方法：

1. 先确认当日原始OHLC、正成交量，以及同日涨停收盘池的所有正证据都与真实收盘精确相符。
2. 读取严格前一市场交易日的有效原始收盘，缺前日时不能拿更早报价替代。核验上市日期，要求至少5个先前上市后市场交易日；上市初期或日历窗口不足时保持未知。
3. 当日公司行动覆盖必须已知且没有行动。分别计算5%、10%、20%、30%标准对称涨跌幅档，按人民币0.01元四舍五入；舍入导致与前收同价时，应用最小一档价差。
4. 只有一个档位与已确认涨停收盘精确相同，才派生同档跌停价。若多个档位舍入同价、不能匹配、原始OHLC越界，或最低价差一分钱，都不会肯定标记。

派生参考价会在事件证据与提示中明确说明，保留前收、前交易日、实际匹配档、取整、上市日期及公司行动核验依据。它不是交易所直接限价字段，也不声称确认了当日历史ST状态；不会按当前股票名称、代码或单纯9.9%涨幅套公式。

交易规则依据为[深交所2026年交易规则](https://docs.static.szse.cn/www/lawrules/rule/trade/W020260424690713155663.pdf)关于最小报价单位、涨跌幅计算、取整和无涨跌幅限制日的规定；可参看[深交所投资者教育的限价计算说明](https://investor.szse.cn/knowledge/stock/deal/t20180801_553961.html)。地天板使用已确认的涨停收盘价唯一验证候选档位。

## 日K跌停价格参考

当未复权日线收盘价与最低价都精确等于当日上市板块的常规跌停参考价，日K用紫色空心向下三角和「跌?」提示。悬停可查看原始参考价、严格前一交易日收盘价和常规跌幅。计算要求有效原始报价、正成交量、足够的上市后交易日、当日已核验无公司行动，且常规档位与其他候选档位的取整价格可区分。当日明确处于特别处理、来源证据冲突或已有已确认板况时不画该参考标记。

当日跌停池已核验而未收录该股时，提示同时说明来源池结果与价格匹配。正式跌停标记和统计仍以同日来源池核验为准。该参考仅用于个股正式日K，随「涨跌停标记」开关显示，前复权只改变图上锚点。

## 缺口与兼容

来源空池、证券身份或日期冲突、OHLC异常、零成交、快照缺失，以及地天板所需的前日、上市或公司行动证据不足时，返回待核验原因，不能把未知当未发生。原始来源SHA存在时一并保留。前复权只改变图上锚点，所有判定仍使用未复权原始价格。

API字段见[分析接口契约](../contracts/analytics-api.md)。展示只读取已发布不可变行情，不联网、不创建采集或业务任务、不写新标记到业务库。行情代际更新后按相同规则重算；没有形态字段的旧冻结研究报告保持原样，不借查看报告补入当前证据。

## 验收要点

- 正例覆盖原三种形态及炸板、回封；原三种形态的日K与详情在同一观察日、同一快照一致。
- 炸板只取原同日来源池；开板次数缺失、非法、0与正数冲突不标回封。临时K线保留快照SHA与采集时间，收盘展示正式同日原代际证据。
- 不把普通长下影、开高低收不相等、零量或原价错一分标为形态；已确认涨停不能与另一正来源错价混用。
- 地天覆盖5/10/20/30%档、分价取整、档位歧义、上市初期、公司行动和严格前日报价缺口。
- 日K「跌?」覆盖来源池明确未入和来源覆盖不足的价格匹配。正式跌停优先显示，参考价不进入已核验事件与统计，也不参与策略、跟踪或回测。
- 切换股票/日期不残留上个标记；悬停和切周月不改变头部日期；周月仅汇总具体日。
- 原价/前复权判定依据相同，旧冻结图不补猜；指数没有个股形态。
- 新旧详情及日/周/月图剔除明确新增字段后逐字段对账，原行情、指标、收盘事件和资金页保持一致。

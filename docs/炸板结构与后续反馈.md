# 炸板结构与后续反馈

这项分析回答三件事：当天有多少股票冲板后没有封住，失败集中在哪些行业/概念，以及昨天失败的股票今天修复还是继续回落。它复用已发布本地数据，不因浏览页面自动取数。

## 从哪里看

- **盘面总览**：简洁的炸板结构摘要，保留数量、比例、前日变化和观察结论；不额外加载今日/昨日成员档案或传输个股明细，点击进入市场情绪看完整分析。原“炸板池前五”仍是来源样本按开板次数和成交额排序，不是已验证的分歧强度模型。
- **市场情绪 → 炸板结构**：当前同口径涨停、未封住和触板家数，近7个市场交易日变化，以及昨日炸板样本今日的平均/中位涨幅、涨跌分布、明显回落和涨停反包情况。明细名称打开对应观察日K线，代码可复制。
- **行业与概念 → 炸板分布**：比较同源方向的涨停/炸板家数、触板规模和炸板比例。选择一行看右侧该方向结构和个股；名称仍打开板块K线，左右列表独立滚动。

完整同范围的收盘炸板比例为：收盘未封住家数 ÷（收盘涨停家数＋收盘未封住家数）。两池必须同日同源、完整、去重并通过价格核验；缺档显示“已观察”及未知比例。完整两池均为空时是0家，比例没有分母，显示“—”。

汇总数字使用统一色彩：炸板比例、收盘未封住为琥珀色，收盘涨停为红色，触板总数为蓝色；未知值保持灰色。色彩区分指标含义，不按未经验证的阈值额外判断市场情绪阶段。

明细上方按今日/昨日队列切换行业、概念分组，标签显示“名称＋关联只数＋样本平均涨跌幅”，上涨红色、下跌绿色、平盘中性，不显示样本占比。百分比只计算该分类下本批炸板股票的观察日可比涨跌幅，按股票去重后等权平均，使用原始精度计算后显示；不使用行业或概念指数。只关联一只股票时，平均涨跌幅就是该股票的涨跌幅。部分报价不可比时，显示有效数量，缺失不补0；全部不可比显示“—”。昨日炸板反馈按炸板日归属冻结，涨跌仍使用这些股票在观察日的表现，成员采集日期另列。行业一行、概念一行，按关联家数优先展示，超出可用宽度的标签不显示；统计仍按完整队列计算。点分类筛选明细，再点取消，也可清除；不会改变上方整体统计。每只股票展示对应行业和概念，较多标签可展开全部。

近7日可点击日期，查看当天炸板股票和分类分布，返回观察日即可回到原明细。这是局部浏览，不会悄悄切换全局日期；未留存的日期仍显示缺口。

市场情绪的最新已发布行情日可为当天炸板队列补充本机已核验的较晚行业或概念档案，并显示“最新行业概念参考”及实际档案日期。补充只影响分类标签和分布，价格、事件及统计分母仍按原队列。昨日反馈、近7日历史明细及 AI 查询仍按对应日期的归属取证。

今日炸板、昨日反馈与历史明细均显示上市板块，支持全部、主板、创业板、科创板、北交所及未知筛选，并能与行业、概念分类同时使用。板块按证券代码和交易所识别，不代表另有历史身份档案。筛选只改变股票明细与连续浏览名单；上方整体统计及行业、概念关联家数仍按原队列计算。

## 怎样理解

同样20家未封住，100家触板和40家触板的含义不同，因此同时看数量和比例。进一步看失败集中于某个方向还是广泛扩散、是高位样本还是低位样本，并结合指数环境、市场广度及连板反馈。不能只凭一个比例判定退潮。

日高到收盘回落描述当天价格失守程度；不等于某人在涨停价买入后的盈亏。昨日炸板今日反馈使用可比收盘收益及独立的涨跌停来源证据；涨幅均值、涨停反包和跌停是不同事实。没有完整分时路径时，不推断早盘/尾盘炸板顺序、封单稳定性、洗盘、出货或主力净流出。

昨日队列的今日反馈同时展示价格表现和板型：正反馈、负反馈、大面、平盘，以及独立核验的涨停反包、跌停等。“大面”按不高于−5%的可比收盘变化分类，主界面只显示名称，具体阈值放在悬停说明中；不代表账户实际盈亏。涨停反包在本页指昨日炸板、今日确认涨停；不把普通上涨叫涨停反包，也不声称已确认包住昨日全部高点。

单只股票一天开板多次，家数仍只算一只。盘中开板后最终回封与收盘未封住分开；来源两池同时列入同股时，说明冲突，不重复累计。题材历史只用所选日已留存成员，多重概念关联不能相加成全市场家数，也不是涨跌原因认定。

## 数据不足时

历史炸板池、价格或成员缺失保持未知，不用今天的题材补昨天，不把缺报写成0。历史表保留缺口，可比报价数量和来源覆盖分别展示；少量已观察交易日不能证明指标有预测能力。本版是描述性研究，尚不提供未来1/3/5日预测胜率，不自动产生策略或开仓信号。

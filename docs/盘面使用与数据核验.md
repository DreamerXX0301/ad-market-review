# 盘面使用与数据核验

## 近30日涨幅榜找不到股票

默认查看涨幅前100名。搜索名称或代码时查全市场，包含未排名证券；清空搜索恢复原范围。也可直接点击“未排名”查看原因。缺少观察日或T−30市场交易日端点、公司行动依据不完整时收益保持未知，不向前借其他报价凑满31条，不以0%或人为排名替代。中间缺报价单列说明，不单独因此移除证券。

## 概念关联数量

涨停梯队的“概念关联”顶部显示概念与关联涨停数量，按数量降序排列，固定展示前20项（不足20项显示实际数量），不折叠，可点击筛出关联股票。数量沿用所选日已留存归属和涨停核验结果；不代表涨停主因，同股多概念导致数量重叠，不能相加。完整数量未知时显示已确认下界或待核验，和浏览分组独占家数分开。

## 证券名录怎么核验

在数据中心打开证券名录，先点“运行本地核验”，它只核验已留存证据，不启动全市场下载。已带有效上市日的证券无需逐只填写；有报价但上市日缺失，证明已交易但不能猜上市日期，也不能把本地最早K线当上市日。仍未知的证券留在核验分母。

对少数例外复制代码，到[上交所名录](https://www.sse.com.cn/assortment/stock/list/share/)或[深交所上市公告](https://www.szse.cn/disclosure/notice/company/index.html)核对代码、名称、上市日期和公告时间。只有明确公告依据且没有报价证据时才标记待上市；人工说明和来源引用按原核验流程留存。北交所证券使用其官方公告核对，不用其他交易所日期替代。

## 更新与资金模块

本日主行情发布后不能重复提交整轮增量；发布时保留的缺口通过补充或原失败步骤修补。盘面补充必须完整成功才禁用重复按钮，部分成功仍可补。新行情日、新代际和扩大范围重新判断。进度、预计时间、整链确认和服务端锁仍按[增量契约](../contracts/sync-session-api.md)执行。

独立资金与轮动模块及行业资金趋势撤下，旧地址转到行业与题材；不将旧日资金当作新日结果，不把成交额当净流入。新手动任务停止请求行业资金源，旧冻结任务按原范围恢复，已留存资料保留。

## 周月图指标留空

BOLL使用20根连续完整可比周期；当前系统KDJ、MACD使用35根预热。五年历史只有约60根月K，因此早期月线有价格却没有指标属于预热范围。尚未结束的本周/月与缺数据分开说明；“形成中”不显示成“预热0/35”，不以正在形成的月K产生完整月指标或策略信号。缺周期、未复权公司行动等可重置连续预热，不能跨缺口连线伪造指标。

## 手动线颜色

支撑绿色、压力红色、参考紫色，点类型自动切默认色，仍可手动选三种颜色。旧色与旧线保留，不改动报价、原锚和提醒判断。

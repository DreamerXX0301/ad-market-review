# 盘中监控

在「自定义研究 → 盘中监控」查看关注股票的盘中变化。首次默认关闭自动采集；查看页面、刷新、保存未启用的设置不会请求行情。

本次独立预览可用底部「查看演示效果」切换虚构测试数据，体验24只示例股票、8条提醒、池内热点、已读状态和「模拟下一次采样」。演示模式有明显标记，数据仅在预览文件和当前页面内存中，不写入业务库、不取行情；刷新会重置交互，底部可切回真实数据。虚构股票不提供K线。

顶部铃铛用醒目的角标显示今日盘中未读数，超过99条显示99+；有未读时柔和闪动，新提醒到来时短暂加强提示。打开预览不自动标为已读，需在「今日提醒」明确标记；关闭自动采集也不会清除已有未读。盘后提醒数量单独展示，不计作盘中未读；系统开启减少动态效果时保留静态高亮与数量。

铃铛浮层默认露出3条提醒，可用滚轮或键盘在列表内滚动查看最近最多5条摘要，顶部计数和底部跳转入口保留；全部记录在监控页查看。列表不会因提醒增加而无限拉高。

今日提醒、监控股票与池内热点共用紧凑表格样式。股票名、数值和短时间保持单行，完整日期时间可悬停查看；收益和涨停使用两行摘要。分类、指标覆盖、来源证据和缺报原因通过独立详情弹层查看，不在表格行内展开。筛选框和操作按钮统一高度。可用URL查询参数`monitor_view=heat&monitor_period=30d`直接进入已发布30交易日热点；这只选择展示视图，不改变监控设置或取数。

## 监控范围

范围可选择策略跟踪中、自选、启用手动画线提醒的股票，以及已发布30日涨幅榜前1000。四个范围取并集，同股多策略只采一份行情，不因此新增策略跟踪轮次。30日榜排名使用已发布收盘数据，日内冻结；不足1000只不补值。第一版最多2000只，超限会提示调整范围。

30日榜是过去30个市场交易日的收益排名，会包含不同走势阶段的股票，不保证覆盖所有刚启动的股票。列表保留来源、排名和基准日，提醒负责记录新的价位变化。

「池内热点」按当前筛选后的股票归属行业或概念统计，可切换盘中、30交易日和年内涨幅，查看上涨占比、涨幅中位数与均值、≥3%家数和领涨股。默认至少3只有效样本，可调整为1只或5只；缺行情不填零，概念重叠分别计入各组。点击分类进入对应股票，点击领涨股打开K线。这反映当前监控池的强弱，不代表全市场热度，也不把个股平均涨幅当作板块指数收益。

「监控股票」和「今日提醒」均支持名称/代码、行业概念、板型与指标筛选。板型区分主板、创业板、科创板、北交所；可查看今日、近30交易日、年内涨幅，近30交易日/近一年/年内涨停次数、最近已确认涨停日期和距离。未知不补零，可选择保留或单独查看未知。当前行业概念与指标观察日单独标注，不冒充提醒发生时的历史归属。

股票筛选框支持名称、代码、拼音和首字母。例如输入 `rc`、`rcdf` 或 `richudongfang` 可在当前监控范围内找到日出东方。

「监控股票」的盘中涨幅、采样价和北京时间排在股票名旁。点击「盘中涨幅」对筛选后的整张名单排序，缺报始终排在最后。涨幅和价格来自本交易日该股最近一轮已保存采样，校验通过才显示。页面每 30 秒检查是否有变化，发现新批次后整批刷新。自选、划线和行业归属也会定期刷新，排序和查看无需逐股请求行情。

## 盘中提醒

有有效手动线就监控对应线；自动参考也有效时可同时监控。无手动线时使用前一完整交易日准备的水平支撑区、压力区及量价参考；没有可靠价位会说明原因，不凭空补一条支撑。真实支撑和短线风险线分开。

同一轮变化中，手动画线与自动区间同时命中时，在同一张提醒卡列出两项依据及各自时间。首次越过、回踩、站回或失守先记录采样观察；下一轮继续满足时更新连续保持。反复越过属于新变化，不把不同价位强行合成一条。

十分钟快照可能漏掉两次采样之间快速发生又消失的穿越；全天累计高低价不能证明先回踩再收回。页面明确区分采集时间、来源批次时间和未知的单股成交时间，盘中观察不等于盘后收盘确认。股票名仍打开已发布K线，事件依据独立展开。

「板况观察」汇总当天已留存盘中观察中可核验的涨停封板、炸板、较上一档回封和跌停，限当前监控池，标明盘中观察采样时间。板况列表使用已有来源，和十分钟价位采样的时点可能不同。列表不根据其间的涨幅推断急板。

## 运行和铃铛

在「采集设置」选择范围、价位来源并显式保存开启后，运行中的唯一worker按已核验交易日采集。09:30建立开盘基线；09:40—11:30、13:10—15:00每10分钟检查。午休和休市不采，不补造历史时段。长任务、网络或来源缺报可能造成延迟/缺档，查看最近批次和逐股原因。

顶部仍用一个铃铛，分「盘中」「盘后」两个页签。有盘中未读时优先显示未读数，关闭采集也保留；没有盘中未读且监控未开启时，显示单独标注的盘后普通计数。两类日期分别标明。打开页面时后台结果每30秒读取一次小摘要；这是读取已保存提醒，不是每30秒请求行情。首次打开不弹历史，同一提醒新增依据或连续保持不反复弹浮层。

关闭网页后，本机服务仍可采集并保存记录；关机或worker停止时不能采集。此版提供页内铃铛和新提醒浮层，未接入外部消息或操作系统通知。

普通报价滚动保留20个交易日，事件及必要来源保留60个交易日；清理由worker续做，暂停任务与备份引用受保护。恢复副本自动关闭开关，需要在唯一正式实例重新明确开启。详细字段及边界见[盘中监控契约](../contracts/intraday-monitor.md)。

# 近期热点筛选与个股题材维护

## 题材库按上市板块查股

在“题材库 → 题材与行业联合查股”选择一个或多个分类后，可用“上市板块”筛选主板、创业板、科创板和北交所，支持多选。默认“不限”；再次点击已选板块可取消，点击“不限”清空板块限制。板块条件可与题材 / 行业并集、交集和股票搜索一起使用。

匹配数、统计覆盖与排序针对全部过滤结果，之后每页展示25只；切换板块回到第一页。跨页或筛选保留的已选股票仍按界面数量提示，可单独清空。该页使用独立的当前业务行情日，不随盘面观察日改变。

上市板块复用当前已核验股票名录的统一分类，不代表历史上市身份。没有可核验名录身份的成员保持未知，仅在“不限”时保留；选择全部四个已知板块会排除未知身份。板块分类和是否有当日报价分别判断，缺行情不会被当成不属于该板块。

## 按近期热点限定选股范围

在“策略管理 → 个股策略 → 新建 / 编辑策略”的“股票范围”下，勾选“近期热点题材 / 行业”。可设最近1至60个市场交易日、排名前1至50名，以及题材、行业或两者。默认起点是近7个交易日、前10名。

保存后，策略摘要会显示“已启用近期热点范围”。属于所选排名中任一分类的股票，再同时满足下方技术条件，才会入选。它可以与MACD、KDJ、历史事件守位等原有条件组合。只设置热点时，编辑器同时保留“有效收盘价大于0”的基础报价条件。

热点依据是本地已留存、逐股原始收盘价核验的涨停股票日数：同一股票同一天只计一次；再按活跃股票数量、名称和稳定ID排序。不是成交额排名，也不把指数成交额解释成资金净流入。行业、概念和人工题材可能重叠，一个股票可以给多个分类提供事件证据。

这份排名用**当前分类成员映射最近事件**，属于当前研究代理口径，并不证明股票在历史事件当天就属于该分类。来源缺日、原价未核验或分类成员未完整同步时，热点范围显示“待核验”；独立技术条件明确失败的股票仍显示未命中。可在“运行结果 → 本次热点范围”展开查看具体日期、来源完整天数、排名和缺口。

每次运行保存自己的配置、排名、联合成员和来源指纹，之后修改目录不会改变旧结果。由于缺少当时的历史成员及当时排名，启用此范围的策略暂不支持历史回测，回测页会明确说明。关闭热点范围并另存版本后，原技术条件仍按原有可用性回测；旧版本与旧运行继续保留。

## 真实离线验收示例

本轮在独立临时业务库，以2026-10-23的真实冻结行情运行“近7交易日、前10名、题材与行业 + MACD柱大于0”，没有联网或修改正式业务数据。排名只计算一次，实际原价读取为271只股票、7个交易日，分256只和15只两批。

7个来源日及711个分类的当前成员均完整；但候选股票日仍有5处原始收盘缺失、2处来源证据冲突，所以363个已确认涨停股票日只能形成排名下界，不能保证前10名边界完整。此时**待核验是数据结论，运行本身已正常完成**：5578只股票中，3650只技术条件明确失败，仍排除；1120只技术条件成立和808只技术指标未知，共1928只保留待核验。“尚未确认入选”不能解释为“已证明0只符合”，也不能据此加入自选。运行回执展示缺口数量，刷新后排名、成员和来源依据保持一致。

热点单独冻结约0.94秒，独立进程绝对峰内存约214MiB；相同数据的普通全市场选择接口约7.23秒，加入热点约7.86秒。新进程重复样本中，普通选择绝对峰约1.92～2.09GiB、带热点约1.96～2.12GiB，包含导入、计算及响应物化；原生分析引擎分配有波动，不能把两进程峰差当作热点精确增量。两者不是磁盘存储量，也不是未来每次运行的固定承诺；时间会受机器与缓存状态影响。热点冻结证据约72KB，只保存每次运行一份，不为每只股票复制完整排名目录。

## 给个股补充题材

任何入口打开的统一个股详情，在“行业 / 题材”右侧点“补充题材”：

1. 已有分类：搜索并选择题材或行业，填写可选依据，点“保存题材归属”。保留股票原有其他归属，已归属项不重复添加。
2. 没有合适题材：选择“创建人工题材并加入”，填写名称和可选依据，点“创建题材并加入”。新建与加入在同一事务完成。

保存后详情即时读取当前归属，人工补充带“人工”标记；目录页仍可新增题材、维护成员、排除或撤销人工修改，并查看变更审计。来源行业/概念不会被改写为第三方认可的归属。

所有修改从当前业务日生效。回看历史K线时仍明确显示当前归属，历史事件、旧选股运行与旧回测不倒灌新题材。仅维护分类不会发起行情采集、创建研究任务、自动加入自选或新增跟踪轮次。

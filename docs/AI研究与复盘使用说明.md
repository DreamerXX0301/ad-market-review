# AI研究与复盘使用说明

对应当前[AI工作台契约](../contracts/ai-workbench-v1.md)与[自动联网契约](../contracts/ai-web-chat-v1.md)。本轮将对话改为按问题查询资料并流式回答。本地验收版本为0.1.19，入口为「AI研究」。本文描述源码能力；每个实例的实际部署结果以健康检查和部署回执为准，不表示已经公开发行。

## 配置模型

在「数据源 → AI模型」分别管理DeepSeek和OpenAI。各自使用官方Key、模型与验证记录，共享本实例的预算、次数及超时，不切换既有行情来源。

1. 填写Key和模型后保存。Key留空保留旧值，清除须用专门操作；界面不回显Key，不写浏览器持久化。
2. 主动点击验证，或使用“保存并验证”。验证会访问官方目录，并发送不带业务资料的极小结构化请求，可能收费；打开页面、保存配置和查看历史不会调用模型。
3. 当前Key、模型和超时匹配的验证通过后，明确启用。凭据、外置主密钥或已核对价格缺失时不能调用。

默认两家合计每天0.50美元、20次。一次用户提问可能需要多次模型请求，逐次计入额度，不等于“一次发送只扣一次调用”。验证也计入。费用由本地价格版本和有效usage估计，不能当供应商账户余额或账单。超时、取消、断线或usage不明时会保留待核费用及额度，删除对话不会把费用清零。

账号能否使用某个模型，以实际验证和调用为准。本轮没有可用DeepSeek测试Key，不宣称其真实认证、流式工具调用或业务解读已经通过。用户不能提供第三方中转URL、自定义请求头或任意数据路径。

## 直接提问

从导航进入「AI助手」直接聊天，也可在盘面或个股页点击「问AI」快捷进入，并自动带上观察日期或股票。三处使用同一份历史，不重复创建消息。桌面左侧为紧凑历史，右侧为主对话；手机端历史可折叠。输入框固定在对话区底部，模型切换和模型设置位于输入框下方。没有本地/联网模式选项，也不必先生成一份固定解读。建议问题仅填入输入框，不自动发送；输入最多2000字。

助手主要回答A股行情复盘、交易时段、公司经营、估值、公告及个股研究。可以直接解释市盈率等通用概念；明显无关的话题会简短说明范围。涉及实际公司、行情或资金事实时，按问题查询本地已保存资料；确需外部资料且当前模型支持时，再规划受限网络搜索。它不会运行SQL或代码、采集新行情、保存策略、加入自选或下单。

页面观察日和标的是起点，不是后续问题的上限。可以在旧对话直接问“今天竞价怎么样”“今天午间什么方向突出”，或明确指定其他日期；“今天”由服务器实际北京时间解释，不会永远沿用旧会话的历史日期。不同日期、材料获取时间和来源披露日期应分别看待。

本轮只有三种受限内部读工具：盘面资料、资料可用性、个股已存研究。模型不能指定文件路径或任意SQL；工具不联网、不创建行情任务、不延长研究缓存。额外部署只读源如有配置，也只提供已存日内记录，其他资料仍读当前实例或明确未知。

## 盘面与时段状态

盘面工具可分别查竞价、午间、午间到收盘、完成日概览和已有资金来源。概览优先日盘广度、四指数、成交额及前日涨停队列反馈；若今天还没有完成日行情，就显示今天最新已存时点，不借旧日数据冒充今天。比较多个时段需要分别读取其资料，因此一次回答可能有多次内部查询。

界面或答案中应区分：

| 状态 | 含义 |
| --- | --- |
| 尚未到时点 | 今天还没到竞价结束09:25、午盘11:30或收盘15:00，不是漏采 |
| 已到但未采集 | 观察时点已到，所选日还没有保存记录；计划采集时间尚未到会另行说明 |
| 已保存 | 有对应日期记录，正文仍要通过日期、SHA与来源权限核验 |
| 未知 | 资料或已核验日历不足，不猜零、不按星期几假定休市 |
| 休市 | 有已核验日历支持，不能仅凭没有行情判断 |

竞价方向只代表冻结候选样本；方向仅含一只股票时，不能推广为整板块强弱。午间方向来自实际保存的行业/概念指数；收盘涨停计数可能只覆盖原重点名单，不能当全板块或全市场排名。行业、概念可重叠，融资融券等宽标签不能直接叫主线；原成员日期不会用当前名单改写。

午间与收盘同股票累计成交额的差只能称可核验范围的成交额增量，不是净流入，也不是连续逐分钟资金路径。独立资金来源不存在时明确缺口，不拿指数或股票成交额代替。供应商主力净流入分类本身也不等于机构真实账户流向。

## 个股资料与网上补查

个股工具从当前实例读取已保存且未过期的v2研究；默认按页面证券及报告身份查询，不重新抓行情、公告或新闻，也不延长父研究七日缓存。财报、估值快照、主营分类、公告标题和技术观察有各自日期与口径；公告标题不代表已经读过全文，技术参考位不等于目标价。

没有当前可用报告时，可以使用同股旧会话已保存的材料，并明确其旧日期；不能借用另一只股票或把旧材料说成最新。报告到期不影响已经完成AI消息的历史阅读。材料显式禁止外发或AI处理时会排除；未取得的数据不能由模型记忆补齐。

联网目前只支持已验证启用的OpenAI `gpt-6.1-sol`，不能自动将其他服务切过去。模型先规划搜索，随后才启用一次官方原生搜索；概念解释或本地资料足够时可不联网。范围限巨潮、交易所及指定正规财经数据/新闻子域，不开放任意网址抓取、股吧或自媒体转载入口。

经营与财报数字优先公告、财报PDF、交易所原文或正规数据页；来源发布日期未知就保持未知。网络现在补查的内容和本地历史时点分开，不能倒填成历史当时已知，也不能写成本地实盘行情。原生引用证明出处关联，不表示所有网页数字已逐项对账。

联网另有费用与保守预留。目前每次搜索额外保守预留0.33美元，不是固定实际扣费；有效回执无法证明搜索内容已包含于input时，费用继续待核。安装默认预算仍是0.50美元/20次。为保留历史失败及未知费用，并完成新链路和用户继续试用，用户试用实例显式设置10美元/100次、超时60秒；这些是本地准入额度，不是已扣款，也不改变安装默认值。历史费用没有清零。

## 流式回答与来源

发送后会显示查询状态和逐段文字，工具查询来源可展开查看。答案应先回答问题，再解释依据，只说明影响判断的具体不足，不再强制输出“冻结材料/原事实/假设”审计模板。新自然回答不要求旧式指标占位符，也不声称所有数字自动验真。

每轮实际取得的工具结果、日期、来源身份和网络引用分别保存到该条消息；下一轮取得新资料，不会改写旧答案。工具结果每次最多24KiB，完整模型请求最多96KiB，容量不足按整条材料排除并说明范围，不截断单位、日期或缺口。个股公告、板块尾项等可能未全部送出，不能把“有该报告”理解为“所有原始材料都读过”。

断线后“重新连接”只续读已有流，不重新生成或再次发送问题。流事件是临时记录，完成后以历史消息为准；刷新可以恢复已完成正文。离开页面不会取消请求。点击取消后可能保留已输出的部分文字，须按“未完成”看待；已发送部分可能已经计费。没有自动付费重试、修复、换服务或暂停继续。

## 继续旧对话与管理历史

旧对话可以直接继续问今天或新日期，每轮重新准备当前角色和工具。旧JSON、旧固定材料或旧联网消息保留原文并按旧格式显示；它们的历史材料范围不再限制新轮次查源。无需仅为更新日期或获得新回答格式而新建对话。

同一对话仍绑定服务、模型和凭据代际。换Key、模型或服务时须显式新对话，旧历史仍可读；单纯调整超时不会永久锁死旧对话，但当前配置必须通过有效验证。在途任务若遇关闭或配置变化仍会停止，不会快速重开后复活。

历史默认保存30天，创建、发送与调用完成等主动活动更新时间；浏览列表、详情或流不会续期。点击“保留”可免于自动到期；取消保留不重新给30天，原期限已过的记录可能立即不可见。最多200个会话，每个40条消息，用户与AI各算一条，不是40轮。

发送时只带最近最多4条已完成消息、总历史最多8KiB及本轮问题，更多旧消息仍留在历史中，不全部发给模型。没有跨会话检索、全站自动检索记忆或向量库。需要引用更早问题时可重新说明。

删除会话会删除消息、来源和流事件；有running任务应先取消并等结束。原研究、行情、策略和自选不受影响，独立用量与费用凭证仍保留；这类独立任务及计费审计当前没有自动到期删除。恢复备份默认关闭AI并使旧验证过期；发送后未完成项需人工核对费用，不能自动补发，重新验证并显式启用后才继续调用。

## 实现与验证记录

实现复用现有React/TypeScript、FastAPI、Pydantic、httpx、SQLite与凭据加密，没有引入LangGraph/PydanticAI框架、向量库、Redis或第二个worker进程。唯一worker内AI控制线程管理任务、只读工具与逐次计费；HTTP线程只处理供应商网络。API仅回放本地SSE，不代替worker发请求，工具不打开行情写入DuckDB。

## 流式阅读与股票范围修正（2026-11-02）

输出时自动跟随新内容向下滚动；上翻阅读后暂停跟随，可点“回到最新”或手动滚到底部恢复。最终正文重排仍遵循当前阅读选择，不把用户拉回回答开头；已有历史打开仍定位末答开头。生成中的标题、列表、粗体和表格也采用安全排版，原生来源仅在最终校验后成为链接。

助手只讨论股票研究、上市公司经营估值、行情复盘及明确的股票影响分析。独立房价、天气、旅游、购物、写作等话题不展开、不追问补充城市，也不调用资料工具或网络；“房价→北京的”按最近用户话题处理，旧助手跑偏不授予权限。真正的房地产板块业绩、地产数据对地产股影响仍属于股票用途。范围不明确时先说明或澄清股票用途。

运行时先根据真实用户消息作保守资源授权，再对读取、联网计划和实际搜索发送进行复核。检索用途和用户原话必须相符，模型自己的解释、默认market会话类型或页面股票锚点不能替代用户授权。不另增一个付费分类模型；无关问题用于理解和简短拒答的已有模型请求仍可能产生少量Token费用，不能宣称任何输入都零费用。目录身份识别仅使用本地真实证券目录，不查询价格或延长研究缓存。

本次新增326项AI后端检查通过；流式滚动的4组尺寸/主题、46个逐步样本以及真实移动触摸回归通过。另8组真实页面GET检查通过。本轮没有新发真实付费模型测试；保存原有对话和账目，未重置用量。试用额度为每日10美元/100次模型请求，模型请求次数不等于问题数，金额包含待核预留而非供应商账单。恢复后正常提问会按所选模型产生费用。

板块区间涨幅排名暂缓接入；目前不能将单日部分指数观察冒充“最近几天全板块排行榜”。以后接入须先验证真实行情窗口、交易日与覆盖范围，并优先使用本系统数据。

本次未新增真实付费测试，特指本轮滚动与范围修正的检查，不包括上一阶段真实模型联测和用户手动问答。范围门槛v2额外拒绝“提及公司名但实际购物娱乐”和任意前缀继承；真实公司身份本身不等于股票研究用途。

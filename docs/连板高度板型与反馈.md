# 连板高度、板型与次日反馈

一只股票可以同时显示“二板、一字涨停、缩量”等信息。它们描述不同维度，展示时分别核验，不把题材、板型或封单快照当作未来表现结论。

| 维度 | 含义 | 主要证据 |
| --- | --- | --- |
| 连板高度 | 来源记录的首板、二连板、三连板等 | 指定日来源连板数与同日真实收盘涨停核验 |
| 当日板型 | 一字涨停/跌停、地天板、非一字涨停、开板情况 | 未复权日K、涨跌停来源池及有日期的来源字段 |
| 量能变化 | 较严格前一交易日缩量、平量或放量 | 同证券相邻交易日正成交量与公司行动可比性 |
| 次日反馈 | 晋级、跌停、大幅回落、回落、正反馈等 | 昨日确认样本、今日原始价格及独立涨跌停证据 |

## 标签怎样形成

- **首板、二连板等**：来源正整数连板数经同日收盘涨停核验后展示。未封板股票若仅有昨日高度，须明确标为昨日高度，不能把冲击二板显示成已封二板。
- **一字涨停、一字跌停**：正成交量下原始开高低收同价，并通过同日收盘池核验。它是日K成交形态，不证明盘口全天持续封死。
- **地天板**：沿用[个股成交形态标记](个股成交形态标记.md)的同日原价与涨跌停参考价核验，不还原触板先后或回封路径。
- **非一字涨停**：原始日K存在成交价差且收盘确认涨停，可作为常说的换手板观察；成交价差本身不能衡量换手是否充分。
- **开板N次**：保留指定日来源记录的次数；来源冲突或缺失时不补0。**反复开板**采用来源次数至少3次的项目观察阈值，便于识别俗称烂板的反复开板样本，不称交易所标准分类。
- **炸板来源样本**：依据当日炸板来源池并核验标的、日期与价格。能否确认收盘未涨停须另看收盘证据；不能只因涨幅没到10%就推算炸板。
- **缩量、放量**：比较严格相邻交易日成交量，今日低于昨日即缩量，高于即放量，相同即平量。缺报价、零量、重复或公司行动影响可比性时保持未知；一字板与量能标签可并列。

首末封板时间、开板次数、封单资金和换手率各自保留来源。日末封单金额只代表该次快照，不能还原全天封单稳定性或成交意愿。

## 连板样本反馈怎样看

默认按**已核验的昨日连板高度从高到低**排列，未知高度排后；表头仍可手动排序。昨日高度、今日板型和今日反馈分别展示。高度缺证据时，排序与概览分组也保持未知，不因原始来源留有一个数字就排在前面。

同高度按证券代码排列。切日期或从不同盘面入口查看时，标签必须匹配同一证券、观察日和行情代际；跨日、跨代际或无效证据不展示。高度未知不影响其他独立有据维度，但不能从原始未核验高度补回排序或概览。

收盘涨停/跌停使用原价与来源池确认。一般价格反馈使用昨日到今日的可比收盘收益；大幅回落采用收益不高于−5%的项目观察阈值，含等号。它不代表某个实际买入价的盈亏，不能将其自动解释为所有追板者都吃了大面。

“正反馈”描述收盘上涨。若提供回踩收回观察，则必须同时有昨日参照和今日低点、收盘；日价观察不能证明真实资金承接或明日延续。未晋级不自动等于跌停，单纯收盘上涨也不自动等于晋级。

## 数据范围与公开资料

总览的炸板前五、封单收盘快照，梯队及当日主线，市场情绪的有据个股观察名单和连板反馈使用同一展示口径。标签绑定标的、观察日与行情代际；缺证据时不补造板型。标记不改变选股、策略跟踪或回测条件。

读取按展示范围批量核验：总览两组前五共用最多10只股票的前日/当日报价批次，反馈共用返回队列的前日/当日批次，梯队复用已有的有界三日报价。不逐股读取全历史，也不为展示发起采集。这是读取范围约束，不等于已完成全市场耗时或并发压力测试；实际首读、暖读与慢项须另行记录。

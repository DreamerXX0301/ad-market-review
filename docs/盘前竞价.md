# 盘前竞价

入口为「盘面研究 → 盘前竞价」。它把昨天的判断和今天的开盘定价放在一起，回答：原来关注的股票今天怎样开，哪里明显偏弱，开盘后还需要核对什么。

## 明早怎么用

1. 盘后先照常完成增量，并保存当日复盘或逐股主线。没有保存也能看已核验事件背景，但系统不会替你补写昨天的判断。
2. 明早首次打开竞价页默认查看当天，无需再点「今天」。若之前手动固定了历史日期，会保留选择并醒目提示“正在查看历史数据”，点击「回到今天」恢复默认浏览。默认模式切回基础行情查看最新已发布盘后日，再回竞价仍看当天。9:25之前可以查看最近已发布日的复盘准备，标明尚未冻结，严格前一交易日待采集时核实；它不是今天的竞价报价。
3. 在「数据中心 → 自动采集计划」开启自动盘前竞价。服务仅在北京时间 **9:25:30至9:30前**按每日计划触发，浏览器不用一直开着；竞价页只查看状态和原结果，不提供单次、手动采集或手填名单。默认优先昨天留存的关注、原主线、自选，再加入昨日已核验涨停及炸板样本，最多100只。重复股票按代码去重，省略数量明确显示；不为浏览历史另建名单。
4. 从“昨天怎么看”开始，逐股核对今天竞价价格、涨幅、金额和量比。低开样本可优先检查，完整名单支持排序；缺报显示未知，不按0处理。
5. 开盘后按列出的事实条件观察承接。盘后运行日常增量，再展开「盘后核对」，看同一冻结名单从竞价到收盘的价差，检查观察是否有价值。

盘后核对已展开时，盘后增量成功完成（含有缺口、无新增的完成结果）会自动重新读取已发布行情；收起、离开竞价页或浏览器隐藏时不为此后台读取，之后展开或返回页面会自动读最新结果。保留「读取盘后结果」按钮作为手动刷新入口。暂停、取消、失败以及午评/竞价采集完成不视为成功盘后增量；自动刷新只读取结果，不创建或重跑取数任务。

盘后核对沿用早上的“一字涨停开·参考、高开延续、修复观察、平开、转弱观察、低开延续”等原分组，用一张对照表列出股数、竞价均幅、收盘均涨幅、竞价至收盘均变化和有效覆盖，点整行展开个股。收盘均涨幅相对原竞价来源前收，竞价后变化相对竞价价；两者分开计算，不按收盘结果重新分强弱。缺失或开盘价不一致的股票保留实际核对情况，缺前收不反推，未知不计为0。行业概念点选后按同一子集重算；盘后数据未发布时先展示原组及股数，收盘数据为“—”，发布后自动补上。

盘后区域也提供原关联行业概念快捷卡片，显示关联股数和明确标注的“收盘均”；只用该组原冻结成员与有效收盘报价交集，缺失和开盘不一致不计为0，发布前为“—”。点选与前面的强弱对照、观察单同步，再点取消。展开个股后，股票下方以一行显示主要行业、概念，点开可看完整标签并复制代码；标签弹层里的均幅明确标注为竞价均幅，原成员档案日期保留，不用当前行业概念补历史。

新安装默认关闭自动采集。打开页面、切换日期或重启只会读取既有状态，只有已明确开启的自动配置才能到时触发。仅来源暂未就绪时，原每日自动授权可在窗口内有限重试原任务，名单与原判断保持首次冻结版本。手动创建、重试、继续、暂停和取消均被拒绝；此前已保存的停止记录不再继续，也不会因关闭再开启计划而复活。排队超过9:30或跨日不能补造竞价。

## 服务到时自己运行

自动采集由项目唯一worker执行，保存开启且服务在合法窗口运行时才能开始，不依赖页面定时器。页面显示自动状态、服务是否在线、下次候选时间和最近执行结果；采集中与午评、盘后增量一样显示全局进度，禁止重复操作，完成后进入对应日期结果。

电脑和worker须在采集窗口保持运行。服务没有启动、电脑休眠或长任务忙过9:30时会标明跳过，不在醒来后补造盘前快照。非交易日由来源日历核实，没有确认行情时保持未知。

来源仅暂时未就绪时，自动授权可在原窗口内有限重试同一任务，最多3次；原名单不漂移。当天已有原任务或旧版留存快照时不会再建一份。此前已暂停或取消的任务不会自动继续；关闭计划只影响后续自动采集，不停止已经提交的任务。

自动设置随SQLite备份保留，但恢复到独立副本时强制关闭，需要再次明确开启，防止预演和现用安装同时取数。旧版单次或手填名单配置只保留历史信息，不再触发新任务；在数据中心重新保存每日开关后按当前规则执行。此设置只授权竞价终态采集。

## 页面怎么设计

- **昨天怎么看**：引用采集开始前已经保存的严格前日复盘、逐股主线和关注股，显示原文、实际保存时间和来源身份。我的判断与来源转述分开；没有原判断时明确缺失，不拿当前题材补历史。
- **今天发生了什么**：展示候选覆盖、高低平开、中位涨幅、样本竞价额，以及原关注股的逐项对照。名单有优先顺序和容量说明，省略多少只明确显示；这些统计仅代表所选样本。
- **昨日到今日的反馈**：把“昨日炸板→今日高开”的修复观察、“昨日涨停→今日低开”的转弱观察，以及高开延续、低开延续、平开待确认分开看，列数量、均幅与股票。缺事件、缺报价、两池冲突各自保持未知；“被大盘拖累”保留为待核对解释，不替系统判定个股下跌原因。
- **一字涨停开·参考**：放在强弱卡片最前，从修复/高开延续中单列。用原竞价前收按股票常规市场10/20/30%档、人民币分取整计算参考价，必须与有正成交量的有效竞价价精确相等。因此10.07%或9.98%也可能匹配，不能简单用涨幅≥10%筛。ST、新股名称等不猜档，缺参考输入才显示待核验。它是涨停开参考筛选，来源尚无当日直接限价，未核验例外，不代表全天一字、封单稳定或能成交。股票与均幅来自真实竞价，和其他强弱组互斥；可继续展开、复制代码及按行业概念联动。
- **题材数量与均幅**：按原成员档案分题材/行业显示本次样本股数、有效均幅，可排序并点数量展开股票。档案日期和竞价日期分开显示；同股跨题材的数量不可相加，均幅不是板块指数涨幅。
- **开盘后核对什么**：把原关注理由和本次竞价价放在一起，列出需要继续观察的条件。高开、量比和标签都不直接变成买入信号，也不自动写策略或跟踪。
- **盘后再看**：只对原冻结名单使用同日已发布的真实未复权行情，缺价、无成交和开盘价不一致各自说明。价差是事后事实，不是能以竞价价实际成交的收益承诺。

来源短线风向标单独列示，它不是全市场基准。可按竞价涨幅切换「高→低」和「低→高」，默认高的在前，缺失值始终最后。请求明细、响应阶段和SHA等技术证据由后台留存与校验，普通竞价页面不展示。个股图表截止竞价日前已发布收盘日，不让今天盘后图表混进盘前观察。

表格入选背景使用短标签：红色“昨日涨停”、黄色“昨日炸板”、蓝色“自选/自定义”、紫色“昨日关注/主线”。鼠标停留可查看原始来源说明。

## 为什么只做终态

沪深开盘集合竞价为9:15至9:25，9:20至9:25不能撤单。本系统固定从9:25:30起采集最终结果，30秒是系统缓冲而非交易所要求；没有连续挂单轨迹，不推断撤单、抢筹或封单稳定。[上交所规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、[深交所说明](https://investor.szse.cn/institute/video/classroom/knowledge/t20100721_537821.html)。

真实接口在未就绪时也可能返回完整数值。程序接受已核验的`final/ready`及`matched/final`两组终态标记，同时验证当日时窗、价格涨幅及量额；保留来源原值，其余错组和未就绪状态仍拒绝。来源时间戳是响应组装时间，不能冒充每只股票的行情时刻；未就绪数据不能拿旧开盘价替代。[同花顺接口说明](https://fuyao.aicubes.cn/docs/api-reference/auction/)。

窗口外收到的来源响应不采用；窗口内已核验合法竞价仍可在有效租约下保存。如果可选基准恰好过窗，基准显示未知，竞价保存为部分可用，不补请求、不丢弃此前合法报价。

价格和竞价额为人民币元，成交量为手，百分数保留来源原值。成交额不叫净流入，未匹配量不表示买卖方向。缺报不等于停牌；没有历史竞价留存时，不用历史开盘价倒造一份“当时的竞价”。

## 保存与版本

快照、原名单、昨日原判断和有界来源原件一起保存于业务SQLite，正文不可变并核验SHA。标准业务备份会保存仍在保留期内的证据；与午评一致，保留28个自然日，到期随已授权的新成功盘后增量滚动清理。未运行增量时暂留，清理按实际发布行情日计算窗口，不按电脑时钟猜测交易日。密钥不进入页面、原件或导出。

行业概念及共振统计按竞价引用的原成员代际复算，不另存一份逐日页面。在竞价正文仍保留时，通用清理会识别原代际引用，保护对应来源及共享文件；标准备份包含仍可用的来源闭包。到期清理移除竞价快照与内嵌原件，保留日任务台账、清理回执和必要任务审计；共享行情/成员来源按现有引用及存储规则处理，不由竞价清理直接删除。保留成本也包括仍被其他业务引用的来源和任务审计，不能只按竞价JSON估算。原件缺失或SHA错误时保持未知，不使用当前成员回填历史。自动采集不等于每日自动备份，也不创建异机或云备份。

0.1.14升级到0.1.15无新增迁移，仍须使用独立版本目录和恢复副本验收；更早安装按升级路径追加030、031、032。不能直接迁移或替换现用唯一业务库。自动配置默认关闭，恢复副本须再次明确开启。独立预览的观察和采集保存在预览副本，正式版本切换遵循[版本升级与回滚](版本升级与回滚.md)。接口、数据单位及验收边界见[竞价契约](../contracts/auction-snapshots.md)。
# 题材共振

点选关联卡片后，有关联个股的强弱卡片自动展开并高亮股票；切换所选组会重新展开。取消后恢复全部及默认折叠。

强弱卡片中“一字涨停开·参考”固定置前，其余按竞价均幅从高到低排列，平开0%位于正负均幅之间，缺失均幅最后，同值保留原分类顺序。点选行业概念后，先按子集重算均幅，再重新排序；卡内股票默认按昨日板高降序、同层竞价涨幅降序，可在展开列表内调整。

上下两处主要关联卡片可直接点选，强弱对照和观察单同步只显示该组关联股票，再点一次或“取消选中”恢复全部；选择绑定观察日期，翻页在新选择后回到第一页。关联卡片不再复制代码，股票代码及逐股归属代码仍可复制。卡片上的数量及均幅属于原候选交集；筛选后的强弱分组数量与均幅重新按所选股票有效报价统计，不把缺失算成零。

共振表的名称、前列命中、集中倍数、竞价均幅、中位数和高开占比均支持点表头双向排序；名称首次按中文升序，数值首次从高到低，缺失始终放后，先排序全部合格分组再展示15组。前列命中按命中家数，高开占比按原始比例排序，不按四舍五入的显示文字排序。

竞价观察单与强弱对照直接展示主要关联行业概念：至少3只有效样本，按本次候选关联股数选取每类前2组，显示关联数量及竞价均幅；不使用下拉筛选。观察单每页20只，可批量复制全部代码。每个归属标签显示该组本次候选的等权竞价均幅，缺少有效报价时不补零；多题材不再平均成一个混合值。强弱卡片采用紧凑两行，完整归属与代码在弹层查看；题材汇总和共振表可点击整行展开，复制按钮不触发展开。

个股在强弱对照、低开复核卡片和竞价观察单中统一展示行业与概念，默认折叠较多标签，保留完整归属及成员档案日期；未核验时显示待核验。行业、概念和股票代码均可独立复制，分组支持批量复制股票。题材共振及行业概念汇总支持全部/概念/行业筛选；固定列宽，股票在独立整行展开为名称、代码和竞价涨幅小卡片，可按昨日板高或本份真实竞价涨幅排序，不取盘中涨幅。

“题材共振”把有效竞价涨幅前20只与原成员档案对照，查看强势样本是否集中在同一题材或行业。默认按集中倍数从高到低，也可按均幅和命中数排序；同时显示均幅、中位数和高开占比，点开方向可看命中的股票。每组至少3只候选且命中前列至少2只，展示前15组。集中倍数大于1表示组内前列占比高于全部候选的前列占比，不是收益预测。

一字涨停关联方向单列。当前竞价快照没有可靠的今日涨停价与一字证据时显示“待核验”，不凭接近10%的高开或昨日标签认定一字，不编造剔除锚股后的数据。题材统计来自本次最多100只候选，成员档案日期与竞价日期分别显示，不代表完整板块。

## 页内目录

竞价页左侧提供“竞价概览、自动采集、强弱对照、昨日复盘、低开复核、题材共振、行业概念、竞价观察单、来源基准、盘后核对”目录；当前区自动高亮，悬停显示说明，窄屏改为顶部横向目录。目录只跳转本页实际存在的区域，不改变观察日期；定位盘后核对时自动展开对应内容。


## 按昨日板高找股

强弱对照和竞价观察单都有“昨日板高”快捷筛选：首板、二板、三板、四板、五板及以上和其他/未核验。标签明确写“昨日”，五板及以上的个股仍显示实际高度，例如昨日六板；不是今天已经连板晋级。

数量和竞价均幅只针对这份最多100只冻结观察样本。只有严格前日已核验的涨停高度才能归入对应层级，炸板、缺档或冲突不会算作首板。均幅只统计有效竞价报价；无有效值显示“—”，不以0填充。筛选和行业概念条件可组合，两处共用本日选择；再次点选取消，切日期重置，不改原强弱分类或历史快照。

观察单默认按昨日板高从高到低，同一高度按竞价涨幅从高到低，仍可点表头调整。强弱卡片保留原分类，组内采用同样的顺序。板高汇总在浏览器本地完成，不增加取数成本。


## 展开个股的标签

竞价观察单、低开复核、强弱卡片、题材共振及行业概念展开后的个股，共用昨日事件和上市板块标签。已核验的前日涨停显示“昨日首板”或实际“昨日N板”，前日炸板显示“昨日炸板”；缺档或冲突保持未核验，不凭当前高开、题材关联或今天的板数补写。

主板、创业板、科创板和北交所标签按这份冻结股票代码及交易所后缀分类，无法识别时保持未知。它只方便浏览当前代码分类，不证明历史上市身份，也不作为涨跌停制度或策略筛选依据。标签来自本地只读派生，不额外取数，不修改原竞价快照或SHA。


展开后的股票列表可独立按“昨日板高”或“竞价涨幅”切换升序、降序，默认昨日板高从高到低、同层竞价涨幅从高到低；未知放后。也可点全部、主板、创业板、科创板、北交所或未知，只看当前组对应股票；“当前N / 本组M”区分筛选后的数量与原组数量。

这些选择只作用于各自展开卡片，互不影响；换日期或题材后恢复全部和默认排序。不改变上方强弱分类、原分组统计和前列标志，不改全局筛选、策略或原竞价数据，也不额外取数。

### 采集防误触与进度展示

盘后增量、盘前竞价和午评运行时不提供暂停/取消；任务记录与HTTP控制入口同时执行此限制。保留当前阶段、已耗时、历史样本支持的预计剩余范围与结果查看；样本不足不编造倒计时。关闭浏览器不停止已提交任务，关闭自动计划只影响未来触发。旧版/恢复副本中已保存的暂停、取消状态仍保留，按原规则处理，不自动复活。

### 看一字板所在方向有没有其他个股跟随

板块列表默认“聚焦方向”：先收起融资融券、沪深股通等通用属性及不足3只候选的零散方向，每次显示20个方向，可继续展开。页面会显示收起数量；想查完整归属时切换“全部关联”。机器人、商业航天、公司产业链等真实题材仍保留，这只是减少列表噪声，不删除原标签或改变统计。

个股卡片优先显示当前选中的题材，每类先看一个标签，“其余”可展开全部关联。例如选中商业航天，右侧先显示该题材，不让融资融券占住首个概念的位置。板块均幅仍是该标签原候选交集的统计，显示顺序不会改变数值。

进入“竞价板块与个股”，选择“观察锚股”，左侧会限定为它关联的行业、概念。点击方向，右侧显示剔除锚股后的高/平/低开家数、中位涨幅、有效报价覆盖及昨日梯队；可进一步选择“较低板高且高开”。这比只看整组平均涨幅更容易分辨是一只股票突出，还是其他候选也有高开表现。

左侧“昨日最高”来自本组冻结候选的严格前日已核验板高，例如昨日2板；点击表头可升降序排序。它不是今天的晋级高度，也不代表未采集的板块全体成员。没有证据时显示待核验，炸板单列，不能把未知当成首板或0板。

目前原“今日一字涨停关联题材”自动识别为待核验：这份终态竞价只有一个时点，缺少直接核验的今日限价与连续封板证据。因此锚股是手选观察基准，不自动标成今日一字。原“竞价涨停开参考”仍只是常规档价格参考；昨日确认一字、今日竞价涨停、盘后确认全天一字属于不同日期/时点的事实。

“较低板高”仅指昨日连续板数低于锚股，并非股价低位或预测冲板。统计只覆盖本次最多100只冻结候选；观察同概念、同业行业有共同表现，仍不证明实际上涨由某只锚股带动。盘后核对继续在原入口独立展示，收盘结果不会提前混入竞价排序。

设计参考了公开报道中“前排竞价与同题材股票同时列示”的方式：[财联社竞价观察案例](https://www.cls.cn/detail/2483031)也呈现同方向不同股票的分化；[证券时报板块行情案例](https://www.stcn.com/article/detail/3765217.html)记录了一字开盘与其他成员涨停并存的情况。它们是观察案例，不提供可直接沿用的命中率。竞价撮合和报价时点依据[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)，以实际证据区分竞价与全天表现。

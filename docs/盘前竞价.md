# 盘前竞价

入口为「盘面研究 → 盘前竞价」。它把昨天的判断和今天的开盘定价放在一起，回答：原来关注的股票今天怎样开，哪里明显偏弱，开盘后还需要核对什么。

## 明早怎么用

1. 盘后先照常完成增量，并保存当日复盘或逐股主线。没有保存也能看已核验事件背景，但系统不会替你补写昨天的判断。
2. 明早打开竞价页，点击「今天」。9:25之前可以查看最近已发布日的复盘准备，标明尚未冻结，严格前一交易日待采集时核实。
3. 可开启「服务自动采集」，选择今天一次或每个交易日。服务会在北京时间 **9:25:05后、9:30前**自行触发，浏览器不用一直开着；也保留9:25至9:30前的手动入口。默认优先昨天留存的关注、原主线、自选，再加入昨日已核验涨停及炸板样本，最多100只。也可输入最多100个完整股票代码，例如`600519.SH`，只观察指定名单。
4. 从“昨天怎么看”开始，逐股核对今天竞价价格、涨幅、金额和量比。低开样本可优先检查，完整名单支持排序；缺报显示未知，不按0处理。
5. 开盘后按列出的事实条件观察承接。盘后运行日常增量，再展开「盘后核对」，看同一冻结名单从竞价到收盘的价差，检查观察是否有价值。

新安装默认关闭自动采集。打开页面、切换日期或重启只会读取既有状态，只有已明确开启的自动配置才能到时触发。手动失败可在原日窗口内重试原任务，名单与原判断保持首次冻结版本；暂停须手动继续，取消后当天不重新采集。排队超过9:30或跨日不能补造竞价。

## 服务到时自己运行

自动采集由项目唯一worker执行，服务运行就能到时开始，不依赖页面定时器。页面显示自动状态、服务是否在线、下次候选时间和最近执行结果；采集中与午评、盘后增量一样显示全局进度，禁止重复操作，完成后进入对应日期结果。

电脑和worker须在采集窗口保持运行。服务没有启动、电脑休眠或长任务忙过9:30时会标明跳过，不在醒来后补造盘前快照。非交易日由来源日历核实，没有确认行情时保持未知。

来源仅暂时未就绪时，自动授权可在原窗口内有限重试同一任务，最多3次；原名单不漂移。已经手动采集当天不会再建一份。暂停、取消或手动接管后自动调度停止继续该任务，也可随时关闭后续自动采集。

自动设置随SQLite备份保留，但恢复到独立副本时强制关闭，需要再次明确开启，防止预演和现用安装同时取数。此设置只授权竞价终态采集。

## 页面怎么设计

- **昨天怎么看**：引用采集开始前已经保存的严格前日复盘、逐股主线和关注股，显示原文、实际保存时间和来源身份。我的判断与来源转述分开；没有原判断时明确缺失，不拿当前题材补历史。
- **今天发生了什么**：展示候选覆盖、高低平开、中位涨幅、样本竞价额，以及原关注股的逐项对照。名单有优先顺序和容量说明，省略多少只明确显示；这些统计仅代表所选样本。
- **昨日到今日的反馈**：把“昨日炸板→今日高开”的修复观察、“昨日涨停→今日低开”的转弱观察，以及高开延续、低开延续、平开待确认分开看，列数量、均幅与股票。缺事件、缺报价、两池冲突各自保持未知；“被大盘拖累”保留为待核对解释，不替系统判定个股下跌原因。
- **题材数量与均幅**：按原成员档案分题材/行业显示本次样本股数、有效均幅，可排序并点数量展开股票。档案日期和竞价日期分开显示；同股跨题材的数量不可相加，均幅不是板块指数涨幅。
- **开盘后核对什么**：把原关注理由和本次竞价价放在一起，列出需要继续观察的条件。高开、量比和标签都不直接变成买入信号，也不自动写策略或跟踪。
- **盘后再看**：只对原冻结名单使用同日已发布的真实未复权行情，缺价、无成交和开盘价不一致各自说明。价差是事后事实，不是能以竞价价实际成交的收益承诺。

来源短线风向标单独列示，它不是全市场基准。可按竞价涨幅切换「高→低」和「低→高」，默认高的在前，缺失值始终最后。原件SHA、请求及接收时间等证据可展开查看，主体阅读不被来源细节打断。个股图表截止竞价日前已发布收盘日，不让今天盘后图表混进盘前观察。

表格入选背景使用短标签：红色“昨日涨停”、黄色“昨日炸板”、蓝色“自选/自定义”、紫色“昨日关注/主线”。鼠标停留可查看原始来源说明。

## 为什么只做终态

沪深开盘集合竞价为9:15至9:25，9:20至9:25不能撤单。初版冻结9:25之后的最终结果，没有连续挂单轨迹，不推断撤单、抢筹或封单稳定。[上交所规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、[深交所说明](https://investor.szse.cn/institute/video/classroom/knowledge/t20100721_537821.html)。

真实接口在未就绪时也可能返回完整数值。程序接受已核验的`final/ready`及`matched/final`两组终态标记，同时验证当日时窗、价格涨幅及量额；保留来源原值，其余错组和未就绪状态仍拒绝。来源时间戳是响应组装时间，不能冒充每只股票的行情时刻；未就绪数据不能拿旧开盘价替代。[同花顺接口说明](https://fuyao.aicubes.cn/docs/api-reference/auction/)。

价格和竞价额为人民币元，成交量为手，百分数保留来源原值。成交额不叫净流入，未匹配量不表示买卖方向。缺报不等于停牌；没有历史竞价留存时，不用历史开盘价倒造一份“当时的竞价”。

## 保存与版本

快照、原名单、昨日原判断和有界来源原件一起保存于业务SQLite，正文不可变并核验SHA。标准业务备份会保存这些证据；初版长期保留，与午评28日清理独立。密钥不进入页面、原件或导出。

新版必须在独立版本目录和恢复副本完成迁移030、031及验收后使用，不能直接迁移现用唯一业务库。自动配置默认关闭，恢复副本须再次明确开启。独立预览的观察和采集保存在预览副本，正式版本切换遵循[版本升级与回滚](版本升级与回滚.md)。接口、数据单位及验收边界见[竞价契约](../contracts/auction-snapshots.md)。
# 题材共振

个股在强弱对照、低开复核卡片和竞价观察单中统一展示行业与概念，默认折叠较多标签，保留完整归属及成员档案日期；未核验时显示待核验。行业、概念和股票代码均可独立复制，分组支持批量复制股票。题材共振及行业概念汇总支持全部/概念/行业筛选；固定列宽，股票在独立整行展开为名称、代码和竞价涨幅小卡片，按本份真实竞价涨幅排序，不取盘中涨幅。

“题材共振”把有效竞价涨幅前20只与原成员档案对照，查看强势样本是否集中在同一题材或行业。默认按集中倍数从高到低，也可按均幅和命中数排序；同时显示均幅、中位数和高开占比，点开方向可看命中的股票。每组至少3只候选且命中前列至少2只，展示前15组。集中倍数大于1表示组内前列占比高于全部候选的前列占比，不是收益预测。

一字涨停关联方向单列。当前竞价快照没有可靠的今日涨停价与一字证据时显示“待核验”，不凭接近10%的高开或昨日标签认定一字，不编造剔除锚股后的数据。题材统计来自本次最多100只候选，成员档案日期与竞价日期分别显示，不代表完整板块。

# BOLL选股条件

在策略编辑器中添加条件，选择“BOLL收口与方向”，直接设置方向和参数。它与量能、MACD、KDJ使用同一套“以下全部满足 / 任一满足”条件组；编辑后保存策略，再手动运行。图表BOLL显示偏好和策略参数分别保存，修改副图不会改写策略。

## 先选观察方式

| 方式 | 满足时的价格关系 |
| --- | --- |
| 当期收口 | 当期带宽不高于此前历史带宽的指定分位阈值 |
| 向上突破 | 前一期收盘≤前一期上轨，当期收盘严格高于当期上轨 |
| 向下突破 | 前一期收盘≥前一期下轨，当期收盘严格低于当期下轨 |
| 上方回轨 | 前一期收盘严格高于前一期上轨，当期收盘回到上下轨闭区间 |
| 下方回轨 | 前一期收盘严格低于前一期下轨，当期收盘回到上下轨闭区间 |

突破检查当期刚发生的交叉；已经连续数期处于轨外，不会每天重复算作新突破。回轨要求收盘落在下轨至上轨之间，直接从上轨外跌到下轨外不算上方回轨。盘中最高或最低触碰不替代收盘条件。

“先有收口”开启时，方向条件还要求此前最近R个完整周期至少一次收口，范围为前1至R期，不含当前突破或回轨期。选择“当期收口”时直接检查当前状态。收口本身不决定后续方向。

## 参数与计算

| 设置 | 默认 | 可调范围 / 含义 |
| --- | --- | --- |
| BOLL周期N | 20 | 整数2—250 |
| 标准差倍数K | 2 | 0.1—10的有限数字 |
| 历史分位窗口L | 125 | 整数10—750，以所选周期计 |
| 收口分位 | 10% | 1%—100%，越小筛选越严格 |
| 最近收口范围R | 5 | 整数1—60，以所选周期计 |
| 先有收口 | 开启 | 用于方向条件，可关闭 |
| 中轨方向 | 不限 | 不限 / 向上 / 向下 |
| 中轨方向间隔S | 5 | 整数1—60，比较当前中轨与前S期中轨 |
| 要求带宽扩张 | 关闭 | 开启后，当期带宽须严格高于前一期带宽 |

中轨为最近N期收盘的简单平均；上、下轨为中轨加、减K倍**总体标准差**，分母为N。带宽为`(上轨−下轨)/中轨`，页面以百分比展示。历史分位阈值只取当期之前L个连续可比带宽，以排序后位置`(L−1)×分位比例`在相邻值之间线性插值；当期带宽不进入自己的历史阈值。

中轨“向上 / 向下”分别要求当前中轨严格大于 / 小于前S期中轨；相等不满足。“带宽扩张”只比较相邻两期带宽，不等于价格上涨。关闭“先有收口”的方向条件不要求历史分位预热；开启中轨方向或带宽扩张才增加对应依赖。所有参数按各叶子的日、完整周或完整月周期解释。

数值比较使用绝对和相对各`1e-12`的浮点误差容差；容差内视为相等，避免理论触轨被计算误差变成突破。容差随依据记录，不是额外的涨跌幅门槛。

例如默认当期收口至少需要20+125=145根连续可比周期；突破本身需要前后两组BOLL值，20周期时至少21根。前置收口、方向间隔等条件会按实际依赖要求更多预热。参数范围是输入上限，不表示本地五年数据足以计算750个完整周或月；不足时显示待核验。

## 与放量、MACD、KDJ一起用

可在“以下全部满足”组中依次加入：

1. BOLL向上突破，开启先有收口，参数自行调整。
2. 只要求比前一期多时，选择“成交量大于前一交易日（放量）”并设为“是”，无需填写倍数；也可从“快捷添加条件”选择“成交量大于前一周期（放量）”。需要指定幅度时，选择“较前一交易日成交量倍数≥1.5”。日K均比较前一个市场交易日，不是前20日均量；周/月条件则比较前一个完整周/月。
3. MACD金叉，或MACD柱线>0。
4. KDJ K>D；如需要，再用K值上下限限制范围。

全部加入时四类条件必须在各自周期同时满足。想让MACD或KDJ任选其一，可把两项放进子组“任一满足”，外层继续要求BOLL和量能。金叉要求当期刚上穿，强于只要求持续K>D或柱线为正；条件叠加可能让结果很少，不应因没有候选就认定计算错误。

“放量=是”严格要求成交量增加，相等不算。在前后两期均有有效正成交量时，倍数条件`>1`与其等价，`≥1.5`表示至少1.5倍，`≥1`还包含平量。数值倍数保留原有口径，例如零量当日可能为0；放量、缩量布尔条件另要求当前及前期均有可核验的正成交量，零量或缺量保持未知，不能把数值0当成已确认缩量。不要使用“成交量 > 字段 成交量”表示较昨日放量：字段比较的两边都取同一周期，这条规则比较的是当期成交量与其自身。新增入口只向当前草稿加入已有条件，不自动改写已保存策略；缺报价、零量停牌或覆盖不足仍待核验。

每个普通条件可独立选日 / 完整周 / 完整月。历史事件的“今日满足”可加入日线BOLL，用于“过去出现倍量或涨停，今天BOLL突破”等组合；“历史曾出现”的事件日扫描暂不接受BOLL条件。它不自动要求收口发生在绑定事件之后，也不修改事件价比较或守位区间。

板块策略使用板块自身指数的BOLL；不会据此生成成员个股信号。个股受限回测和跟踪沿用同一BOLL定义，回测仍受上市身份、可成交价格、费用与其他字段支持范围约束。

## 看懂结果和缺口

条件依据保留配置、观察周期及日期、当期轨道与带宽、历史分位阈值、最近前置收口日及方向比较等有界证据。它不把整段历史行情写进每个候选，也不会用观察日之后的报价反算信号。

策略使用严格市场交易日序列，完整周 / 月必须覆盖应有市场日；缺报、重复报价、无效OHLC、零成交量、公司行动或行动覆盖未知会打断连续可比区间，重新预热。缺数不能跳过去拼成“最近N条有效报价”，也不能以图表连续显示的轨道证明策略已满足。依赖不足保留未知；在组合中仍遵循三值逻辑：全部满足组内已有明确否，则整体为否；任一满足组内已有明确是，则整体为是。

收口、突破、回轨是可复核的观察定义；历史离线样本没有证明这些过滤必然提高收益。研究记录与其成本、样本边界见[BOLL收口突破离线研究](research/BOLL收口突破离线研究.md)。API定义见[工作区条件契约](../contracts/workspace-api.md#boll收口与方向条件)。

## 验收重点

- 参数保存后重开、运行和回测使用同一配置；同一规则中不同N/K或分位窗口互不串值。
- 首次收盘越轨、等于轨道、连续出轨、回轨越过另一侧轨道分别判定；平坦价格、空窗口与预热不足保持明确状态。
- 用前缀行情独立计算，与包含未来行情但指定同一观察日的结果一致；修改未来行情不改变旧信号。
- 日、完整周、完整月及历史事件今日条件在选股、跟踪、回测中对账；未完成周/月、缺整周期或公司行动不回退旧值。
- 回测按证券、周期和不同BOLL计算参数预备指标；不为每个观察日重新计算全部历史。旧规则不因新增BOLL扫描或持久化额外行情。

# 今日划线提醒

顶部铃铛显示最新已发布业务日的划线提醒数量。点开可看最近5条，再点“查看今日提醒”进入自选页。这里的“今日”是应用的行情业务日，周末或尚未完成更新时不会自动切到电脑日期。

自选页的划线提醒分“今日”和“历史”。历史不含今日，可选择截至日期；历史任务补跑发现的旧触发仍按实际事件交易日归档。列表显示持久总数及已加载范围，搜索与状态筛选作用于当前已加载的最多1000条。点击股票可查看对应事件日的K线和冻结依据。

这里只提供顶部数量和记录预览，点击可以查看完整今日列表，不播放声音，不发送浏览器或外部通知。业务日变化、划线核验完成或返回可见页面时重新读取小摘要，不额外启动定时轮询。页面关闭后不承诺提醒。

这里只读取已保存记录，不连接实时行情、不运行规则。新增提醒仍来自已授权的保存划线、手动核验或盘后更新。新线持续跟踪；首次实际提醒后继续60个市场交易日，之后由盘后增量清理线和关联提醒。查看今日或历史均不会延长期限，也不会重复加入自选。

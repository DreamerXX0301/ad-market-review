# 今日划线提醒

自动量价提醒也使用同一个铃铛和提醒列表，带「自动量价」来源标记，手动画线事件保留原规则。入口在个股日K的「量价参考 → 提醒设置」，按股票选择回踩收回、收盘突破、支撑失守或参考止损跌破，可单独要求突破放量。默认关闭，保存后从新的已发布交易日起检查。

点击「保存设置」成功后自动关闭弹窗，并显示保存结果提示；校验或保存失败时保留弹窗与当前填写内容，方便修改或重试。「重新设定短线基准」成功后保留弹窗，便于继续查看基准准备状态。

新建个股规则默认选择「一周短线」，距离上限默认5%，可逐股在0.5%至20%内设置（最多两位小数）。已有历史结构规则继续原模式，只有明确保存才会改变。一周短线把「短线风险线」与真实支撑分开：近端结构不足时显示暂无近端支撑，风险线可按收盘、ATR与距离约束单独生成；历史结构的旧参考止损在界面称「结构失效参考」。

短线监控的风险线从启用或重新设定时准备基准，随后只抬高不下调；收盘失守后保持原基准，不因跌价改用更低的线。设置里展示实际保存的下一交易日价位及失守状态，可点击「重新设定短线基准」显式开启新一轮；有未保存的表单修改时先保存或重新读取。重设增加配置版本、清除旧的下一交易日基准并重新准备，不改变历史事件，也不追溯保存当日提醒。图表按观察日和默认5%上限静态计算，提醒则按逐股配置与持久化跟踪基准核验，两者可能不同。风险线不是个人成本止损，不保证实际成交损失。

每天盘后先使用前一交易日已保存的监控基准检查当天收盘，再更新下一交易日价位。没有事前基准、缺数或除权不可比时不制造触发。支撑压力可能数日不变，ATR缓冲可逐日变化。旧触发价和依据固定保留；关闭自动规则不影响原来的划线提醒。详情见[量价参考](自动支撑压力线.md#自动量价参考)和[接口契约](../contracts/workspace-api.md#自动量价收盘提醒)。

恢复备份得到的新副本会关闭自动量价监控，保留原提醒类型、量能偏好和历史触发依据。需要在副本中重新启用并准备新的监控基准；原手动画线及其历史提醒保持不变。正常关闭浏览器或重启服务不等于恢复备份，不会因此清空配置。

顶部铃铛显示最新已发布业务日的划线提醒数量。点开可看最近5条，再点“查看今日提醒”进入自选页。这里的“今日”是应用的行情业务日，周末或尚未完成更新时不会自动切到电脑日期。

自选页的划线提醒分“今日”和“历史”。历史不含今日，可选择截至日期；历史任务补跑发现的旧触发仍按实际事件交易日归档。列表显示持久总数及已加载范围，搜索与状态筛选作用于当前已加载的最多1000条。点击股票可查看对应事件日的K线和冻结依据。

这里只提供顶部数量和记录预览，点击可以查看完整今日列表，不播放声音，不发送浏览器或外部通知。业务日变化、划线核验完成或返回可见页面时重新读取小摘要，不额外启动定时轮询。页面关闭后不承诺提醒。

这里只读取已保存记录，不连接实时行情、不运行规则。新增提醒仍来自已授权的保存划线、手动核验或盘后更新。新线持续跟踪；首次实际提醒后继续60个市场交易日，之后由盘后增量清理线和关联提醒。查看今日或历史均不会延长期限，也不会重复加入自选。

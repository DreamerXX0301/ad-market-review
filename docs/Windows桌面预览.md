# Windows 桌面原生托盘预览

桌面版号从 0.1 开始，面向 Windows 11 x64 本地试用。业务基线为 b3454f2711d0bf630f552ba768843e11165855d6，完整集成提交、桌面版号、业务版本与依赖摘要以包内 BUILD-MANIFEST.json 为准。盘面研究、自定义研究和管理功能的第一方后端都使用原生扩展。Windows 发布的第一方前端脚本经过混淆。浏览器脚本与原生扩展仍可被分析，签名安装器与正式升级流程另行验收。

## 打开工作台

1. 将 ZIP 完整解压到新目录，双击 `AMR-Desktop-Preview.exe`。启动器常驻 Windows 通知区域，用系统默认浏览器打开本机工作台。若任务栏上暂时看不到蓝紫色图标，可以在右下角的隐藏图标中查看，悬停提示为「冒险的梦想家」。
2. 关闭网页或浏览器后，后台仍会运行。双击托盘图标、右键点「打开工作台」或再次双击 EXE，可以重新打开页面。使用托盘的「退出工作台」后，后台停止接收新任务，等当前工作安全收尾后退出。也可以在新版目录的 PowerShell 运行 `.\AMR-Desktop-Preview.exe --quit` 请求安全退出。
3. 同一 Windows 用户先前激活的有效卡会沿用。授权与工作台在同一个包里。进入授权页后可复制机器码，选取 `.amr-license` 文件并导入。续期时打开「授权管理」，导入新卡即可。
4. 新安装使用空业务库，数据源按原工作台流程配置。初始化与研究手动发起，新安装的自动计划关闭。

API 只监听 127.0.0.1。每次用托盘打开页面会使用短时、一次性的本机启动票据。首次分配端口后优先沿用，端口暂时不可用时换用临时端口，本次的浏览器界面偏好可能与平时不同。授权在本机离线复验。到期后仍可查看机器码和导入新卡，已有任务按安全机制收尾，历史数据留存。签发工具与私钥由卖方保管。 [离线授权契约](../contracts/desktop-licensing-v1.md)

## 导入旧版数据

先从旧版正常退出并等后台任务收尾，再将新版完整解压到新目录。首次启动优先检测上一版托盘数据。没有托盘版业务库时，再检测首版数据。选「导入」后，程序会从已停止的旧版制作备份，独立解压、恢复并核对文件和业务库。校验通过才启用新的数据目录。原程序、原数据及浏览器配置保留，可供回滚。也可在新版首次启动前，从 PowerShell 运行 `.\AMR-Desktop-Preview.exe --import-previous` 完成导入。导入前会检查磁盘空间。

新版使用当前 Windows 用户的本机 NTFS 目录 `%LOCALAPPDATA%\ad-market-review\workbench-tray-native-v1\<验签公钥指纹>`。数据、外置凭据主密钥及版本回执分开存放。导入后保留已核验的恢复包和小回执，授权继续沿用此前的 `license-preview-v1` 身份目录。导入后的排队任务保持暂停，自动计划需要手动开启。若首次启动选择使用新数据，之后的导入流程要求另建独立恢复目录。

后续版本同样先在独立副本验收，再切换程序。旧版本和回滚资料按验证结果留存，每次更新完成空间清理。 [版本升级与回滚](版本升级与回滚.md)

## 真机验收

- 在解压目录的 PowerShell 运行 `.\AMR-Desktop-Preview.exe --diagnose`。结果窗口应包含 api、frontend、worker_once、backup_restore 四项 ok。诊断使用独立空库，并在 Windows 上核验 DPAPI 及原生核心模块载入。
- 双击 EXE，检查默认浏览器打开、有效授权沿用、关闭浏览器后后台继续、再次打开页面、托盘退出以及任务安全收尾。
- 分别用已停用托盘版及首版的独立业务样本测试导入，并确认同时存在两份数据时优先选择托盘版。核对独立数据目录、旧版回滚、授权到期和续期。

# Windows 桌面预览

首版面向 Windows 11 x64 本地试用。业务基线为 b3454f2711d0bf630f552ba768843e11165855d6，完整集成提交、应用版本与依赖摘要以包内 BUILD-MANIFEST.json 为准。私有预览包解压即可运行，包含可读取的 Python 后端源码。签名安装器与覆盖更新流程另行验收。

## 打开工作台

1. 将预览 ZIP 完整解压到新的程序目录，双击 AMR-Desktop-Preview.exe。包内提供 x64 Python、SQLite 和所需依赖，由本机 Microsoft Edge 打开独立的工作台窗口。
2. 同一 Windows 用户先前在授权测试程序激活的有效卡会沿用。若进入授权页，按提示从 .amr-license 文件复制授权内容，导入后点「打开工作台」。
3. 工作台默认打开空业务库。数据源按原工作台流程配置，初始化与研究手动发起。新安装的自动计划关闭。
4. 从工作台「授权与退出」入口结束应用，也可正常关闭工作台窗口。后台有任务时等待控制台提示的安全收尾完成，再启动新包。已有另一个同配置预览运行时，启动器提示正在使用。

API 只监听 127.0.0.1。首次分配端口后优先沿用，端口暂时不可用时换用临时端口，本次的浏览器界面偏好可能与平时不同。窗口用一次启动票据建立本地会话。授权状态独立保护并在本地复验，用户离线也可启用。到期后授权页仍可查看机器码、导入新卡和退出，已有任务按原有安全机制收尾，历史数据留存。 [离线授权契约](../contracts/desktop-licensing-v1.md)

## 程序、数据与下一版

程序目录只放构建产物。预览数据使用当前 Windows 用户的本机 NTFS 目录 %LOCALAPPDATA%\ad-market-review\workbench-preview-v1\<验签公钥指纹>，包含独立 data、外置主密钥目录、浏览器配置和 release.json。Windows 授权仍使用此前的 license-preview-v1 身份目录。暂存 ZIP、程序目录与业务、授权目录可分别管理。

相同构建重新解压到另一个位置后，仍按同一用户目录和构建标记读取业务数据与授权。不同源码提交遇到旧预览数据时会先停止启动。收到后续稳定提交后，更新按现有规范制作完整备份，恢复到独立副本迁移并对账，维护窗口重做最终备份再切换。旧版本和回滚资料按验证结果留存，每次更新完成空间清理。 [版本升级与回滚](版本升级与回滚.md)

## 真机验收

- 在解压目录的 PowerShell 运行 .\AMR-Desktop-Preview.exe --diagnose，可用临时空库检查 SQLite WAL 运行库、DuckDB、NumPy、pandas、PyArrow、独立工作进程、迁移、静态页面与备份恢复。Windows 下还检查 Edge 安装路径和 DPAPI。结果应包含 api、frontend、worker_once、backup_restore 四项 ok。
- 再双击 EXE，验收同用户已有授权、打开界面、同时双开拒绝、正常退出及第二次启动。用新的测试数据目录和自有来源验收新增业务。
- 确认授权过期后的入口及重新导入，并用第二台真实电脑复核设备绑定。签名分发和覆盖安装都需单独验收。

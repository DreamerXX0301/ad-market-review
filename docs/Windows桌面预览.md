# Windows 桌面托盘预览

面向 Windows 11 x64 本地试用。业务基线为 b3454f2711d0bf630f552ba768843e11165855d6，完整集成提交、应用版本与依赖摘要以包内 BUILD-MANIFEST.json 为准。私有预览包提供第一方 Python 字节码与前端构建产物，签名安装器与正式升级流程另行验收。浏览器可以查看前端 JS，本机也可以分析 Python 字节码。

## 打开工作台

1. 将 ZIP 完整解压到新目录，双击 `AMR-Desktop-Preview.exe`。启动器常驻 Windows 通知区域，用系统默认浏览器打开本机工作台。若任务栏上暂时看不到图标，可以在右下角的隐藏图标中查看。
2. 关闭网页或浏览器后，后台仍会运行。双击托盘图标、右键点「打开工作台」或再次双击 EXE，可以重新打开页面。使用托盘的「退出工作台」后，后台停止接收新任务，等当前工作安全收尾后退出。
3. 同一 Windows 用户先前激活的有效卡会沿用。授权与工作台在同一个包里。进入授权页后可复制机器码，选取 `.amr-license` 文件并导入。续期时打开「授权管理」，导入新卡即可。
4. 新安装使用空业务库，数据源按原工作台流程配置。初始化与研究手动发起，新安装的自动计划关闭。

API 只监听 127.0.0.1。每次用托盘打开页面会使用短时、一次性的本机启动票据。首次分配端口后优先沿用，端口暂时不可用时换用临时端口，本次的浏览器界面偏好可能与平时不同。授权在本机离线复验。到期后仍可查看机器码和导入新卡，已有任务按安全机制收尾，历史数据留存。签发工具与私钥由卖方保管。 [离线授权契约](../contracts/desktop-licensing-v1.md)

## 从首版保留数据

先正常退出首版并等后台任务收尾，再将托盘版完整解压到新目录。首启检测到首版数据时会提示是否导入。选择导入会从停用的旧版制作备份，独立解压、恢复和核验业务数据，验收完成后托盘版使用新的数据目录。旧版程序与数据保留，可供回滚。若需要从 PowerShell 明确执行同一导入流程，请在托盘版首次启动前运行 `.\AMR-Desktop-Preview.exe --import-previous`。大库导入时会预检磁盘可用空间。

工作台数据使用当前 Windows 用户的本机 NTFS 目录 `%LOCALAPPDATA%\ad-market-review\workbench-tray-v1\<验签公钥指纹>`，包括 data、外置主密钥和 release.json。导入后还保存已验证的恢复包及小回执。授权仍存于此前的 `license-preview-v1` 身份目录。首版 Edge 专用浏览器配置保留在原目录，新版界面偏好由当前默认浏览器保存。

后续版本同样先在独立副本验收，再切换程序。旧版本和回滚资料按验证结果留存，每次更新完成空间清理。 [版本升级与回滚](版本升级与回滚.md)

## 真机验收

- 在解压目录的 PowerShell 运行 `.\AMR-Desktop-Preview.exe --diagnose`。结果窗口应包含 api、frontend、worker_once、backup_restore 四项 ok。诊断使用独立空库，并在 Windows 上核验 DPAPI。
- 双击 EXE，检查默认浏览器打开、有效授权沿用、关闭浏览器后后台继续、再次打开页面、托盘退出以及任务安全收尾。
- 用已停用首版的独立业务样本测试导入。核验新旧数据目录与旧版回滚，并检查授权到期、续期及另一台机器导入同卡的结果。

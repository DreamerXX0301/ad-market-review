# 市场温度与下一交易日计划

市场情绪页按“今天怎么看 → 下一交易日怎么准备 → 重点观察谁”组织。完整统计、指数明细、来源与情绪证据留存仍可展开查看。

左侧页内目录可直接定位市场读数、执行计划、开仓与量能、核心方向、指数环境、短线接力和历史/来源；折叠区域会先打开再定位。窄屏改为横向目录，不改变盘面观察日期。操作状态按禁止红色、条件放行绿色、等待黄色、资料未知灰色显示，同时保留文字；绿色仍需满足对应确认条件。

## 首屏怎样看

大号数字是**沪深广度温度**，计算上涨股票占当天有效上涨、下跌、平盘样本的比例。它回答当天有多大范围的股票上涨，不是账户赚钱比例，也不把不同制度的接力成功率、指数涨幅揉成一个神秘总分。温度旁给出严格前一交易日变化与样本可比率。

上市日期等资料不足、无法确认真实应有家数时，按已留存沪深主表数量作为保守上界核验可比率，并标明样本观察；主表上界可能包括非当日有效股票，不冒充完整历史范围。没有有据上界时，只保留观察温度，阶段待核验并禁止开仓，不能把少量报价当成覆盖100%。

阶段分为冰点、修复、退潮、高潮、普涨、混沌、分化及待核验，采用页面可展开查看的项目阈值。它是单日阶段观察，现有离线六阶段研究草案仍未转为已验证的交易模型。相同的高温度可能对应修复或普涨，应同时看指数、广度和短线价格反馈。

| 阶段 | 主要观察依据 | 准备重点 |
| --- | --- | --- |
| 冰点 | 低温且上涨家数很少 | 先等止跌，低温本身不能证明底部 |
| 修复 | 严格相邻前日低温，当日明显回升 | 看下一交易日是否延续，以及指数能否配合 |
| 退潮 | 严格相邻前日高温，当日明显回落 | 防守优先，核对原定失效条件 |
| 高潮 | 高广度与完整、逐股原价核验的来源事件同时达到阈值 | 防次日分歧和不可成交 |
| 普涨 | 大多数样本上涨，未命中前述优先规则 | 确认指数与接力是否同向 |
| 混沌 | 已有证据明确互相背离 | 等方向选择；缺数据本身不叫混沌 |
| 分化 | 广度可判但未命中其他条件 | 看局部方向与实际承接 |
| 待核验 | 日历、可比报价或覆盖不足 | 先核对资料，不将缺失按0算 |

例如多数个股明显反弹，而四指数的20日收益与MA20位置仍弱，页面会同时显示修复与分歧原因。不能只看温度高，就把所有行动都改成可以加仓。全部昨板队列价格偏强，也不能替代普通10%制度组资料不足的晋级结论。

## 短线接力怎样看

“昨日涨停今均涨幅”观察P日确认队列到T日的原价可比收盘收益。切到普通10%等制度组时，先按P日有据身份冻结成员；只要T日价格与公司行动资料可比，即使T日ST/制度身份尚未核验，价格反馈仍纳入计算。今日能否确认同制度晋级单独核验，不能因此只留下继续涨停的股票计算均幅。

价格主卡显示有效数/确认成员数与覆盖率，均值只代表有效价格样本；前日来源全集或分组未齐时注明范围。原先严格T日身份子样本指标移入同制度核验说明，不能冒充整组收益。晋级率缺精确证据时仍保持未知或上下界，不用价格推定晋级。无样本分组、无值指标不再堆积空卡；待核验项和原因集中展开查看，真实0仍展示。

## 下一交易日如何执行清单

开仓、加仓和抄底分别列当前准备状态、明日先确认的条件，以及失效或放弃条件。状态包含明确的禁止开仓，以及暂不考虑、等待确认、满足条件后复核；所有明日触发均为待验证。收盘资料不会提前知道次日是否满足条件。

冰点、退潮和关键数据不足时，开仓闸门禁止开仓。冰点后的显著放量、广度修复和指数当日表现达到公开条件后，才进入有条件试错，不能把指数中期偏弱直接等同于永远不能参与修复。成交额与盘面总览使用同一沪深京股票范围，显著放量默认定义为较严格前一交易日增加至少20%，这是项目规则，不是经过验证的最佳阈值。

未知、重复或不可比的成交额比较不能放行。普通趋势日不一定需要20%的显著放量，但比较资料必须完整；20%是冰点修复解禁的额外门槛。

短底只列候选，记录真实候选日指数低点与后续确认/失效条件。单日放量反弹不直接标成确定底部；先核对后续回踩、承接和是否破候选低点。前日连续冰点天数、近5日冰点次数分别计算，有断档就中断，不能把不属于冰点的历史日期硬凑进去。

- 开仓：看指数、广度与候选所属方向能否同步转强，以及真实可成交报价和观察日参照的承接。
- 加仓：先核对已有持仓原定失效条件，再核对市场与所属方向。系统不掌握真实账户承受能力，不代替这一步。
- 抄底：本版不根据冰点、大跌或单日反弹确认底部，先看止跌和后续承接，重新建立失效条件。

展开“三种情景”可看转强延续、冲高分歧、继续转弱分别如何重新评估原清单。系统没有自动下单或自动执行计划；当天一字涨停也不等于下一日有机会成交。

标题是下一交易日计划。仅当本地市场日历已经留存后一交易日，才显示具体日期；否则保留下一交易日，不用自然日加一，也不跳过未知假期去猜。

## 核心方向与个股观察

候选来自观察日真实核验的涨停样本和当日留存的题材归属，不是系统已经确认的龙头或上涨因果。最多3个方向、每个方向3只股票；独立股票列表最多5只。每只股票有入选原因、当日原始收盘参照、跟踪和失效条件，点击进入统一详情，可连续看图。

方向按已确认涨停样本下界排序，股票按来源连板数、当日成交额和代码排序；样本不完整时给出范围。没有指定日成员快照时只保留有据股票，不把今天的题材回填到历史。

历史回看是以当前留存证据复算所选日期，不声称当时已经发布过盘前计划。现有手动“情绪证据留存”仍保存原三轴统计，暂不把这里的顶层预案算作已归档。

## 涨停梯队里的形态

梯队的连板、概念、当日主线、反包及20cm股票卡片也展示地天板、一字涨停。它与个股详情、K线使用同一核验算法；缺少证据时不打标签。晋级失败组缺少独立当日跌停证明时，不推测一字跌停。判定详情见[个股成交形态标记](个股成交形态标记.md)。

## 数据与研究依据

这些读数和清单只使用本地已发布数据，不触发取数、策略、自选或回测任务。接口和精确字段见[分析接口契约](../contracts/analytics-api.md)。

上交所刊载的[投资者情绪指数构建研究](https://www.sse.com.cn/aboutus/research/report/c/10056610/files/2a3cc9eb887144759849e4287455e54b.pdf)区分可观测代理指标与投资者心理，并讨论多维度量；本项目温度和阶段阈值由本项目定义，不能称为该研究认证的标准。连续涨停的原因及交易风险也需独立分析，可参阅[深交所相关投教](https://investor.szse.cn/warning/riskedu/t20120412_550505.html)；这里不会从涨停高度推导确定的未来收益。

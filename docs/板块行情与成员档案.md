# 板块行情与成员档案

行业与题材的历史指数K线、当前成分股、指定日历史成员是独立数据能力。板块有历史价格，不代表本地同时拥有该时期的成员；历史成员缺失也不应阻止查看已留存的指数涨幅和成交额。

## 初始化与增量

新的手动初始化依次执行主行情、完整当前题材成员、板块历史K线及盘面补充。题材阶段保存当次真实采集的当前成员及采集日，不回溯构造过去五年的成员变迁。旧任务按原冻结链继续，不因更新自动扩大范围。

盘后增量追加行情和板块K线尾部，并补目标日盘面资料；当前题材成员默认沿用已留存名单和原采集日，不表示每天重新采集完整成员。需要更新成员时，由用户手动运行题材成员刷新。后续发布中留存的成员可形成离散档案，但不能把没有存档的中间日期推断为成员不变。

尚未部署的请求节奏候选只适用于更新后新创建的手动盘后增量：板块尾部保持串行，以0.6秒全局发起间隔请求；遇来源认证、权限或限流拒绝立即停发，未请求项保留未知。已排队、暂停或需要重试的旧任务继续原冻结节奏，不自动扩大目录或历史窗口。来源短样本与完整增量耗时的区别见[存储与盘后增量优化](存储与盘后增量优化.md)。

## 怎么查看

点击行业或概念名称即可打开成分股窗口，历史缺档时仍可打开查看说明。默认“所选日历史成员”只读取所选盘面日已有档案；缺档显示未知，不显示为零只，也不会自动换成当前成员。

从当天尚未发布收盘行情的盘面搜索板块时，板块 K 线截至最近的已发布收盘日。弹窗保留入口观察日，并分别标明当前成员采集日和报价日。选择历史成员时，仅可选择已发布交易日。

如需查看当前研究范围，手动将“成员口径”改为“当前最新成员”。界面分别显示成员采集日和行情日；股票指标及打开的K线使用当前业务日，不继续套用旧盘面日期。当前成员包含来源名单及本地人工调整，不能作为过去属于该题材的证明，也不会写回历史档案。

如果在非交易日初始化，成员采集日可能晚于最后行情日。例如24日采集当前成员、行情截至23日，不能据此认定已拥有23日的历史成员；仍可显式查看当前名单，界面保留24日成员与23日报价两个日期。

跨来源行业只在已核验明确代码关系时提供当前成员入口。仅有东财行业名称、缺少唯一同花顺来源身份时，不按名称猜测当前成员；已有历史同名代理仍保留原来源说明。

这些读取和口径切换只查询本地已留存数据，不联网、不创建采集任务，也不创建个股策略或跟踪记录。

# 自动支撑压力线

## 自动量价参考

普通个股、指数和板块 K 线打开后会展示「量价参考」。卡片列出风险参考、支撑、压力与突破参考，以及当前完整周期的量能和近期突破状态。点击有参考线的卡片可切换图上标注，最多显示风险、支撑、突破三条。展开「判断依据」可核对拐点形成日、确认日、原突破位和实际量能窗口。个股单位为元，指数及板块为点。

个股日K默认「一周短线」，可切换「历史结构」。一周是持股观察档位，不是将图表换成周K。短线计算及提醒仍从最近20根完整日K中寻找已确认且符合原规则的近端支撑压力，确认需左右各2根。图表的支撑观察单独展示真实位置：优先显示近20日结构支撑，超出默认5%风险距离也保留价格与实际距离，并注明「距离较远，不能替代短线风险线」；近期没有有效支撑时，可显示同一连续可比区间内的「历史结构支撑（120根）」。确实没有确认支撑才留空，不把旧低点挪近或伪造位置。支撑观察线不扩展原支撑类提醒的触发范围，提醒以设置中已保存近端基准为准；5%风险距离不再用于隐藏真实支撑。ATR14与前20日均量仍使用有界连续可比报价预热。

短线模式独立展示「短线风险线」：在有效近端支撑或仍有效的近5日原突破基准下留`0.25×ATR14`的候选、`参考收盘－1×ATR14`、`参考收盘×(1－距离上限/100)`中取最高有效价。没有近端支撑时仍可由后两项形成风险提醒参考；缺少ATR或可比报价时不生成。风险线的日期是收盘公式基准日，不能称作已确认低点。图表默认距离上限5%，这是可复核的试算参数，尚未证明最优，不表示个人成本止损或实际成交亏损上限。

图表短线风险线随所选观察日静态重算；自动提醒在「提醒设置」中另行保存逐股模式与0.5%至20%的距离上限（最多两位小数），并显示实际冻结基准。监控期间短线风险线只抬高不下调，失守后保留原基准；只有明确修改配置或点击「重新设定短线基准」才开始新一轮，保存当日不追溯提醒。已有历史结构规则仍按原配置，不自动转换；历史图上的静态参考与个人启用后的监控记录不能混为一条线。

新增量价参考线默认隐藏，需要时点击对应价位显示，独立分组并使用虚线与短标签。切换短线/历史结构会清空该组显示选择，防止旧模式价位残留；它们不修改手动画线、波浪折线、自动斜趋势线、均线及原有图层偏好，重叠标签沿用现有避让规则。个股日K可打开独立「提醒设置」，按前一交易日持久化基准做盘后收盘核验；设置、触发及每日更新见[今日提醒](今日划线提醒.md)。

历史结构沿用最近120根内连续可比的完整K线。拐点须经左右各2根完整柱确认。「结构失效参考」（旧称参考止损）使用仍有效的支撑或最近5个完整周期内仍守住的原突破位，取其中较高的基准价，再减去0.5倍ATR14。原突破位只标为回踩参照，来源继续显示原压力的形成与确认日期。压力上方加0.2倍ATR14作为待突破参考；实际突破发生时，压力和缓冲使用突破前一完整周期已知的数值冻结。ATR按真实波幅和Wilder递推计算，包含跳空，样本不足15根时不计算缓冲价。

公式使用同一周期、同一价格口径的 `H/L/C/V`（最高、最低、收盘和成交量）：

- 低拐点 `L_i < min(L_(i-2), L_(i-1), L_(i+1), L_(i+2))`，高拐点对应严格大于四个相邻高点。只在 `i+2` 完整结束后确认。确认后被后续最低/最高价穿越的支撑/压力候选淘汰，再分别选参考收盘下方/上方最近的有效候选，同价优先较近形成日。
- `TR_t = max(H_t-L_t, abs(H_t-C_(t-1)), abs(L_t-C_(t-1)))`。窗口内前14个TR的算术均值初始化，随后 `ATR_t = (13*ATR_(t-1)+TR_t)/14`。该值只刻画波动幅度，不推断涨跌方向。
- `止损参考 = 止损基准 - 0.5*ATR14`；`待突破参考 = 有效压力 + 0.2*ATR14`。突破事件使用前一完整周期已知压力与ATR判定，当前参考止损使用最近完整周期的ATR，二者时间锚分别展示。
- `量能倍数 = V_t / ((V_(t-20)+...+V_(t-1))/20)`。量能用于标注突破、回踩或跌破的成交量背景，不直接乘进支撑或止损价格，也不将放量等同于上涨。

成交量使用本完整周期除以前20个完整周期均量，均量不含本周期。首版规则将至少1.5倍标为放量，不高于0.8倍标为缩量，其余标为正常。图中分别展示突破当期与当前周期的量能，避免把几日前的放量当作今天放量。缺失、非正成交量或公司行动导致原始成交量不可比时，保留待核验。只有日K汇总时不推算分价筹码分布或盘中实时量。

界面区分收盘突破且放量、收盘突破但未达放量门槛、突破后回踩仍守住、突破后回落和支撑跌破。这些倍数是可复核的首版观察参数，尚未针对各类股票做收益有效性回测。历史结构失效参考随观察日的已知结构重算，未绑定个人成本或持仓历史；只有明确开启的短线提醒独立保存只上移的监控基准，它也不是个人持仓成本账户。

日K严格使用观察日已发布收盘，周/月只计算完整周期并标明参考日期。缺档、停牌、复权证据和确认不足会保留原因。计算复用当前图表数据及缓存，切日期、证券、周期或价格口径后重新绑定，读取不触发采集或保存提醒。旧研究报告按冻结内容展示。

历史结构及ATR缓冲可用于组织风险观察，但跳空、停牌、涨跌停及成交条件会影响实际执行。参数依据可参阅 [Fidelity 的 ATR 说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)及[平均成交量说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/average-volume)。

## 自动候选划线

在个股或大盘指数的 K 线工具栏点「划线」，可以直接选线型、输入价格或点图选价，再点「保存划线」。提醒、备注和颜色在同一个折叠项里，折叠标题会显示本次启用的提醒。

展开「自动支撑压力」，选择回看 60、120 或 240 根当前周期 K 线，再点「计算候选并预览」。勾选需要的价位后点「保存所选支撑压力线」。在「已保存划线」中可以显示、编辑或删除。重算只更新预览，重复保存同一次候选不会产生重复记录。

日K、周K、月K分别使用各自的历史结构。周/月仅使用已完成、报价完整的周期；本周或本月未完成的K线不会参与分型确认。各周期统一用观察日最近已发布日收盘划分支撑在下、压力在上，参考报价日期单独标明；不会拿上月末旧收盘把当前价格上方的线称为支撑。候选保留源周期，保存后与同一价格口径的日/周/月图共用。指数按原始点位保存。个股按当前图表的实际未复权或本地前复权口径保存，复权锚跟随当前观察日记录；以后换锚仅在公司行动证据可核验时投影显示，原保存价不被重写。

## 候选怎样得到

算法版本为 `confirmed-pivot-cluster-v1`。一个历史低点必须严格低于左侧2根、右侧2根完整可比K线的最低价，才构成已确认低分型；高点反向处理。右侧第2根的日期是确认日，必须不晚于观察日。相同价格的平顶、平底不会反复计数。缺少交易日报价或整周、整月时不会越过缺口拼接确认；未复权公司行动之后重新划定可比窗口，公司行动来源覆盖未知不生成可比候选。

低分型中不高于最近已发布日收盘的价格作为支撑候选，高分型中不低于该收盘的价格作为压力候选。同侧价位在最大跨度0.8%内聚合，采用组内算术均价；不是首尾不断扩张的链式聚合。每侧按离参考收盘的距离由近到远保留至多3条，合计最多6条。没有符合条件的候选时保留原因，可以扩大回看范围或手动输入价格。

这些是历史价格结构的参考位置，不是保证有效的支撑、压力，也不代表收益预测。图中注明观察日、来源周期、价格口径、参考收盘日期、历史分型数量与最近确认日期。来源窗口内样本少时保持少量候选，不补造6条。

## 保存和原有划线的关系

- 保存候选写入业务SQLite的 `chart_annotation`，不修改日K、指标、策略或历史事件。
- 自动候选默认只有显示用途，不启用提醒，不自动加入自选。个股如需提醒，可在保存后编辑并明确勾选规则；指数不提供个股提醒与自动自选。
- 保存来源含算法版本、行情代际、观察日、周期、窗口、分型与确认日期、原候选价。后续手工改价或改类型会标注“已手动修改”，来源证据继续保留。
- 单个标的与原手工线共同最多64条。批量超限时整批不写入。
- 窗口或行情代际变化需要重新计算。过期预览保存返回错误，不能把旧图的候选静默存到新口径。
- 未保存的预览只存在本次界面，换股票、周期、观察日、行情代际或收起候选后即移除。已保存的线按显式提醒规则保留：未实际提醒持续监控，首次提醒后继续60个市场交易日，超期由新盘后增量清理线及关联提醒；没有启用提醒的候选线不会因保存时间而到期。详见[保留规则](划线提醒到期清理.md)。

## 计算与性能边界

只有用户点击计算或保存时执行本地计算。GET列表只读取SQLite，不联网，也不会自动生成行情任务。保存时先在事务外读取单证券已发布价格并重算核验，再用短事务保存至多6条线；不会打开worker正在写入的DuckDB。计算不调用全市场图表广度或全市场行情面板，不为一个指数候选加载全部股票。

迁移021只增加来源、幂等键和股票/指数类型字段。历史手工线仍为股票标记且来源为空，不会自动改变已有提醒规则。数据库约束再次保证指数无个股提醒、自动自选及个股复权口径；提醒消费也显式只取股票规则。

验收覆盖：严格左右确认、历史观察日与未来数据隔离、D/W/M、未完成周期与缺口、公司行动、价格聚合跨度、有界候选、未知与不足样本、来源价格对账、手工修改保护、保存持久化与幂等、批量原子上限、过期代际/预览拒绝、指数API及数据库约束、旧手工线与提醒回归。

## 手动线配色

新增支撑线默认绿色、压力线默认红色、参考线默认紫色。切换用途同时切换默认颜色，仍可在三种颜色中手动选择；颜色只影响展示，不改变提醒条件。旧蓝色、金色线继续按保存色显示，仅改备注不会改色；不批量重写旧线。

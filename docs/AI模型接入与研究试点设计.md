# AI模型接入、会话与复盘设计

决策更新：2026-11-02。当前接口以[AI工作台契约](../contracts/ai-workbench-v1.md)为准，操作见[使用说明](AI研究与复盘使用说明.md)。本轮源码在独立8799预览验收，不表示正式发布；正式8788保持原版本与数据。

## 产品定位

系统角色是“A股行情复盘与个股研究助手”：自然中文、独立判断、不迎合用户预设。股票、公司经营、估值、公告、行情和复盘属于范围；普通金融概念可以直接解释；明显无关问题简短说明专业范围，不调用工具。

独立“AI助手”是主入口，个股研究和盘面页面保留快捷入口，携带标的或观察日期进入同一个助手。三处共用会话、模型配置和历史，不复制消息或重复排队。AI会话查询日期独立于盘面view date；页面日期只是可更改的问题锚点。用户直接输入首问，继续多轮追问。主界面保留消息、输入、发送/停止、新对话和历史；全部/个股/复盘只筛选历史，不改变资料权限。回答需要引用时显示简洁来源。资料查询、网络选择、证据保存、协议和费用控制在内部处理，不要求用户选择本地/联网模式或理解“冻结范围”。

问题涉及具体市场或公司事实时，先查询相应本地只读工具。确实需要外部资料且所选模型支持时，由模型申请一次联网查询。网页或工具正文是资料，不获得改变角色、运行代码或写业务数据的权限。

## 每轮查询与历史

会话绑定服务商、模型和凭据版本；页面标的、观察日只是查询锚点。旧会话继续提问也使用当前逐轮查询协议，不因旧提示词永久锁住未来问题。“今天/现在”使用本轮北京时间，不把历史页面日期当今天。

原有消息原文、当时使用的协议和来源保持不变。每个新回答独立保存本轮时间、实际工具结果、来源、协议、模型回答及用量；保留这些记录用于事后核对，不等于把未来所有查询限制在同一份旧材料中。没有跨会话长期记忆或自动把历史摘要当新事实。

本地保存最多200会话、每会话40条消息，默认30天，可手动保留。创建、追问及完成更新活动时间；读取历史不续期、不查模型、不联网。模型接收最近最多4条消息且有8KiB上限，页面仍可查看更早记录。删除或到期回收正文和事件，不抹去费用回执。

## 取数与真实边界

三个本地工具分别用于盘面、个股研究和时段可用性查询；无任意SQL、路径、文件、策略、自选或交易工具。个股复用已有真实研究报告；盘面复用不可变发布读模型、严格统计及竞价/午间/收盘记录。工具输入和返回都有界，优先保留业务事实及日期、单位、采集窗口、样本覆盖；超限整体排除条目并保留原因。

| 可用性 | 模型应解释的含义 |
| --- | --- |
| available | 已有可核对资料，说明实际样本和时间 |
| not_due | 尚未到该交易时段 |
| not_collected | 时点已到，但没有已采集资料 |
| rest_day | 经已有交易日历核验为休市 |
| unknown | 无法核实，不推定休市或数据为零 |

竞价以09:25、午间11:30、收盘15:00为时段界限，实际采集窗口另行保存。不根据星期几单独确认交易日；不拿收盘倒推竞价，不用当前成员回填历史，也不把小范围候选样本说成全市场。指数日价和历史成分是独立能力；成交额与价格活跃不等于净资金流入。没有真实净流入或连续时序时，明确分析能覆盖的量价与涨停分布，不虚构资金轮转。

部署可显式指定另一个SQLite作只读时段记录来源；连接采用mode=ro、query_only及外键/递归触发器/超时配置，只读有验证的来源文件，不读取该实例凭据、不创建任务、不联网。其他行情仍走本实例已发布快照，不能跨进程打开唯一worker正在写的DuckDB。

## 技术与流式链路

复用React、TypeScript、Vite、FastAPI、Pydantic、httpx、SQLite和Fernet加密。新增AI业务表和035/036迁移；不新增模型SDK、向量库、Redis、Celery或Agent框架，也不训练模型。

每轮发送小页面锚点、本次时间、有限历史和版本化系统提示词；模型通过Responses函数调用提出读取请求，唯一worker内的控制线程执行工具，HTTP线程只处理网络。工具结果返回模型生成自然正文，不再强迫自然回答套用旧版审计JSON。

完成回答使用安全React节点排版标题、粗体、段落、列表、表格和原生来源标签，桌面限制正文阅读宽度，移动端表格在自身容器内滚动。不执行模型HTML或任意图表代码，旧文本答案也应用相同排版，不要求用户重新生成。

供应商请求使用stream:true；增量文本经有界队列交回控制线程，短事务写事件，由API以SSE实时推送。流连接断开只重读事件，不重新提交模型。停止通过任务取消控制实际请求，已经收到的内容保存并标记未完成。发送后进程中断不自动重放收费请求。

一个用户回合最多3次模型请求、3次本地读取、1次联网；最后一次直接回答，不无限循环。每次完整模型输入最多96KiB，本地工具返回最多24KiB，回答文本最多64KiB，事件最多2048条，结束后事件暂存15分钟；最终消息独立持久化。

## 服务商、提示词和费用

DeepSeek和OpenAI分别配置Key、模型、验证及启用状态，固定官方端点，不自动跨服务商换Key或模型。模型目录以本地已核价项及主动验证为准；认证、结构化探测和实际长回答能力分别留证。当前真实认证与业务回答验收使用OpenAI；没有DeepSeek测试Key，不能宣称其实际端到端回答已验证。

提示词需要编写和版本管理，负责角色、日期解释、工具选择、事实与推断、来源质量和回答风格；凭据隔离、预算、取消、日期及来源验证由程序实现，不能只靠提示词。

默认共享限制为0.50美元/天、20次模型请求，超时45秒，可配置至60秒。一个用户问题可能产生多次模型请求，费用/次数按实际子请求登记，父任务不重复计费。每次出站前按实际完整payload和最大输出保守预留，已知usage结算后才允许后续请求。隔离试用的具体限额见使用说明，不代表安装默认或供应商余额。

联网先通过不执行网络的规划函数提出需要，再单独授权实际搜索请求并增加0.33美元保守预留；最多一次。当前只对已验证支持原生搜索的OpenAI模型开放，不把普通模型API联网等同于网页搜索。来源限交易所、巨潮及明确财经数据/新闻子域，排除股吧和自媒体入口。原生引用证明来源关联，不表示网页每个数字都已机器对账；检索时刻、网页发布日期与行情观察日分别保存。

缺usage、发送后取消或未知搜索内容计费保留待核对，不补零或自动重试。本地保护不等于供应商硬账单封顶；关闭或删会话不消除已发生费用。store:false也不表示供应商零留存。

Key只进入后端加密凭据，主密钥外置；不进入Git、浏览器存储、日志或导出。配置和验证在独立设置页，普通聊天不展示内部开关。恢复副本默认关闭AI外发、使旧验证失效并阻止已发送任务重放，同时保留历史与费用。

## 改动规模、速度与验收

改动集中在共用AI模块、两处页面入口、配置和035/036迁移，不改变策略、回测、交易信号或行情写入链。网络等待在独立HTTP线程；主worker仍可调度行情，通用行情任务忙时延后启动新AI，已有回答继续排空事件和处理取消。正常不开AI面板时延迟加载，不主动请求模型。

本地读工具、模型首轮决策、必要的后续模型生成和联网都会增加等待。流式输出减少首字等待后的空白感，不等于总耗时或模型成本消失。实际耗时和费用以同问题实测回执为准，不承诺所有网络下固定秒数。

代码、模拟流测试和浏览器布局都不能代替真实问题验收。必须使用已有用户会话再次提问“今天竞价如何”，核对实际读取了今日记录；随后查询午评/收盘，并观察首个文本在任务完成前出现。历史、刷新重连、停止、费用与正式服务不变分别检查。最新结果记录在使用说明，旧原型或旧版结构化解读结果不充当新链路的证明。

## 参考项目调研

研究了[tick-stock-panel固定提交](https://github.com/shy3130/tick-stock-panel/tree/7a7252a7446f02233649ecf443038b52574cf857)的[聊天编排](https://github.com/shy3130/tick-stock-panel/blob/7a7252a7446f02233649ecf443038b52574cf857/backend/app/custom/assistant/chat_service.py)、[工具表](https://github.com/shy3130/tick-stock-panel/blob/7a7252a7446f02233649ecf443038b52574cf857/backend/app/custom/assistant/tools.py)和[消息界面](https://github.com/shy3130/tick-stock-panel/blob/7a7252a7446f02233649ecf443038b52574cf857/frontend/src/custom/assistant/ui/messages.tsx)。借鉴按问题读数据、回填工具结果并自然流式回答的结构，没有复制代码、安装其依赖或执行其脚本。

该固定版本工具表没有通用网页搜索；模型API连通与通用联网检索是不同能力。其自动重试、长循环、双重历史和默认最新日期语义没有照搬。本项目仍保留唯一worker、指定日期、来源证明和费用约束。其[MIT许可证](https://github.com/shy3130/tick-stock-panel/blob/7a7252a7446f02233649ecf443038b52574cf857/LICENSE)不代表第三方金融数据或网页内容自动获得再分发许可。

## 图表与经营卡片的后续约束

参考界面的图表用于说明表达方式，不能当成行情来源。本轮真实个股工具已有同一报告期主营分类、原收入占比，以及带逐期披露日期的股东户数，适合分别设计分类条形图与披露期折线。产品与地区须分组，主营利润不能标成公司净利润，单季、累计与全年口径不能混为同一可比序列。当前工具没有完整营收、归母净利或PE历史序列，因此本轮先完成正文与表格排版；后续图表应从有证据ID、日期和单位的工具值确定性投影，不能照抄参考截图数值或解析任意模型图表代码。

最新修正：通过股票用途资源门槛、原用户话题继承和执行前校验，约束任何联网计划；独立房价/天气等不展开。模型可自然简拒，程序负责阻止越界数据调用，不增加付费分类请求。流式输出同时安全排版并默认跟随，用户上翻暂停、回到最新恢复。本轮先稳定现有能力，板块区间排行榜暂不接入。

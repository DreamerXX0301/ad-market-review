# AI模型接入、会话与复盘设计

当前决策对应0.1.26源码、schema40与`ai-agent-round-v5`。操作见[AI使用说明](AI研究与复盘使用说明.md)，每步执行见[AI对话执行流程](AI对话执行流程.md)，接口与边界以[工作台契约](../contracts/ai-workbench-v1.md)、[逐轮协议](../contracts/ai-agent-round-v1.md)及实现为准。源码、镜像与实例部署分开验收，不以本文认定线上已更新。

## 产品定位与入口

AI是A股盘面及上市公司研究助手，以自然多轮对话为主体。独立「AI助手」是主入口，盘面和个股页保留携带日期/证券锚点的快捷入口，共用配置、历史与发送链路，不复制消息或重复排队。

界面保留历史、正文、底部输入、发送/停止与新会话；模型切换和设置位于输入框下方。用户不必选择“仅本地/联网”、材料范围或冻结协议。程序准备实际时间和可用工具，模型决定研究所需资料并组织回答；具体不足用自然语言说明，不把内部审计清单当作答案。

页面日期与证券是起点，不是会话后续上限。可以换股、换日、问今天或继续“这一天”；观察日只辅助指代，不能自动授予股票领域权限。与股票无关的话题简短引导，不能借页面锚点、旧助手或网页话术越界。

## v5先理解语义，再执行只读计划

首个模型请求只开放一次`plan_stock_task`，强制单计划、禁止并行。模型结合当前完整问题、最近真实用户问题、执行时间和已核验证券身份判断用途，替代新轮次的关键词白名单硬拒。正常次日观察、连板指代或银行经营问题不要求固定句式；确实缺分析对象时再澄清。

入队冻结schema将当前原话与可选最近用户原话绑定enum；控制层仍逐字复核引用、函数声明、参数、来源和能力摘要。首轮可另带严格ISO验证的`observation_date`，不发页面kind/subject、旧助手正文或本地行情/报告。多个计划、混合绕过或非法字段整批拒绝，不能先执行第一项。

接受计划后持久化`accepted_stock_plan/semantic_scope`，再依序读取真实资料，交给后续模型请求自然流式回答。schema合规不保证语义永远正确，提示词也不能替代程序权限。网页、工具正文及旧助手回答只作资料，不能改变角色或增加执行能力。

## 资料能力与固定统计

八项受限读取分别为盘面`read_market_data`、盘中`read_intraday_data`、可用性`check_data_availability`、个股价量`read_stock_quote`、个股走势`read_stock_trend`、涨停梯队`read_limit_up_data`、盘面明细`read_market_detail`和已存研究`read_stock_research`。它们复用本系统已有日期、价格、发布与来源核验，不接受任意SQL、文件路径、代码、写策略、自选修改或交易指令。

没有研究报告不妨碍查询已存日价量；概览未附名字不代表梯队不存在。资料不足、尚未采集、未到时点与本轮未读取分别说明。指数日价与历史成分独立，成员缺档不清空真实指数行情；成交额及价格活跃不等于净流入，无连续时序不能推造资金路径。

盘中 `all` 按日期与冻结计划读取。当前计划包含0935、0945、1000、1030、1100、1330、1400、1430八档。旧七档、六档和四档任务按原窗口执行。09:25竞价与09:35开盘观察分别留证。股票和方向投影仅恢复已核验原引用中的行业/题材、上市板块、跌停/回封及广度、炸板指标，缺证据保留状态和原因。封炸跌停变化分布使用完整已核验池差集，先计总量、已分类和缺失，再截取分类Top与股票样本；原快照没有的年内、30日收益或涨停历史不冒充已支持。

`read_market_data(noon)`以所选来源本日原午评的实际采集结束为cutoff，累计原竞价、全部截至该点已完成留存的上午盘中和午评本体，不读下午/收盘正文。`read_market_data(close)`以同来源正式收盘锚点累计原竞价、全部已存盘中、午评与正式收盘池，另保留原午间至收盘回看。各阶段须同日、原SHA/身份/权限有效且当时已完成，收盘cutoff与正式发布时间分列；晚补档、未来日期或当前head不得回填，旧记录缺档显式保留。

盘面明细新增边界如下；查询都在完整已载入且经核验的所选来源内先过滤，再有界投影，不把返回名单当全体。

| 分区 | 数据与限制 |
| --- | --- |
| `auction`、`noon` | 原时点股票、方向、归属分布和封炸跌停事实；不要求完成日行情，不用当前成员补历史归属 |
| `dragon_tiger` | 已存股票/机构/游资榜按单日、三日分开；唯一精确命中证券才取对应席位，匿名不合并，金额不跨区间累加 |
| `abnormal` | 保留监控范围、请求日、观察日、报价日及来源期限；来源未完整时标记范围，供应商监控区间不等于官方监管或解除日期 |

过滤后的已观察数、确认总数、来源完整性和截取范围分别返回。无匹配只能说明这份留存范围，不证明全市场没有事件。

涨幅榜采用所选日原始近30交易日收益前1000固定样本，表格搜索/重排/分页之前取样，不足用实际数。页面和AI复用同一分布，题材/行业各最多Top5。同股多分类可重复，占比合计可超过100%，未知和仅资格标签样本单列，不用100%减Top5推“其他”。

研究题材维度仅排除已审定`fuyao/concept`完全同名的融资融券、沪股通、深股通资格属性；原列表标签、行业、人工同名及未审来源不因此删除。当前日重读有效分类，历史日不以当前成员或手工修改倒填。询问“前1000里有没有电池相关的票”时，按留存分类名称关键词匹配，再对同一固定样本内证券取并集。继续问一个已核验分类时用真实 topic_id 等值筛选。两种查询均在截取名单前执行，返回来源、日期、已观察数与确认总数。无匹配证据时保留未知。详见[前1000分布契约](../contracts/gainers-distribution-v1.md)。

## 技术与线程分工

复用React、TypeScript、Vite、FastAPI、Pydantic、httpx、SQLite与Fernet，不引入模型SDK、Redis、Celery、向量库或通用Agent框架，不训练模型。035/036在首次AI接入时新增7张业务表，0.1.21不新增迁移；当前schema39同时包含037盘中快照、038累计简报与039竞价补充发现，AI只读这些已保存证据。

唯一worker内AI控制线程负责调度、计划与权限校验、只读取数、预算、取消和归档。HTTP线程只处理固定官方Responses请求与流等待，经有界队列请求控制线程授权；不自行读业务库或行情。查询在事务外执行，SQLite写入短事务，不跨进程打开worker正在写的DuckDB。

新AI任务等待通用job与同步锁；网络等待与行情调度分开，不等于CPU/磁盘没有竞争。累计链复用轻量已存摘要入口和原正式发布引用，不直接读取整份盘面页面或当前head来恢复时点事实；原正文与成员证明在一次请求内复用缓存，下一轮仍重新核验来源。

单次工具结果24KiB只是返回上限，不是底层只读量；盘中每档汇总3KiB、单档详情10KiB。累计链先省略可选股票、方向等样本并保留省略数，再共享列名、成员证明和相邻引用；`phase_fact_columns`解释`values/rows`，保留原数值、null、单位、必要阶段和来源身份，不截断JSON或丢弃尾盘/正式收盘。不可约的超限返回容量不足，不伪装成缺少行情。

防止无依据输出由严格参数/权限、只读隔离、日期与代际/SHA核验、确定性统计和缺口标记共同承担，不能只交给提示词。程序保证输入边界，不保证供应商永不出错或自然语言每个数字、因果均被逐句验证；当前链路仍不承诺零幻觉。

## 流式回答、历史与费用状态

供应商`stream:true`，增量由控制线程短事务写本地事件，API以SSE回放，前端安全排版常用Markdown。上翻暂停跟随，回到底部恢复；不执行模型HTML、任意组件或图表代码。

SSE重连只续读已有事件，不重问模型；停止、中断和最终归档保留实际状态及可能的partial，不自动付费重试。正文完整完成与usage/费用可核清是不同维度，受限搜索完成后仍可能费用待核，不能将其隐藏、补零或当成供应商已扣款。

会话绑定provider/model/Key代际，换配置显式新会话，旧消息可读。历史默认30天，可保留，最多200会话、每会话40条；回答只带最近4条已完成消息、8KiB。首轮计划不发送旧助手/报告正文，无跨会话向量记忆。研究缓存仍7天，AI不续期。

临时流事件终态15分钟后可回收；正文随会话删除，任务与费用审计没有自动TTL，当前不能保证全部AI存储增长严格有界。重复验收原文不作为长期旁路留存；标准备份及必要历史证据依各自恢复规则管理。

## 模型、联网与成本

DeepSeek保持原有Flash/Pro及配置兼容。OpenAI固定八项：`gpt-6.1-sol`、`gpt-6-astra`、`gpt-6.1-terra`、`gpt-6-sol`、`gpt-6-luna`、`gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`；发现目录不扩充GPT选择器，旧标识/Key/历史不自动改写。账号权限须逐模型验证，认证与一个极小probe不等于所有复杂链路已通过。[模型核价契约](../contracts/ai-openai-models-v1.md)保留官方来源与版本。

每轮最多3次模型请求，3份实质资料加2次可用性检查、总5次本地读取，搜索最多一次。一个模型响应可提出多项查询，由控制线程顺序执行，不把每个工具画成新HTTP。额度不足返回“本轮未读取”，用剩余原有请求总结，不增加第四次。

语义计划合并在原首轮工具请求，没有另起分类模型。资料问题通常2至3请求，概念/招呼也可能2次；域外引导仍可能计费。安装默认每天0.50美元、20次请求、45秒超时，实际实例可配置；按逐次请求/验证尝试计费而非问题数，父子不重复计费，界面预估及预留不等于供应商账单或余额。

自动原生搜索目前仅接通`gpt-6.1-sol`，不是所有模型API自带联网，也不静默切服务。模型先规划，再核验股票用途、真实引用、能力、固定正规来源与费用。用户指定本系统统计时网页不能替代；网页发布日期未知不回填历史。原生引用证明关联，不证明所有自由文本和数字自动验真。

## 凭据、恢复与实际边界

Key只存后端密文，master外置，不进Git、浏览器持久存储、日志或导出。固定官方端点、TLS验证、不跟重定向，不接受任意中转URL、请求头或路径。`store:false`不能替供应商承诺零留存。

程序失败诊断仅存私有白名单version/stage/code/path，不保存原参数值、不进API/历史/SSE，终态仍清请求材料；原失败状态与账目不删不隐藏。标准恢复关闭AI、使验证过期，不重放已发送请求；独立版本、业务/费用对账、完整恢复包核验后再受控切换。

当前没有多日全板块累计收益排行榜、真实资金逐分钟路径、完整长期记忆、通用AI图表执行或自动交易。图表或经营卡片若后续增加，应由带日期、单位、证据身份的工具值确定性投影，不能复制参考截图数值或执行模型代码。

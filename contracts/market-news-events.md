# 消息与事件 v1

## 读取接口

盘面共享观察日，未手动选择时默认北京时间当日。两个接口均只读取留存数据和可丢弃的派生缓存，浏览和切换日期不会发起采集。

- `GET /api/v1/market/news-events?date=YYYY-MM-DD` 返回早盘 `auction`、午盘 `noon`、盘后增量 `after_close` 三档，含档位状态、区间起点、消息截止时间、实际归档时间、来源与理由。消息保留来源 ID、发布时间、系统观察时间、标题与 HTTPS 原文地址。来源明确提供的关联单列依据，只有相同且已经核验的事件 ID 用于双向跳转。
- `GET /api/v1/market/news-events/calendar?date=YYYY-MM-DD&days=7` 支持 `days=7` 或 `30` 个自然日，含观察日本身。返回截至所选观察日已经取得的日程版本、可核验的来源范围和区间内事件。事件状态包括已确认、暂定、延期和取消。国家统计局年度发布日程按来源标记为暂定，带官方文档链接，有明确时间时标注北京时间。
- 档位 `pending` 表示尚待归档，`missing` 表示没有留存，`expired` 表示超出留存。来源异常是 `unavailable`，来源范围未齐全是 `partial`；`complete` 的空列表仅表示本次已核验的来源区间无新增。

页面把同一观察日的已归档消息合为一条时间轴，按原文发布时间倒序。同一来源同一 ID 只显示首次归档的记录，跨自然日的消息保留原始日期。

## 采集与存储

采集默认关闭。已授权的本地唯一 worker 在空闲时执行，早盘从北京时间 09:00 到 09:02 前，午盘从 12:30 到 12:35 前，盘后跟随同日增量的主行情发布。消息早盘和午盘先使用现有核验回执，缺回执时在当天档位内用已启用的扶摇交易日历核验一次。国家统计局日历的启用与财联社采集独立。竞价与午评原有时间不受消息档位配置影响。09:23 至 09:30 及当日竞价任务仍在排队或执行期间，消息采集不入场。第三方请求在有硬超时的独立短进程执行，返回后再做本地短事务。来源缺档不阻塞竞价、午评或增量的发布。

消息区间从上一份有效简报的实际截止时间衔接。盘后简报结束之后的公告、隔夜、周末及节假日消息归入下一次有效档位；超过抓取范围或分页上限明确标记覆盖缺口。过期快照按 30 个自然日滚动，事件日历保留覆盖最早可回看日的必要来源版本。历史回看使用当时留存的消息和日历版本，缺少同期行情和关联依据时保留未知。

盘面读取沿用共享 `pane-read-cache-v1`。近 7 个已发布交易日走常规缓存，较早的留存日期首次写入后保留 24 小时，重复打开不延长。缓存命中仍校验对应归档，来源有新版本、缓存缺失、过期或校验失败时从 SQLite 正式归档重读。

# 前端调用与交互约定

API 根路径 `/api/v1`，snake_case；成功直接返回业务对象，列表通常为 `{items,total}`，错误为 HTTP 状态与 `{detail}`。本页描述消费规则，字段与业务语义分别见 [Analytics API](analytics-api.md) 和 [Workspace API](workspace-api.md)。不把当前机器的验收数量或来源样本写成接口保证。

## 页面与日期域

| 页面/入口 | 主要 API | 日期域 |
| --- | --- | --- |
| 盘面总览、指数、情绪、行业题材、梯队、涨幅榜、异动、资金 | `/overview`、`/market/{kind}`、chart | 共享盘面观察日 |
| 题材库 | `/topics`、`/topic-members` | 当前分类与业务日报价，成员采集日另示 |
| 个股策略/跟踪 | `/strategies`、`/strategy-runs`、`/tracking-*` | 当前业务日或冻结运行/轮次 |
| 板块策略/跟踪 | `/sector-strategies`、`/sector-strategy-runs`、`/sector-tracking-*` | 独立板块业务与冻结证据 |
| 个股研究 | `/research/jobs` | 指定标的手动运行，材料时间与行情截止分别显示 |
| 个股回测 | `/backtests` | 本次独立起止日及预热范围 |
| 数据中心/来源 | `/data/status`、`/tasks`、`/sources` | 同步任务冻结目标日及当前能力验证 |

切换盘面日期不改策略日期、跟踪进度或回测区间。从盘面打开详情保持该观察日；从冻结选股结果连续浏览保持运行 business_date；跟踪导航按当前筛选/排序列表，保留每股当前轮次的价格锚点。股票切换须清旧名/旧数据，不把前一只的报告或事件价短暂展示给新标的。

## 搜索与成员

- 专用股票/研究选择器继续调用 `/instruments`；顶部全局搜索使用 `/search?query=&limit=`。按 `target_type/kind` 分股票、指数、行业、概念，不用代码形状猜类型。
- 全局检索仅支持已有名称/代码；没有拼音保证。板块点击传明确 topic_code，不能用名称拼接代码或向股票 chart 发请求。
- 板块 K 与成员独立入口；members_available=false 不应禁用已有真实板块 K。
- `/sectors/{topic_code}/members` 不需要跟踪轮次。latest 默认当前业务日报价，可对应较新的真实成员采集日；historical 只读所选日档案。两个日期醒目标明，历史缺档不回填当前成员。
- 成员显示 board_label、年内/30日收益、年内涨停次数与最近确认日期，另有本月收益时不能替代 30 日。它们共用 `/instruments/{id}/summary` 语义；未知显示原因，下界不写成精确次数。
- 展开板块成员只浏览股票，不自动创建个股跟踪，不向股票图传板块事件价基线。

## 图表与行情

- CandleChart 支持 D/W/M、MA5/10/20/30/60/250、量、MACD、KDJ；指标由后端返回，前端不重复计算。副图数值显示在对应副图，null 不补零连线。
- 日线指标连续显示模式与严格市场日模式分开；报价连续不补停牌 K，也不改变业务条件。保存的图表偏好只影响显示。
- price_basis 请求 none/forward，并展示实际返回口径和回退原因。板块/指数隐藏个股复权与涨跌停开关。
- 周/月形成中或不完整柱显示状态，不能把图表最后一根形成中柱当成策略已确认信号。候选浪点需满足确认日期不晚于观察日，不宣传确定浪型。
- 涨跌停箭头仅画来源核验正事件；未知/冲突不当普通未涨停。周/月显示具体日事件摘要，不画“整月涨停”。
- 指数自身涨跌幅放点位旁，amount_change 单独显示较前一交易日放量/缩量金额；缺金额为待核验，零差为平量。四指数金额不得相加充当沪深总成交额。
- `data_coverage` 在各页显示来源真实范围、部分覆盖及所选日可用性；不从 bootstrap 主行情范围猜全页完整。available_dates 只是稀疏已确认日期。
- 情绪首屏展示市场赚钱效应和昨日涨停样本今日反馈，无自造总分。收益正负红绿，比例/计数用中性语义；显示“可比 X / 观察 Y、待核验 Z”，收益覆盖不等于来源全集完整。
- 资金净流入、指数成交额和跨日资金趋势分别标口径；同名跨源映射明确提示，不能声称历史成分完全相同。

## 条件编辑、运行与跟踪

- fields 接口是编辑器白名单，尊重 type/operators/integer/min/max/constant_only/fixed_period 与场景限制；不可将新高的 N 输入当成布尔值，也不提供跟踪专用字段给普通选股。
- 普通叶可独立 D/W/M，日固定字段不随策略切周期。历史事件用独立节点编辑窗口、latest/earliest、自定义 where 和 then，事件内部锁日线；已有复杂树不可按扁平叶覆盖或静默丢失。
- 数值比较、趋势状态和上穿/下穿事件清楚区分；“金叉=false”不能替代死叉。提醒推荐与结束推荐分开，但已保存的跨场景合法字段仍可读/编辑。
- checks 展示 actual、unknown reason、信号日/周期及必要来源证据。滚动一年次数 actual=null 时，可显示“至少 N 次”；有限上下界证明不伪装完整值。
- 新运行的非命中候选可能仅包含相关指标和证明，不能假定所有候选都带所有技术字段。选股/核对运行期间按 task 状态显示真实进度，并允许取消。
- 跟踪进度 unknown 显示“交易日进度待核验”，不填 0 或绘制假百分比；已知 D0 正常显示 0。提醒不移出，结束归档；缩短期限后待手动核对不静默结束。
- 默认政策应用活动轮次需显式勾选，先展示影响数及跳过自定义数；不改变原始入池日期、价格及历史事件。
- 个股政策逻辑为 AND/OR，独立板块政策为 ANY/ALL，不能只改标签而改变保存语义。板块跟踪不提供个股回测入口。
- 普通 Table 在完整已加载列表上排序后本地分页；服务端已分页/排序表使用 external，不把当前页排序说成全量。unknown 两方向均最后，股票连续浏览使用同一筛选排序顺序。

## 数据中心与任务

| 操作 | 前端行为 |
| --- | --- |
| 主初始化 | 读取 initialization.can_initialize；主发布成功后禁重建，不用 market.ready 猜附属链全部成功 |
| 板块全库首次 | 读取 sector_charts.initialization；collection_complete 可在质量 partial 时成功锁定，首日来源缺口不等于需重拉 |
| 盘后增量 | 当前日 18:00 后手动提交；新链跟进板块尾部及当日补充，不给用户再点整库初始化 |
| 单板块历史 K | GET 先读缓存；缺缓存显示明确加载按钮，POST 后轮询精确 topic_code/as_of/target_date 任务 |
| 题材全量与盘面补充 | 用户显式提交；分别显示真实覆盖和缺口，不与主初始化混成一个成功图标 |

任务 progress/stage_progress 为 0–100 百分比；无真实百分比只显示排队或不确定进度，不使用计时假增长。批次数使用 actual_completed_batches/actual_total_batches，不能将加权 accepted_batches 冒充实际页数。

状态包括 queued/running/paused/succeeded/no_change/partial/failed/cancelled。区分任务终态与来源覆盖，partial 仍需说明可用与失败范围。暂停/取消不自动继续；控制按钮按支持动作显示，retry 可返回新任务 ID。关闭浏览器不取消已提交任务。

新初始化链为主行情→题材→全库板块 K→补充；新增量为主行情→板块尾部→补充。旧冻结任务不扩范围。已完成板块首次初始化后，create/retry/resume 的 409 是正常保护，不通过换 request_key 绕开。

## 来源、研究与回测

- 来源能力 available/locked/unsupported/unverified 分开显示，保留 account_access/checked_at 和证据；有 Key 或“免费/付费”标签不代表已获全部权限。验证只在用户操作后请求，页面挂载不自动探测。
- API Key 输入提交/关闭后清空，不存 localStorage、URL、日志或导出。后端响应只含配置状态，不返回密钥。
- 研究更换标的清空旧报告与任务绑定；旧任务回调必须匹配当前请求，防止旧股报告覆盖新股。搜索浮层不能被小面板裁切，保持键盘/Escape 操作。
- 研究按真实中文阶段和进度展示，材料 partial 保留缺口；列表轮询不续期，七天过期后主动打开/运行可重拉。仅已加载材料可本地排序，不能冒称来源全集。
- 回测先查 availability，范围外/未支持条件不给运行；七项统计、订单/成交/交易/权益与拒单原因保留。期末持仓严格筛 end_date，胜率/盈亏比无定义显示未知。
- 叠层详情仅最上层处理 Escape/遮罩；上层有正确 dialog/focus 语义，关闭后返回仍存在的触发元素，不能一次 Escape 误关底层列表。

可执行接口审计入口为 [check-api.mjs](../frontend/scripts/check-api.mjs)，只读检查不等于供应商未来稳定性保证。公开仓库不包含运行数据、账户凭据或本机验收材料。

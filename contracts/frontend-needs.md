# 前端调用与交互约定

API 根路径 `/api/v1`，snake_case；成功直接返回业务对象，列表通常为 `{items,total}`，错误为 HTTP 状态与 `{detail}`。本页描述消费规则，字段与业务语义分别见 [Analytics API](analytics-api.md) 和 [Workspace API](workspace-api.md)。

## 页面与日期域

| 页面/入口 | 主要 API | 日期域 |
| --- | --- | --- |
| 盘面总览、指数、情绪、行业与概念、梯队、涨幅榜、异动 | `/overview`、`/market/{kind}`、chart | 共享盘面观察日 |
| 盘前竞价 | `/market/auction`、`/market/auction/dates`、`/market/auction/automation` | 共享盘面观察日；竞价使用本次冻结时点，正式历史图严格早于该日；自动竞价配置不随观察日改变 |
| 午评快照与收盘回看 | `/market/noon`、`/market/noon/dates`、`/market/noon/{snapshot_id}/sector-members`、`/market/noon/close-review` | 共享盘面观察日；午间报价绑定原快照，收盘回看另核验同日已发布行情 |
| 题材库 | `/topics`、`/topic-members` | 当前分类与业务日报价，成员采集日另示 |
| 个股策略/跟踪 | `/strategies`、`/strategy-runs`、`/tracking-*` | 当前业务日或冻结运行/轮次 |
| 板块策略/跟踪 | `/sector-strategies`、`/sector-strategy-runs`、`/sector-tracking-*` | 独立板块业务与冻结证据 |
| 个股研究 | `/research/jobs` | 指定标的手动运行，材料时间与行情截止分别显示 |
| 个股回测 | `/backtests` | 本次独立起止日及预热范围 |
| 数据中心/来源 | `/data/status`、`/tasks`、`/sources` | 同步任务冻结目标日及当前能力验证 |
| 数据中心自动午评/盘后设置 | `GET/PUT /settings/automatic-tasks` | 独立于盘面观察日的全局配置；按服务器北京时间有效窗口执行 |

切换盘面日期不改策略日期、跟踪进度或回测区间。从盘面打开详情保持该观察日；从冻结选股结果连续浏览保持运行 business_date；跟踪导航按当前筛选/排序列表，保留每股当前轮次的价格锚点。股票切换须清旧名/旧数据，不把前一只的报告或事件价短暂展示给新标的。

站内日期字段共用 `DatePicker` 日历弹层，支持年份/月快速选择、ISO 日期输入、范围校验及键盘移动。`allowedDates` 只有在调用方提供明确离散日历时才限制为可选交易日；仅有起止范围不推断周末、节假日或历史数据完整性。盘面保留精确前后交易日与最新日按钮；回测及历史成员仍使用各自日期域。Escape 先关闭日历并返回触发控件，不连带关闭外层成员弹窗。

## 搜索与成员

- 专用股票/研究选择器继续调用 `/instruments`；顶部全局搜索使用 `/search?query=&limit=`。按 `target_type/kind` 分股票、指数、行业、概念，不用代码形状猜类型。
- 全局检索仅支持已有名称/代码；没有拼音保证。板块点击传明确 topic_code，不能用名称拼接代码或向股票 chart 发请求。
- 板块 K 与成员独立入口；members_available=false 不应禁用已有真实板块 K。
- `/sectors/{topic_code}/members` 不需要跟踪轮次。latest 默认当前业务日报价，可对应较新的真实成员采集日；historical 只读所选日档案。两个日期醒目标明，历史缺档不回填当前成员。
- 盘后成员显示 board_label、年内/30日收益、年内涨停次数与最近确认日期，另有本月收益时不能替代 30 日。它们共用 `/instruments/{id}/summary` 语义；未知显示原因，下界不写成精确次数。
- `NoonSectorDialog`是独立的[同快照午间成员详情](noon-sector-members.md)：成员价幅只取原`{snapshot_id}`中的午间报价，不套用通用收盘`summary`，也不拿最新或昨日收盘价补缺报。午间报价日与成员名单留存日分别展示；板块及个股正式K线背景严格早于午评日，不拼入午间报价。六个上市板块快捷按钮复用服务端`board`筛选，切换回第一页，保留搜索、排序与快照身份；板别未知和报价未知分别处理。
- 个股与研究行情摘要显示五项：今日涨幅、年内涨停次数、最近确认涨停日期、年内涨幅、近30交易日涨幅。今日按摘要观察日的 `change_pct` 显示，历史观察日标明日期；不随图表周/月切换改用周期涨幅。缺少精确前一市场交易日或可比公司行动证据时显示待核验，不填 0。
- 30日涨幅榜、资金轮动、行业题材成员、搜索、自选和策略共用StockDrawer基础布局、详情/摘要数据及个股图表偏好；只保留各自观察日、已加载筛选排序列表和真实策略/自选事件上下文。普通盘面/成员导航分别标记market/members，不冒充策略或跟踪来源，不携带意外策略checks或事件基准。每次换股按完整代码和日期隔离旧响应。
- 详情头部统一读取 `current_topics/current_industries/current_topics_observed_date/current_topics_scope`，按当前业务日有效题材/人工归属展示，来源采集日期独立说明，与自选同口径；回看历史也明确“当前归属，非历史归因”，原观察日topics不被覆盖。缺字段为待核验，空数组为暂无已知归属，不能解释为没有分类。股票未加入自选或没有策略记录时仍有基础行情资料，不因此创建业务事件。
- 展开板块成员只浏览股票，不自动创建个股跟踪，不向股票图传板块事件价基线。
- 行业/题材成分股弹窗在桌面使用接近视口的独立宽高，上方筛选与表头保持可见；表格独立滚动，分页和关闭操作留在容器内。只调整成员弹窗，不放大策略、来源配置等其它对话框。

## 图表与行情

- KDJ 仅展示 K、D 曲线与数值，J 值不进入图表、提示、研究指标表或个股/板块条件选择；服务端原始数据与既有配置仍保留。含隐藏指标的历史条件只显示保留提示，不展示其阈值或证据数值。

- CandleChart 支持 D/W/M、MA5/10/20/30/60/250、BOLL、量、MACD、KDJ；MA/MACD/KDJ 由后端返回，前端不重复计算。BOLL 是显示专用独立副图（含同周期、同复权OHLC蜡烛及上红、中青、下绿三轨），使用本次返回的同口径收盘价及后端连续段/预热元数据计算20周期简单均值 ± 2倍总体标准差，禁止跨重置段拼接；不足20根可比报价/完整周期保留空值。副图数值显示在对应副图，null 不补零连线；副图及开关统一按成交量→BOLL→KDJ→MACD排序，指数上涨家数置后。
- BOLL 独立副图显隐与成交量/MACD/KDJ 副图组合按个股/指数分别保存；指数另可保存上涨家数。全部副图关闭是有效偏好；BOLL 默认关闭，原副图默认开启。偏好面板与图下开关共用设置，跨同类型图表/刷新同步；升级保留已有均线、复权和波浪偏好。
- 日线指标连续显示模式与严格市场日模式分开；报价连续不补停牌 K，也不改变业务条件。保存的图表偏好只影响显示。
- price_basis 请求 none/forward，并展示实际返回口径和回退原因。板块/指数隐藏个股复权与涨跌停开关。
- 头部固定显示匹配证券和观察日的真实未复权日收盘、涨幅与实际报价日期，明确非实时，hover与日/周/月切换不改变；观察日缺报价时标明最近实际报价日期或待核验。旧锚前复权水平线仅在 `annotation_projection_evidence` 的chart-annotation-projection-v1、同代际、published_corporate_actions覆盖范围含旧锚且事件可核验时换算展示；原存储价、锚和提醒证据不变，证据不足列明隐藏原因。
- 周/月形成中或不完整柱显示状态，不能把图表最后一根形成中柱当成策略已确认信号。候选浪点需满足确认日期不晚于观察日，不宣传确定浪型。
- 涨跌停箭头仅画来源核验正事件；未知/冲突不当普通未涨停。周/月显示具体日事件摘要，不画“整月涨停”。
- 指数自身涨跌幅放点位旁，amount_change 单独显示较前一交易日放量/缩量金额；缺金额为待核验，零差为平量。四指数金额不得相加充当沪深总成交额。
- `data_coverage` 在各页显示来源真实范围、部分覆盖及所选日可用性；不从 bootstrap 主行情范围猜全页完整。available_dates 只是稀疏已确认日期。
- 情绪首屏以顶层 `market_outlook` 展示沪深广度温度、单日阶段和下一交易日条件计划，再列同日有据方向及候选。三轴统计不合成交易评分，离线六阶段草案不转正；缺关键证据待核验，所有未来触发均未观察，短底最多为候选。
- 短线价格观察默认展示全部队列；切换普通10%等制度组后以 `cohort_price_feedback` 为价格主卡。今日制度身份未知或改变不单独剔除有效价格，原 `metrics` 的严格同制度子样本在展开区独立说明。旧快照缺新对象时明确为旧子样本，不能冒充整组均幅。显示“可比 X / 观察 Y、待核验 Z”，收益覆盖100%不证明来源全集或昨日分组完整。
- 情绪页按可用章节提供最多8项页内目录，折叠区域先展开再定位；页底、连续切换长短制度组、人工滚动和窄屏横向目录保持定位与高亮一致，不改共享日期或路由。当前目录项用蓝色；执行状态另以禁止红、条件绿、等待黄、未知灰和文字同时表达。收益仍涨红跌绿。
- 无样本制度组收起，无值指标集中列出待核验原因，全无值指数窗口按需展开；真实0必须显示。来源与覆盖说明仍可查。
- 总览炸板/封单前五、梯队、主线、情绪名单与连板反馈复用 `board_presentation`。今日高度、昨日高度、板型、量能和反馈分别展示；类型过多时保留高度与量能，额外板型可展开。反馈默认按已确认昨日高度降序、同高按代码、未知置末；排序及概览不回退未核验原高度。字段和阈值见[分析契约](analytics-api.md)与[板型说明](../docs/连板高度板型与反馈.md)。
- 资金净流入、指数成交额和跨日资金趋势分别标口径；同名跨源映射明确提示，不能声称历史成分完全相同。

## 条件编辑、运行与跟踪

连板反馈从资金轮动移到市场情绪（明细与概览）和盘面总览（紧凑概览及跳转）。市场读数之后先看指数环境，再看执行计划与核心方向；目录与实际布局一致，来源与留存移出统计折叠区，单独放页底。完整统计和个股名单默认展开；题材候选与独立名单统一使用CopyStockCode，复制不打开个股。概览含核验通过的昨日首板；明细只展示昨日二板及以上，首板不进入明细导航。概览按全部已返回样本统计，不能受明细分页/排序影响，首板来源缺失不显示为零。

### 个股划线与自选提醒

- 划线类型 `reference/support/resistance` 与名字分开；已有无类型标记按 `reference`、空提醒、关闭自动入自选显示，不根据“支撑”等旧名字猜用途。新线默认支撑、仅 `support_reclaim`，`support_breakdown` 为另勾的失守风险项；压力使用 `pressure_close_breakout/pressure_touch`，不能提交 `resistance_*` 模式键。
- 支撑回踩收回、压力收盘突破或日内触碰为成功触发；收盘失守为 `invalidated`，颜色与标题单独呈现，不当成回踩成功，不自动加入自选。typed line 的 `auto_watchlist` 开关独立；不在自选的股票也可保存并启用提醒。保存后核验当前已发布完整日 K，此后每次手动行情更新继续核验；只读页面挂载不创建核验任务。
- 线价为主输入，备注次要，颜色色点与支撑/压力/参考分段选择；规则卡展示明确语义。历史线型、价格口径与固定复权锚日保留，切股/切锚时不能携带上一股草稿或异步结果。
- 自选页分“自选股票 / 划线提醒”，冷加载数量显示 `—` 而非假空0。提醒默认“今日”，仅指最新已发布业务日的触发；“历史”仅含更早事件，支持截至日期，不按创建时间把历史补跑改成今日。`GET /watchlist/line-alerts?scope=today|history|all&as_of=&limit=100` 默认 `all` 保持旧调用；今日/历史界面至多读取1000条，显示加载范围与持久总数，搜索和状态筛选仅限已加载记录。`GET /watchlist` 每股的 `latest_line_alert` 仍按股票批量返回，不从全局列表的截断结果推断无提醒。
- 顶部全局提醒入口使用 `GET /watchlist/line-alerts/summary`，只读业务SQLite的当日总数与最新5条紧凑事件，不读取行情、不触发检查、不新增后台轮询。业务日变化、核验完成或返回可见页面时刷新；点击可直达今日提醒。只显示数量和记录预览，不播放声音，不保存声音偏好，不发送浏览器或外部通知；页面关闭时不承诺提醒。
- 事件证据优先用 `comparison_line_price` 作实际判定线价，单列原保存 `line_price`、原 `price_basis/anchor_date` 与 `comparison_evidence.comparison_anchor`，避免公司行动转换后把原保存价与原始日线混比。前收盘、开高低收、划线版本与记录时间使用保存证据，不拼最新报价。缺失证据不补0。
- 自动入池显示 added/already_present/disabled/capacity_reached/not_eligible/missing_current_quote 的真实结果；容量满、缺当前报价或已移出时提供手动自选星标。补跑历史命中显示触发交易日与实际加入自选业务日，后者独立冻结加入价；不使用历史触发价替代。移出自选不等于停用独立划线提醒，停用需取消全部模式；同事件重复检查不自动加回。
- 未实际触发线持续监控；首次实际成功或失守风险提醒后继续60个市场交易日，重复提醒不延长。图表管理列表显示首次提醒日期和固定规则；不增加延期或期限配置。下一次新盘后增量清理超期线及关联提醒，自选和策略跟踪保留。清理完成通知复用 LINE_ALERT_CHECK_FINISHED，重新读取当前线与自选。
- 手动“检查划线提醒”以 request_key 幂等提交，未确认响应可同键重试，确认已接受后下一次显式检查用新键。复用全局 activity 的真实 operation/进度，隐藏路由关闭本页 GET，终态读取持久结果并刷新 membership；compact activity 中已过期的手动任务按精确 job_id 恢复状态。`latest_check.stale/is_current/stale_reason` 将旧规则/旧行情核验与当前结果分开，不能把旧完成当当前已核验。
- 全局 activity 按已完成划线检查的 job_id/finished_at_ms 及最后已知快照去重通知共享自选 IDs；不依赖访问自选页，所以搜索打开个股并保存线后自动入自选，当前星标也更新。最近5条之外已过期的先前活动检查只触发一次有界 IDs 读取；隐藏浏览器停用既有 activity 轮询，不查全历史。并发中的旧 IDs 请求需先结束再读取完成后的版本，多个完成顺序合并，不能把旧响应当新自选状态。

- fields 接口是编辑器白名单，尊重 type/operators/integer/min/max/constant_only/fixed_period 与场景限制；不可将新高的 N 输入当成布尔值，也不提供跟踪专用字段给普通选股。
- 普通叶可独立 D/W/M，日固定字段不随策略切周期。历史事件分“近N日内任一天 / 自定义前N—M日 / 指定前N日”三种呈现，复用 from/to AST，新建默认前1—30交易日、不含今日、包含两端，旧定义原样保留。历史倍量/同日已核验收盘涨停/自定义 where 与“今日条件”then 分开编辑，快捷添加今日涨幅、MACD/KD金叉及可选事件价比较；latest/earliest 明确说明先选一次事件再判断今日，未知不能绕过。事件内部新条件锁日线；已有复杂树不可按扁平叶覆盖或静默丢失。
- 数值比较、趋势状态和上穿/下穿事件清楚区分；“金叉=false”不能替代死叉。提醒推荐与结束推荐分开，但已保存的跨场景合法字段仍可读/编辑。
- checks 展示 actual、unknown reason、信号日/周期及必要来源证据。滚动一年次数 actual=null 时，可显示“至少 N 次”；有限上下界证明不伪装完整值。
- 新运行的非命中候选可能仅包含相关指标和证明，不能假定所有候选都带所有技术字段。选股/核对运行期间按 task 状态显示真实进度，并允许取消。
- 个股及行业/概念策略页提供独立策略多选、当前目标全选、“执行所选并跟踪”和“一键执行并跟踪”；策略选择和单策略候选手动入池选择分别维护，勾选框不得嵌套在策略按钮内。新批次由后端冻结自动跟踪语义，逐个筛选，全部 matched 自动加入各自策略跟踪池，已跟踪或手工忽略跳过；已有仅筛选批次不追溯执行入池。前端仅以批次 `auto_add===true` 显示自动跟踪，其余明确标注“仅筛选的历史批次”。逐项展示 selection_status、tracking_status、命中/新增/跳过/其中手工忽略计数；缺统计显示待回报，不能把未执行伪装为0或入池完成。批次与子项进度、当前策略、失败原因及精确 run_id 结果可恢复；读取或打开结果不创建任务。POST 响应不确定时同参数重试复用 request_key，选择/顺序/范围/行情日变化才生成新 key；确认已创建后下一次显式执行使用新 key。
- 批次列表通过 GET 恢复；可见策略路由中每次读取完成后再安排下一次2秒轮询，隐藏路由或浏览器标签页时中止、终态停止、暂停等待手动继续。只有已完成子项计数增加才刷新策略元信息和历史结果，不每次轮询重载结果或发 POST。旧结果在批量运行期间继续保留；暂停、继续、取消通过显式任务操作执行。
- 个股与板块运行结果共用三段计数控件“满足 / 待核验 / 未满足”，显式0保留，未知计数不填0；支持箭头、Home/End和单一键盘焦点。结果日期、规则版本和已保存状态仅在标题展示；正常保存不重复全宽提示，仅正在更新或行情/版本变更时显示简短状态，不影响原排序、判断依据或已保存结果恢复。
- 跟踪进度 unknown 显示“交易日进度待核验”，不填 0 或绘制假百分比；已知 D0 正常显示 0。提醒不移出，结束归档；缩短期限后待手动核对不静默结束。
- 默认政策应用活动轮次需显式勾选，先展示影响数及跳过自定义数；不改变原始入池日期、价格及历史事件。
- 个股政策逻辑为 AND/OR，独立板块政策为 ANY/ALL，不能只改标签而改变保存语义。板块跟踪不提供个股回测入口。
- 普通 Table 在完整已加载列表上排序后本地分页；服务端已分页/排序表使用 external，不把当前页排序说成全量。unknown 两方向均最后，股票连续浏览使用同一筛选排序顺序。
- 个股及板块跟踪表显式启用多条件排序，默认跟踪进度（已核验市场交易日数）降序、同进度按今日/观察日涨幅降序；个股提醒默认触发日、触发日涨幅降序。优先级控件支持增删、字段/方向切换、上下调整及重置；点击表头切回单项排序。先应用既有文本、题材及热点筛选，再比较原始未舍入值，最后分页；每级未知值始终排末，全部同值按证券/板块身份及轮次稳定排序。进度不按期限百分比排序，价格变化待核验不得按隐藏的原始涨幅排序。只改变客户端浏览顺序，不增加API查询参数、不创建任务或改变政策/提醒规则；提醒范围仍限接口已加载记录。通用Table默认单列排序及external表不受影响。

## 数据中心与任务

| 操作 | 前端行为 |
| --- | --- |
| 主初始化 | 读取 initialization.can_initialize；主发布成功后禁重建，不用 market.ready 猜附属链全部成功 |
| 板块全库首次 | 读取 sector_charts.initialization；collection_complete 可在质量 partial 时成功锁定，首日来源缺口不等于需重拉 |
| 盘后增量 | 默认当前日18:00后手动提交；显式启用自动计划后的创建见下文，新链及整库初始化保护不变 |
| 单板块历史 K | GET 先读缓存；缺缓存显示明确加载按钮，POST 后轮询精确 topic_code/as_of/target_date 任务 |
| 题材全量与盘面补充 | 用户显式提交；分别显示真实覆盖和缺口，不与主初始化混成一个成功图标 |

数据中心的[自动午评与盘后计划](automatic-review-tasks.md)新安装默认关闭。设置卡只GET/PUT配置，保留两个开关、北京时间和修订号冲突保护；保存成功不表示任务已创建或执行，不由浏览器计时取数。显式开启后唯一worker仅在当日有效窗口内创建任务，初始化和跨日历史补跑仍不自动发起；失败、暂停、取消不自动重试或继续。自动盘后沿用原会话发现、全站锁与完成结果确认，未确认上一轮时等待，不替用户确认。[自动竞价](auction-snapshots.md)使用其独立配置与原任务授权规则，两类设置不混用。

任务 progress/stage_progress 为 0–100 百分比；无真实百分比只显示排队或不确定进度，不使用计时假增长。批次数使用 actual_completed_batches/actual_total_batches，不能将加权 accepted_batches 冒充实际页数。

“数据覆盖”卡分开显示已留存记录和 `coverage_progress` 的已覆盖/应覆盖、单位及百分比。各卡明确交易日、证券上市日期、成员组、来源事件或指标可用率等分母维度；缺分母、零样本或冲突时显示比例待核验且不画进度条。不能用一模块行数占全库行数充当完整度，也不能把来源三池100%解释为全部盘面历史100%。

卡头按维度 `coverage_status/coverage_label` 显示当前范围已覆盖、有缺口、待核验或按需计算；原 `status` 发布质量只在详情用 `snapshot_quality_label/note` 说明。进度百分比显示舍入到100而原始整数分子仍小于分母时，显示“<100%”；按需指标注明输入行情记录，不画假完成率。任务结束状态、当前维度完整度和发布时整体质量不可混用。

上市身份保留 `catalog_count` 总名录，`listed_count` 为已核验上市日期，`pending_listing_count` 为来源未来上市日或人工确认并有同代无报价证据的待上市；未知日期、无报价本身不能产生待上市结论。覆盖分母为已上市加未知，待上市另列不计入当期分母，不能用覆盖分母替代总名录。详情读取 `/data/listing-status`，列出来源日期、依据、对应业务日及 `confirmed_at_ms` 的实际记录时间，不能把 `confirmed_date/observed_business_date` 当真实操作时间。人工通用入口显式 POST `/data/listing-status/confirm`，只保存 pending/unknown 确认与说明，不填上市日期、不硬编码代码；同参数不确定重试同 request_key，行情日变化需刷新。人工更正使旧覆盖报告过期，提示重验；源日期只按来源更新，上市后下一次盘后增量重新核验并纳入。

`daily_raw/analysis_bars` 共用 `daily.gap_diagnosis`，两个覆盖行打开同一份诊断。默认按股显示结论、影响和下一步，按无报价日数/最长区间/区间数排序并搜索；股票区间和日期两层折叠且惰性挂载，避免把数千日期直接铺出。isolated/long_consecutive 只是连续市场交易日形态，不作停牌推断；本地原始包、规范行情、显式远程来源核验分别标明。

“向来源核验”只在用户点击时 POST `/data/quote-gap-source`，GET 仅恢复计划与小摘要，不联网探测。完整本地核验报告变化后更新 planKey 并重读可用性，防止先本地核验后按钮仍保留旧不可用状态。任务进度复用共享 activity 并在完成后刷新共用诊断；隐藏路由暂停本页 GET。来源回执按 diagnosis/head 绑定，过期不用于当前结论；`source_no_quote` 不等于停牌证明，有可补报价也需另行发布核验。统计明确“本次股票核验 checked/planned”，缺口核验为 checked_sessions/total_gap_sessions，全量证券数另列，不能将3/3子集解释为全部1125只完成；未提供数字显示未知而非0。

状态包括 queued/running/paused/succeeded/no_change/partial/failed/cancelled。区分任务终态与来源覆盖，partial 仍需说明可用与失败范围。暂停/取消不自动继续；控制按钮按支持动作显示，retry 可返回新任务 ID。关闭浏览器不取消已提交任务。

全局任务条复用一次 `/tasks/activity` 读取，跨页面与浏览器刷新展示真实任务名称、策略、阶段、已报告进度及结果。个股/板块提交即时显示待确认状态并禁重复；服务端确认前不伪造百分比。活动时2秒读取，空闲30秒，读取失败15秒重试，隐藏标签页暂停轮询。终态可收起；不发起、继续或重跑任务。策略页默认 GET 恢复所选策略的最近保存结果，标明日期和版本；旧日期/规则提示手动刷新，计算中或失败保留上次成功结果。

服务自动竞价在用户明确保存配置后，由唯一worker到窗口触发。前端全局只读发现并核验已有竞价任务，复用午评/盘后增量的同一进度对话框和背景不可操作状态；来源未就绪且仍有自动重试授权时持续等待，不把一次暂时失败当整体完成。无真实活动任务的初始检查不空锁工作台，暂时失联也不擅自认定结束。采集终态后释放并打开原观察日结果。页面打开、状态轮询或历史切换均不自动POST配置或创建采集。

数据中心历史轮询使用`/tasks?limit=200&summary=true`，只取小回执、显示参数及三类链状态事件；不能每2秒重新下载全部任务计划、来源SHA或大日志。当前选中任务仍单独GET完整详情，保留执行记录；历史小回执中的chain_authorized/followup_queued/chain_blocked应继续驱动“等待后续排队”和按钮禁用，不能用精简列表绕过任务链保护。

新初始化链为主行情→题材→全库板块 K→补充；新增量为主行情→板块尾部→补充。旧冻结任务不扩范围。已完成板块首次初始化后，create/retry/resume 的 409 是正常保护，不通过换 request_key 绕开。

## 来源、研究与回测

- 来源能力 available/locked/unsupported/unverified 分开显示，保留 account_access/checked_at 和证据；有 Key 或“免费/付费”标签不代表已获全部权限。验证只在用户操作后请求，页面挂载不自动探测。
- API Key 输入提交/关闭后清空，不存 localStorage、URL、日志或导出。后端响应只含配置状态，不返回密钥。
- 研究更换标的清空旧报告与任务绑定；旧任务回调必须匹配当前请求，防止旧股报告覆盖新股。搜索浮层不能被小面板裁切，保持键盘/Escape 操作。
- 研究按真实中文阶段和进度展示，材料 partial 保留缺口；列表轮询不续期，七天过期后主动打开/运行可重拉。仅已加载材料可本地排序，不能冒称来源全集。
- 回测先查 availability，范围外/未支持条件不给运行；七项统计、订单/成交/交易/权益与拒单原因保留。期末持仓严格筛 end_date，胜率/盈亏比无定义显示未知。
- 叠层详情仅最上层处理 Escape/遮罩；上层有正确 dialog/focus 语义，关闭后返回仍存在的触发元素，不能一次 Escape 误关底层列表。
- 股票代码旁提供独立复制按钮，默认显示并复制六位代码且保留前导零；完整证券ID须明确使用完整代码模式。复制按钮与打开股票的名称按钮并列，不能嵌套按钮；点击、Enter或空格复制不触发开图。仅剪贴板写入成功后提示已复制，权限拒绝或不可用时保留可选中的代码并提示手动复制；切换股票后不继承上一个代码的复制反馈。

可执行GET接口审计入口为 [check-api.mjs](../frontend/scripts/check-api.mjs)，完整审计须在隔离副本运行。它打开研究报告时会续期 `research_report` 和 `retention_pin`，不是业务库完全不变的只读验证；不配置来源或创建同步、选股任务。正式只读升级验收应逐项核对GET副作用并排除报告详情读取，另做业务对账。接口审计不证明供应商未来稳定性，公开仓库不包含运行数据、账户凭据或本机验收材料。

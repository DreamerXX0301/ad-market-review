# AI自动联网与来源引用契约 v1

版本：2026-11-02，对应当前源码，与[AI工作台](ai-workbench-v1.md)配套。文件名沿用v1；当前行为已取代首版“用户选择本地或联网、会话固定模式”。不表示已发行、部署或完成本轮端到端验收。

## 调用时机与角色

用户直接提问，不选择本地/联网模式。每轮为独立任务，页面标的与as_of仅是锚点。实际市场、公司或资金事实先查适合的本地只读工具；资料不足且确需外部资料时，模型可申请`request_web_search(query,reason)`。这个function只规划，不自行搜索或抓取页面；后续模型请求才提供官方`web_search`。

通用金融概念可以直接解释，招呼简短回应；明显无关话题简短说明A股研究范围，不以联网扩大为任意聊天、代码执行或业务操作。网页及工具正文均是不可信资料，不可改变系统角色、读取Key/文件、执行SQL、创建策略、自选或交易。

当前仅已验证并启用的OpenAI `gpt-6.1-sol`有本应用原生搜索能力。其他服务可使用本地工具，不能因此自动换模型或假称已搜索。每轮是否联网由问题与实际能力决定，没有默认强制搜索。

旧客户端的SessionCreate/MessageCreate.allow_web仍可接收，但新链路忽略其模式含义。旧会话的mode/allow_web字段仅用于读取历史格式，不限制新轮次。旧保存答案、原policy和旧来源保持原文；同一旧会话的新追问使用本轮协议与本轮来源，不要求为了查今天另开对话。

## 日期与本地资料

本轮提供执行时北京时间及页面锚点，提交与执行时刻分开保存，排队跨日会刷新执行时钟。用户说“今天、现在、最新”时，应按服务器实际Asia/Shanghai日期查询，不能把旧会话as_of当今天。日期明确改变是正常需求，不是提示注入。网页现在补查的内容、查询时间、页面历史观察日和来源发布日期分别保存；没有可信发布日期时保持null，不回填历史当时已知。

已保存的竞价、午间、收盘资料由受限本地工具查询；“午盘未到”与“午盘已到但未采集”依据实际时钟和记录分开。网上找到的信息不写成本地实时行情、净流入、完整名单或历史当时可知事实；成交额不是净流入，供应商主力净流入分类也不是机构账户真实流向。

## 搜索与来源范围

本轮协议保存搜索政策快照，当前为`ai-web-official-domains-v2`。允许域及其子域：

```text
cninfo.com.cn
sse.com.cn
szse.cn
bse.cn
data.eastmoney.com
finance.eastmoney.com
emweb.securities.eastmoney.com
quote.eastmoney.com
basic.10jqka.com.cn
news.10jqka.com.cn
```

不开放财经根域下所有泛子域、股吧或财富号入口。经营与财报数字优先公司公告、财报PDF、交易所原文，其次正规数据页；域名白名单不证明每篇正文真实、完整或具有再次外发授权。不得以论坛、自媒体转载作经营或净流入数字的确定结论。

模型可以不申请搜索；一旦通过规划进入搜索请求，唯一hosted工具使用`tool_choice:'required'`、`search_context_size:'low'`、`return_token_budget:'default'`、`max_tool_calls:1`，实际执行最多一次。低搜索上下文不是精确内容Token上限；没有自造数字return_token_budget。Responses采用store:false、TLS校验、禁止重定向和固定官方服务域；系统代理仅由部署端显式启用，用户不能设置中转地址。store:false不等于供应商零日志或零留存。

## 结果与引用

新回答为自然文本`response_type:'agent_answer'`，详情包含：

```text
{text,partial,source_context:{
 page_anchor,request_time,submitted_request_time?,tool_results,
 web:{allowed,used,search_call_count,queried_at_ms,requested_as_of?,page_as_of?,validation:'native_citations_only'}
},tool_traces,
 citations:[{start_index,end_index,url,title,source_id}],
 sources:[{source_id,url,title,published_at:null,accessed_at_ms,provenance:"native_annotation",consulted_match,annotation_only}]}
```

具体GET消息公共字段、usage与cost见工作台契约。旧`web_answer`消息按原封套读取，不改写为新格式。新轮次的角色、工具调用参数、实际工具结果及当时协议独立留证；原始凭据、代理认证及私有源路径不保存到用户可见封套。

page_as_of只记录页面锚点；requested_as_of记录本轮盘面工具实际解析的日期，没有可确认目标时可为null，不能为了填字段沿用旧页面日期。搜索问题、实际查询时间与原生来源仍独立保存。

只有本次已完成查询响应的供应商原生url_citation才可成为链接，正文自写URL不采纳。原生annotation提供URL/title/位置；额外sources清单用于记录consulted_match，未精确匹配时标annotation_only，不谎称已读取该页全文。校验http(s)、允许域、无内嵌凭据、正常端口、长度和字符，以及终态原生文本的Unicode码点索引。前端使用Array.from处理码点，不能直接把offset当UTF-16 slice。模型正文自写URL不自动变成可信引用；正文不执行HTML、代码或Markdown链接。

一次原生搜索响应最多24个来源、48处引用，文本最多12000字符，原生网络子封套不超过64KiB。实际搜索却缺引用、来源不在允许域或索引不合法时失败，不自动修复、再搜或降级成无来源完整成功。整体agent最终封套最多256KiB；partial和错误需保留不完整状态。SSE中间文字是过程输出，最终正文与来源从已保存消息读取；重连不发起第二次搜索。

原生引用只证明供应商提供的来源关联，不证明每个网页数字经过本地对账。新自然回答及网络段落不显示“全部数字已核验”或套用旧本地metric占位符校验标签。历史材料不足时应指出具体影响，不能反复泛称资料永远冻结、拒绝今天查询。

## 预算、记录与恢复

同一次用户问题可能先后有多次模型请求。每次实际出站由AI控制线程重新核对共享日预算、请求数、配置及取消状态，并生成独立`ai_request_receipt`；网络线程不直接读写SQLite。每次完整请求上限96KiB，包括本轮前序工具结果和工具定义，不是只计算问题文本。

只有实际进入带官方搜索工具的请求才追加搜索预留。目前Sol按128000搜索内容Token、输入/缓存写入较高单价保守预留0.32美元，再加一次工具费0.01美元；价格版本及实际政策写入本次计费元数据。这是本地保守准入，不是供应商账单或硬消费上限。

未实际搜索且完整回执可确认时，按有效usage正常估计结算；已搜索但无法确认input是否已含搜索内容，保留pending与保守预留，不能假设免费或重复扣算。只有可确认总input已包含内容，才按总input再加实际search调用费一次估算。取消、超时、来源核验失败或断线均不自动退款、补发或换服务。

完成消息与来源按会话30天/手动保留规则管理，浏览历史或SSE不联网、不续期。删除/到期删除业务正文及来源，独立用量和费用凭证继续保留。恢复默认停AI、旧验证失效；已发送未完成的轮次留partial与待核费用，不自动重发。

默认安装仍为两家共享每日0.50美元/20次。隔离验收当前为10美元/100次、超时60秒，历史费用与待核预留均保留；详见使用说明，不是产品默认值，也不能用旧试验额度或费用证明当前agent调用均已验收。
